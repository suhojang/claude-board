## 🪟 Windows

Windows 10 · 11 판도 있습니다. PowerShell 에서 한 줄로 설치합니다.

```powershell
irm https://raw.githubusercontent.com/suhojang/claude-board/main/windows/packaging/install.ps1 | iex
```

설치 프로그램을 쓰려면 [ClaudeBoard-3.2.3-setup.exe](https://github.com/suhojang/claude-board/releases/download/windows-v3.2.3/ClaudeBoard-3.2.3-setup.exe) 를 받아 실행합니다([windows-v3.2.3 릴리스](https://github.com/suhojang/claude-board/releases/tag/windows-v3.2.3)).
필요한 환경 · 사용법 · macOS 판과 다른 점은 [windows/README.md](windows/README.md) 를 보세요.

## 💡 컨셉

Claude Code 를 여러 프로젝트 · 터미널 탭에서 함께 돌리면, 어느 세션이 승인을 기다리는지, 어느 세션이 응답을 끝냈는지 알려면 탭을 하나씩 돌아봐야 합니다.
Claude Board 는 그 확인을 보드 한 장으로 옮깁니다.

- 🗂️ **한눈에**: 프로젝트 폴더(claude 를 띄운 폴더)마다 카드 하나에 세션을 묶고, 급한 순서(승인 대기 → 작업 중 → 대기)로 보여 줍니다.
- 🔔 **놓치지 않게**: 승인이 필요하거나 응답이 끝나면 화면 가운데(메뉴에서 네 모서리로 바꿀 수 있음)에 알림 패널이 뜹니다. 키보드 입력은 가져가지 않습니다.
- 🖥️ **터미널까지 한 창에**: 보드에서 띄우거나 이어 연 세션은 보드 왼쪽 터미널의 탭(보드 탭)에서 돕니다. 왼쪽 터미널 · 오른쪽 보드를 한 화면에 두고, ⌃⌥T 로 접으면 보드만 남습니다.
- 🎯 **바로 그 자리로**: 세션을 누르면 그 세션의 터미널 탭으로 가고, 종료된 세션은 보드 탭에서 `claude --resume` 으로 이어 엽니다.
- 📊 **한도까지 함께**: 5시간 · 주간 사용 한도와 계정 전환을 보드에서 바로 다룹니다.

아이콘도 이 생각을 그대로 담았습니다. 상태 점(승인 대기 주황 · 작업 중 파랑 · 완료 초록)이 붙은 세션 카드가 보드에 쌓여 있습니다.

설치하면 Claude Code hook 이 세션마다 상태를 `~/.claude/notifier/sessions/` 에 기록하고, 보드와 알림 패널이 그 기록을 읽어 보여 줍니다.

## 🧰 필요한 환경

- 🍎 macOS 14(Sonoma) 이상 (Apple Silicon · Intel)
- 🤖 Claude Code
- 🐍 python3 (`python3 --version` 이 나오면 됩니다. 없으면 `xcode-select --install`)
- 👻 다른 터미널에서 도는 세션의 탭으로 이동 · 일시중지 · 보드로 옮기기는 Ghostty 1.3 이상에서만 동작합니다. 보드 탭 세션과 보드 · 알림은 터미널 앱과 상관없이 동작합니다.

## 📦 설치

```sh
curl -fsSL https://github.com/suhojang/claude-board/releases/latest/download/install.sh | bash
```

- ⚙️ 처음 설치할 때 `~/.claude/settings.json` 에 hook 11개와 환경변수 `CLAUDE_CODE_DISABLE_TERMINAL_TITLE=1` 을 등록할지 묻습니다.
  원본은 `settings.json.bak-claude-board-<날짜-시각>` 으로 백업하고, 다른 hook · 설정은 그대로 둡니다.
- 🔐 예전에 dmg 로 설치한 앱을 바꿀 때만 관리자 비밀번호 창이 한 번 뜹니다.
- 🎉 설치가 끝나면 보드가 열립니다. 이미 실행 중인 Claude Code 세션은 다시 시작해야 hook 이 적용됩니다.
- 🔁 보드 안 터미널에서 실행하면 그 보드는 끄지 않습니다(탭의 세션이 끊기지 않게). 끝난 뒤 보드를 종료(⌘Q)하고 다시 열면 새 버전이 뜹니다.
- 🛑 다른 터미널에서 실행하면 떠 있는 보드에 종료를 청합니다. 보드 탭에서 작업 중인 세션이 있으면 ⌘Q 와 같은 확인 창이 뜨고, 취소하면 설치하지 않습니다.

설치하면 `/Applications/Claude Board.app`, `~/.claude/notifier/` 의 알림 패널 · hook 스크립트, 로그인 자동 실행(LaunchAgent),
`~/.local/bin` 의 `claude-board` · `claude-board-tui` 명령이 생깁니다. Ghostty 가 있으면 Ghostty 를 열 때 보드를 함께 띄우는 줄을 `~/.zshrc` 에 넣습니다.
보드는 뜰 때 답변 마크다운 꾸미기 플러그인을 `~/.claude/notifier/plugins/md-render/` 에 옮겨 두고 보드 탭의 claude 에만 씁니다(Claude Code 전역 플러그인으로 설치하지 않습니다).

## 🕹️ 사용법

### 🪟 보드 열기

- 🔁 로그인할 때 저절로 실행됩니다(**설정 > 일반 > 로그인할 때 열기** 로 끌 수 있습니다). Ghostty 가 있으면 Ghostty 를 열 때 보드가 꺼져 있으면 함께 띄웁니다.
- 🖱️ 메뉴 막대의 Claude Board 아이콘을 누르면 보드를 열고 닫습니다. 승인 대기 · 작업 중 세션 수도 함께 보입니다.
- ⌨️ 어느 앱에서든 ⌃⌥B 를 누르면 보드가 처음 크기로 화면 오른쪽(보드 위치가 왼쪽이면 왼쪽)에 붙어 앞으로 나옵니다(터미널은 접힙니다). ⌃⌥T 는 보드 안 터미널을 펼치고 접습니다.
- 💻 터미널에서 `claude-board` 는 보드 창을, `claude-board-tui` 는 터미널판 보드를 엽니다.

### ⚡ 자주 쓰는 조작

| 하고 싶은 것 | 방법 |
|---|---|
| 🧭 그 세션의 터미널로 가기 | 세션 줄을 누르기. 보드 탭 세션은 터미널을 펼쳐 그 탭(나눈 화면이면 그 화면)으로, 다른 터미널 세션은 더블 클릭으로 그 탭으로 (Ghostty 1.3 이상) |
| ⏯️ 끝난 세션 이어 열기 | 종료된 세션을 누르면 보드 탭에서 `claude --resume` 으로 이어 엽니다 |
| 🖥️ 터미널 펼치기 · 접기 | 제목 막대의 **터미널 펼침 · 접힘** 단추나 ⌃⌥T. 터미널과 보드 사이 경계를 끌어 폭을 바꿉니다 |
| 🔲 창 크기 바꾸기 | 터미널을 펼친 동안 제목 막대나 경로 줄 · 탭 줄의 빈 곳을 두 번 누르기(초록 단추도 같음). 화면 전체 ↔ 가로 · 세로 60% |
| ➕ 새 세션 시작 | 탭 줄 끝 **+ ⌘T** 단추나 ⌘T 로 작업 폴더 · 명령 고르기, 또는 경로 카드 머리의 + 로 그 경로에서 바로 |
| 📁 경로별 탭 | 탭 줄 위 경로 줄에서 작업 경로를 누르면 그 경로의 탭만 보입니다. ⌃⌥↑ · ⌃⌥↓ 로 앞 · 뒤 경로, 보드 카드 머리를 눌러도 그 경로로 |
| ✂️ 화면 나누기 | ⌘D · ⇧⌘D 로 오른쪽 · 아래로 나누고 ⌘[ · ⌘] · ⌥⌘방향키로 화면 고르기, ⇧⌘↩ 로 하나만 크게 (Ghostty 와 같은 키) |
| ✏️ 탭 이름 바꾸기 | ⇧⌘R 로 고른 탭의 이름을 탭 안에서 고치기(Return 저장, Esc 취소, 비우면 폴더 이름). 그 탭 claude 의 세션 이름도 같게 바뀝니다 |
| ⚙️ 설정 | 메뉴 막대 **Claude Board > 설정…** (⌘,). 보드는 그대로 두고 터미널 자리가 설정 화면으로 바뀝니다. Esc 나 **터미널로 돌아가기** 로 닫기 |
| 🔠 글자 크기 | 터미널은 ⌘+ · ⌘- (모든 탭), 보드는 ⌥⌘+ · ⌥⌘- · ⌥⌘0. **설정 > 터미널 · 보드** 나 메뉴 막대 **윈도우 > 글자 크기** |
| ⌨️ 단축키 바꾸기 | **설정 > 단축키** 에서 줄의 키를 누르고 새 키 누르기. 다른 앱(Rectangle 등)과 겹치는 키를 옮길 때 |
| 🎨 터미널 테마 바꾸기 | **설정 > 터미널** 의 테마 목록에서 검색 · 미리보기하고 고르기 (열린 탭 모두 바로 바뀜) |
| ⏸️ 일시중지 · 재개 · 중단 | 세션 줄 오른쪽 위 ⋯ 메뉴 (일시중지는 보드 탭 · Ghostty 세션만) |
| 🚚 Ghostty 세션을 보드로 | ⋯ 메뉴의 **보드로 옮기기**. 그쪽 세션을 끝내고 보드 새 탭에서 같은 대화를 이어 엽니다 |
| 🔍 한 상태만 보기 | 윗줄의 상태 칩(승인 대기 · 작업 중 · 대기)을 누르기, 다시 누르면 모두 보기 |
| 👤 계정 바꾸기 | 사용 한도 카드 왼쪽 위 계정을 누르고 저장한 계정 고르기 (**계정 추가…** 로 미리 저장, 로그인은 **설정 > 계정** 안에서) |
| 🔀 한도가 차면 계정 자동 전환 | 계정 메뉴의 **한도가 차면 다른 계정으로 자동 전환** 을 켜기 (기본 꺼짐). 한도로 멈춘 보드 탭 · Ghostty 세션은 전환 40초 뒤 이어서 진행합니다 |
| 🔕 알림 끄기 | 세션 줄의 종 토글은 그 세션만, 윗줄의 종 단추는 전체 |
| 📍 알림 위치 바꾸기 | **설정 > 알림** 의 화면 그림에서 가운데(기본) · 네 모서리 가운데 하나 누르기 |
| ↔️ 보드를 화면 왼쪽에 두기 | **설정 > 창 > 보드 위치** 에서 오른쪽(기본) · 왼쪽 |
| 🤏 창을 작게 두기 | 오른쪽 위 최대축소 단추(↘↖)로 미니 화면, 같은 자리의 ⤢ 로 원래 크기 (터미널을 펼친 채 줄였으면 다시 펼쳐짐) |
| 🌫️ 마우스가 밖에 있을 때 흐리게 | 오른쪽 아래 투명도 슬라이더 (터미널을 펼쳐 화면 전체를 덮은 동안에는 불투명) |
| 🎭 캐릭터 바꾸기 | 캐릭터를 오른쪽 클릭하거나 **설정 > 일반** 에서 고르기 |

제목 옆에는 Claude Board 버전이, 그 아래 활성 세션 수 옆에는 설치된 Claude Code 버전이 보입니다.

## 👀 화면 둘러보기

> ℹ️ 화면의 프로젝트 · 계정 · 사용량은 모두 예시 데이터입니다.

### 📋 보드: 지금 어떤 세션이 무엇을 하고 있는지

맨 위 화면이 보드입니다. 프로젝트 폴더(claude 를 띄운 폴더)마다 카드 하나에 세션을 묶고, 급한 순서(승인 대기 → 작업 중 → 대기)로 보여 줍니다. Claude 가 하위 폴더로 `cd` 하거나 워크트리에 들어가도 세션은 같은 카드에 남아, 보드 안 터미널의 경로 줄과 같게 묶입니다.

- 🚦 **윗줄 상태 칩**: 승인 대기(주황) · 작업 중(파랑) · 대기(회색) 세션 수입니다. 누르면 그 상태의 세션만 남깁니다.
- 📊 **사용 한도**: 5시간 · 주간 한도를 얼마나 썼는지와 언제 초기화되는지 보여 줍니다. 왼쪽 위 계정을 누르면 저장해 둔 다른 계정으로 바꿉니다.
- 📝 **세션 줄**: 마지막 요청 내용, 경과 시간, 응답한 모델과 effort(막대 5칸), 컨텍스트 사용량이 붙습니다. 승인 대기면 무엇을 기다리는지 주황 글씨로 나옵니다.
- 🏷️ **세션 칩**: 세션이 어디서 도는지 보여 줍니다. 보드 탭 `CB`, 다른 터미널은 앱 이름(`Ghostty` 등), 백그라운드는 `$ claude -p` · `$ claude --bg`, 종료된 세션은 "보드에서 이어 열기".
- 🔖 **세션 이름**: 칩 옆에 Claude Code 의 세션 이름(세션끼리 메시지를 보낼 때 부르는 이름)이 붙습니다. 보드 탭 세션은 탭 이름과 같고, 다른 터미널 세션은 Claude Code 가 붙인 이름(예: `claude-board-81`) 그대로입니다. 보드 칸이 좁으면 먼저 빠집니다.
- 📑 **세션 메뉴**: 세션 줄 오른쪽 위 ⋯ 를 누르면 보드와 같은 모양의 패널이 뜹니다. 맨 위에 세션 이름 · 상태 · 칩 · 작업 폴더가, 그 아래 항목마다 아이콘 · 제목 · 한 줄 설명이 보입니다. 쓸 수 없는 항목은 흐리게 두고 까닭을 적고, 세션 중단은 빨간색으로 아래에 따로 있습니다. ↑↓ · Return 으로 고르고 Esc 나 바깥 클릭으로 닫습니다.
- 🧩 **서브에이전트**: 세션이 띄운 하위 작업이 아래에 이어지고, 지금 쓰는 도구(Grep · Read 등)가 보입니다.
- 💤 **백그라운드 · 조용한 카드**: 터미널 없이 도는 세션은 따로 묶이고, 30분 넘게 조용한 경로는 저절로 접힙니다.
- 🎭 **캐릭터**: 오른쪽 위 캐릭터가 세션 상황을 말풍선으로 알려 줍니다. 승인 대기가 있으면 재촉합니다.

### 🖥️ 보드 안 터미널: 세션을 보드에서 바로 띄우고 다룰 때

보드 창 왼쪽에 터미널이 있습니다(엔진은 Ghostty 의 libghostty). 보드에서 새로 띄우거나 이어 연 세션은 이 터미널의 탭(보드 탭)에서 돌고, Ghostty · iTerm2 등에서 도는 세션은 그대로 그 터미널에 있습니다.

- 🪟 **펼치기 · 접기**: 제목 막대의 **터미널 펼침 · 접힘** 단추나 ⌃⌥T. 펼치면 창이 화면 전체로 넓어지고(기본), 접으면 보드만 화면 오른쪽에 남습니다. 가운데 경계를 끌어 폭을 바꾸면 기억합니다.
- 🔲 **창 크기 전환**: 펼친 동안 제목 막대(창 맨 위 띠)나 경로 줄 · 탭 줄의 빈 곳을 두 번 누르면 창이 화면 전체일 때는 가로 · 세로 60% 크기로 화면 가운데에, 그 밖의 크기일 때는 화면 전체로 바뀝니다. 초록 단추도 같습니다.
- ↔️ **보드 위치**: **설정 > 창 > 보드 위치** 에서 오른쪽(기본) · 왼쪽을 고릅니다. 왼쪽이면 펼친 창이 보드 · 터미널 순서가 되고, 접기 · 최대축소 · ⌃⌥B 도 화면 왼쪽 기준입니다. 고르면 바로 적용됩니다.
- 🎞️ **펼치기 · 접기 애니메이션**: **설정 > 창 > 펼치기·접기 애니메이션** 을 켜면 약 0.55초 동안 부드럽게 넓어지고 좁아집니다. 기본은 꺼짐이라 바로 바뀝니다. 움직이는 동안 터미널 화면은 다시 그려지지 않습니다.
- 📁 **경로 줄**: 탭은 작업 경로마다 따로 봅니다. 탭 줄 위 경로 줄에 탭이 있는 경로가 상태 점 · 폴더 이름 · 탭 수로 늘어서고(많아서 넘치면 가로로 밀어 봅니다), 탭 줄에는 지금 경로의 탭만 보입니다. 경로를 누르거나 ⌃⌥↑ · ⌃⌥↓ 로 옮기면 그 경로에서 마지막에 고른 탭으로 갑니다. 세션 줄을 누르거나 이어 열거나 새 세션을 시작하면 그 세션의 경로로 바뀝니다. 탭의 경로는 탭을 연 경로라 셸에서 `cd` 해도 그대로입니다. 터미널을 펼친 동안 지금 경로의 보드 카드는 폴더 아이콘에 터미널 표지가 붙고, 카드 머리를 누르면 그 경로로 바뀝니다.
- 🗂️ **탭**: 세션은 탭으로 하나씩 보고, 탭 안의 화면을 나눌 수도 있습니다. ⌘1~⌘9 로 탭 줄(지금 경로의 탭) 순서대로 바로 고르고 ⌃⌥← · ⌃⌥→ 로 왼쪽 · 오른쪽 탭으로 가며(Ghostty 의 ⇧⌘[ · ⇧⌘] · ⌃⇥ · ⌃⇧⇥ 도 같고, 접혀 있으면 펼칩니다), 탭에 마우스를 올리면 나오는 × 로 탭을, ⌘W 로 고른 화면을 닫습니다(화면이 하나면 탭이 닫힙니다). 탭이 많아 넘치면 탭 줄을 가로로 밀어 보고, 고른 탭은 늘 보이게 탭 줄이 따라 움직입니다. ⌘ 를 누르면 바로 탭마다 × 자리에 ⌘1~⌘9 가, 고른 탭에 **⇧⌘R 이름 바꾸기** 가 보입니다. 글꼴 · 색은 Ghostty 설정을 따르고(테마는 보드에서 따로 고를 수 있습니다), 한글 조합 중 Return · Esc 가 한 번에 듣습니다. 한글 입력 상태에서도 ⌘W · ⌘C · ⌘V 같은 단축키가 영문 상태와 같이 듣습니다.
- ✂️ **화면 나누기**: Ghostty 와 같은 키로 탭 안의 화면을 나눕니다(메뉴 막대 **윈도우 > 화면 나누기**). ⌘D 는 오른쪽, ⇧⌘D 는 아래로 나눠 지금 화면과 같은 폴더의 셸을 엽니다. ⌘[ · ⌘] 로 앞 · 뒤 화면, ⌥⌘방향키로 그 방향 화면을 고르고 화면을 눌러도 됩니다. 고르지 않은 화면은 흐리게 보입니다. 경계를 끌거나 ⌃⌘방향키(10pt씩)로 크기를 바꾸고 ⌃⌘= 로 고르게 합니다. ⇧⌘↩ 로 고른 화면 하나만 크게 보고 다시 누르면 돌아옵니다. 탭의 상태 점은 화면들 가운데 가장 급한 세션을 따르고, 세션 줄을 누르면 그 세션의 화면으로 갑니다. 나눈 모양은 보드를 다시 켜도 남습니다.
- 🔠 **글자 크기**: 메뉴 막대의 **윈도우 > 글자 크기** 나 **설정 > 터미널 · 보드** 에서 터미널과 보드를 따로 정합니다. 터미널은 ⌘+ · ⌘- 로 1pt씩(열린 탭 모두와 새 탭), **터미널 글자 원래 크기** 로 Ghostty 설정 크기로 돌아갑니다. 보드는 ⌥⌘+ · ⌥⌘- 로 10%씩(80%~150%), ⌥⌘0 으로 원래 크기입니다. 둘 다 다시 켜도 남습니다. ⌘0 은 터미널에서도 **세션 보드 보기** 입니다.
- 🎨 **터미널 테마**: **설정 > 터미널** 의 테마 목록에서 엔진에 든 테마 485개를 이름으로 찾고, 줄마다 색 띠와 옆의 터미널 견본으로 미리 봅니다. 줄을 누르면 열린 탭 모두 바로 바뀝니다. 고른 테마는 Ghostty 설정의 theme 보다 먼저이고 다시 켜도 남습니다. 목록 맨 위 **Ghostty 설정 따르기** 를 고르면 Ghostty 설정을 따릅니다(Ghostty 설정 파일은 바꾸지 않습니다). 밝은 테마에서는 고른 탭과 지금 경로 칸의 글자가 어둡게 바뀝니다.
- ✏️ **탭 이름 바꾸기**: ⇧⌘R 을 누르면 고른 탭의 이름 자리가 입력 칸이 됩니다. Return 이나 다른 곳을 눌러 저장하고, Esc 로 취소합니다. 비우고 저장하면 폴더 이름으로 돌아갑니다. 바꾼 이름은 보드를 다시 켜도 남습니다(메뉴 막대 **윈도우 > 탭 이름 바꾸기**).
  보드 탭의 claude 는 탭 이름을 세션 이름으로 씁니다. 같은 이름을 쓰는 세션이 이미 있으면 `-2`, `-3` 을 붙이고(나눈 탭의 화면들도 이렇게 나뉩니다), 화면이 하나인 탭의 탭 줄에는 그 세션의 실제 이름이 보입니다. claude 가 도는 탭의 이름을 바꾸면 보드가 그 claude 에 `/rename <새 이름>` 을 바로 쳐 넣습니다. 승인을 기다리는 중이면 승인 창에 키가 들어가지 않게 승인을 처리한 뒤에 칩니다. 아직 요청이 없는 세션은 첫 요청을 보낼 때 칩니다(그동안 탭 줄은 새 이름, 카드 라벨은 옛 이름). 입력 칸에 쓰던 글이 있으면 그 글과 섞일 수 있습니다.
- ⚙️ **설정 화면**: 메뉴 막대의 **Claude Board > 설정…** (⌘,)을 누르면 보드는 그대로 두고 터미널 자리가 설정 화면으로 바뀝니다(기본은 옆으로 밀려 들어옵니다. **설정 > 창 > 설정 화면 전환** 에서 서서히 바뀌기 · 효과 없음으로 바꿀 수 있습니다). 왼쪽의 일반 · 창 · 알림 · 터미널 · 보드 · 계정 · 단축키 · 업데이트 묶음을 고르거나 검색 칸에 이름을 쳐 모든 묶음에서 찾습니다. 바꾸면 바로 적용되고 다시 켜도 남습니다. Esc(검색어가 있으면 먼저 지웁니다), **터미널로 돌아가기**, ⌘, · ⌘W 로 닫습니다. 터미널이 접혀 있었으면 펼쳐서 보여 주고 닫을 때 다시 접습니다. 설정 화면이 떠 있는 동안에도 탭은 뒤에서 그대로 돌고, ⌘T · ⌘1 같은 탭 단축키나 세션 줄을 누르면 설정 화면을 닫고 그 탭으로 갑니다.
- ⌨️ **단축키 바꾸기**: **설정 > 단축키** 에서 보드 단축키를 모두 바꿀 수 있습니다(아래 키는 모두 기본값입니다). 줄의 키를 누르고 새 키를 누르면 바로 바뀌고, 메뉴와 탭 줄 · 제목 막대의 안내 글자도 따라 바뀝니다. Esc 는 취소, ⌫ 는 그 단축키 비우기입니다. 보드의 다른 동작과 같은 키면 그 줄에 알리고 겹친 쪽을 비울 수 있고, macOS 시스템 단축키와 겹치면 알립니다. ⌘Q · ⌘W · ⌘C · ⌘V 같은 macOS 기본 키는 고를 수 없습니다. 바꾼 키는 다시 켜도 남고, **모두 기본값으로** 로 되돌립니다.
- ➕ **새 세션**: 탭 줄 끝 **+ ⌘T** 단추나 ⌘T 로 연 창에서 작업 폴더와 명령을 고릅니다(터미널이 접혀 있으면 펼칩니다). 기본 명령 `claude --dangerously-skip-permissions` 는 권한 확인을 건너뛰어 승인 대기가 거의 없습니다. 기본 명령과 답변 마크다운 꾸미기의 기본값은 **설정 > 터미널 > 새 세션** 에서 바꿉니다. 경로 카드 머리의 + 는 그 경로에서 바로 시작합니다.
- 🔚 **끝난 탭**: 보드 탭은 그 작업 경로의 로그인 셸에서 claude 를 띄웁니다. claude 가 끝나면(`/exit`) 일반 터미널처럼 셸 프롬프트로 돌아오고(↑ 로 방금 명령), 종료된 세션을 누르면 그 화면이 셸 프롬프트로 남아 있으면 그 화면에서 이어 엽니다. 셸까지 `exit` 하면 그 화면이 닫히고, 탭의 마지막 화면이면 탭이 닫힙니다.
- 🧭 **누르면**: 보드 탭 세션은 터미널을 펼쳐 그 탭의 그 화면으로(미니 화면에서도), 다른 터미널 세션은 지금처럼 그 터미널로, 백그라운드 세션은 터미널이 없다는 안내만 보입니다. 보드는 백그라운드 세션에 신호를 보내지 않습니다.
- 🚚 **보드로 옮기기**: Ghostty 세션의 ⋯ 메뉴에서 고르면 그 세션을 `/exit` 로 끝내고 보드 새 탭에서 같은 대화를 이어 엽니다.
- 🔌 **업데이트 · 종료**: 보드 탭 세션은 보드와 함께 꺼집니다. 그 가운데 일하는 중인 세션이 있으면 먼저 묻고, 보드가 다시 뜨면 탭을 되살립니다. 마지막에 보던 탭은 바로, 다른 탭은 그 탭에 들어갈 때 대화를 이어 엽니다(셸 탭에서 직접 친 claude 도). 끊긴 세션은 일시중지로 남아 ⋯ 메뉴의 **세션 재개** 로 하던 일을 이어 갑니다.
- 🎨 **답변 마크다운 꾸미기**: 보드 탭의 claude 는 답변이 끝나면 제목 · 굵게 · 인라인 코드 · 목록 등을 색으로 다시 그립니다. 새 세션 창의 **답변 마크다운 꾸미기** 체크로 끕니다.
  [deepskyblue86/claude-markdown-mod](https://github.com/deepskyblue86/claude-markdown-mod)(md-render, MIT)를 들여온 것입니다.

### 🟠 승인이 필요할 때

<p align="center"><img src="docs/images/notify-wait.png" width="440" alt="승인 대기 알림 패널"></p>

Claude 가 도구 사용 승인을 기다리면 화면 가운데에 알림 패널이 뜹니다(**설정 > 알림 > 알림 위치** 에서 네 모서리 중 하나로 바꿀 수 있습니다). 키보드 입력을 가져가지 않으므로 터미널에 쓰던 프롬프트를 그대로 이어서 쓸 수 있습니다.
패널을 누르면 보드가 열리고(보드 탭 세션이면 터미널을 펼쳐 그 탭으로), 누르지 않으면 10초 뒤 닫힙니다. 아래 줄은 지금 전체 세션의 상태별 개수입니다.

### 📐 중간 화면: 창을 줄였을 때

<p align="center"><img src="docs/images/medium.png" width="420" alt="경로마다 한 줄로 접힌 카드가 보이는 중간 화면"></p>

카드를 누르면 그 카드만 펼쳐집니다.

### 🤏 미니 화면: 화면 구석에 두고 볼 때

<p align="center"><img src="docs/images/mini.png" width="300" alt="경로마다 한 줄씩 보이는 미니 화면"></p>

창을 더 줄이거나 오른쪽 위의 최대축소 단추(↘↖)를 누르면 경로마다 한 줄(상태 · 이름 · 터미널/백그라운드 · 지금 하는 일)로 보입니다.
줄을 한 번 누르면 그 세션의 터미널 앱이, 두 번 누르면 그 세션의 터미널 창이 앞으로 옵니다(보드 탭 세션은 터미널을 펼쳐 그 탭으로). 같은 자리의 ⤢ 를 누르면 원래 크기로 돌아갑니다(터미널을 펼친 채 줄였으면 다시 펼칩니다).

### 🆕 새 버전이 나왔을 때

## 🔄 업데이트

새 버전이 나오면 보드 윗줄 아래에 알림이 뜹니다. **변경 내용** 으로 바뀐 점을 확인하고, **업데이트** 를 누르면 새 버전으로 바꿔 끼우고 보드가 다시 열립니다.
위 설치 명령을 다시 실행해도 같습니다. hook 등록은 다시 묻지 않습니다.
보드 탭에서 작업 중 · 승인 대기인 세션이 있으면 "작업 중인 세션 n개가 꺼집니다" 로 먼저 묻고, 다시 열린 보드가 그 탭들을 되살립니다. 마지막에 보던 탭은 바로 대화를 이어 열고, 다른 탭은 그 탭에 들어갈 때 이어 엽니다. 백그라운드 세션과 다른 터미널의 세션은 영향이 없습니다.

새 버전은 보드를 켤 때와 그 뒤 1시간마다 확인합니다(**설정 > 업데이트 > 자동으로 업데이트 확인** 으로 끌 수 있습니다). 바로 확인하려면 윗줄의 업데이트 확인 단추(⟳), 메뉴 막대의 **Claude Board > 업데이트 확인…**, **설정 > 업데이트** 의 **업데이트 확인** 을 누릅니다.
새 버전이 있으면 같은 알림이 뜨고, 없으면 "최신 버전입니다" 가 잠깐 보입니다.

## 🗑️ 제거

```sh
curl -fsSL https://raw.githubusercontent.com/suhojang/claude-board/main/packaging/Uninstall.command | bash
```

앱, 설치된 파일(보드가 옮겨 둔 `~/.claude/notifier/plugins/` 포함), settings.json 의 hook 과 환경변수, 자동 실행 등록, `~/.zshrc` 에 넣은 줄, 계정 전환용으로 저장한 로그인 정보를 지웁니다.
`/Applications` 의 앱을 지울 때 관리자 비밀번호를 묻습니다.

## 🛠️ 배포 (관리자)

1. [CHANGELOG.md](CHANGELOG.md) 맨 위에 새 버전 항목을 쓰고 commit · push 합니다.
2. `packaging/release.sh <버전>` 을 실행하면 앱을 빌드 · 서명하고 GitHub 릴리스를 만듭니다. 릴리스 설명은 CHANGELOG 의 그 버전 항목입니다.

서명에는 `packaging/make-cert.sh` 로 만든 개인 인증서(Claude Board Signing)가 필요합니다. 인증서를 바꾸면 사용자 Mac 에서 Ghostty 제어 권한을 다시 묻고, `install.sh` 가 설치를 거부합니다.
