# Claude Board 설치 가이드 (Windows)

Claude Board 는 Claude Code 세션 상태를 한눈에 보여 주는 보드 창과, 응답이 끝나거나 승인이 필요할 때
화면 가운데(또는 고른 모서리)에 뜨는 알림 패널을 함께 제공합니다. 이 문서는 Windows 판의 모든 기능을 자세히 설명합니다.
macOS 판은 [packaging/README.txt](../../packaging/README.txt) 를 보세요.

## 1. 설치하기 전에 알아 두실 점

### 1) 필요한 환경

- Windows 10 1809(빌드 17763) 이상 또는 Windows 11 이 필요합니다. 내장 터미널이 쓰는 ConPTY 가 1809 부터 있어, 그보다 낮은 Windows 에서는 setup.exe 와 PowerShell 설치가 시작하기 전에 안내하고 멈춥니다. x64 용으로 빌드합니다(ARM64 Windows 에서는 확인하지 않았습니다). 실제 Windows 10 PC 에서는 아직 확인하지 않았고, Windows 11 에서 흉내 낸 확인(pwsh 가 없는 PC · GPU 가 없는 화면 · 글꼴 대체 · Windows Terminal 이 없는 클래식 콘솔 · Windows PowerShell 5.1 설치)만 했습니다(미확인).
- Microsoft Edge WebView2 런타임이 필요합니다. 보드와 알림 패널이 WebView2 로 그려지기 때문입니다.
  Windows 11 과 최근 Windows 10 에는 이미 들어 있습니다. 없으면 setup.exe 는 설치 중에 받아 설치하고,
  PowerShell 설치는 "WebView2 런타임을 찾지 못했습니다" 라고 알려 줍니다. 그때는
  https://developer.microsoft.com/microsoft-edge/webview2/ 에서 Evergreen 런타임을 설치하세요.
- Claude Code 가 설치되어 있어야 합니다. 네이티브 설치(PowerShell 에서 `irm https://claude.ai/install.ps1 | iex`)를 권장합니다.
  네이티브 설치는 `%USERPROFILE%\.local\bin` 을 PATH 에 넣어 주므로, 이 폴더에 들어가는 `claude-board` · `claude-board-tui` 명령을 바로 쓸 수 있습니다.
- python 은 필요 없습니다. hook 은 실행 파일 하나(`claude-board-hook.exe`)로 동작합니다.
- 다른 터미널에서 도는 세션의 창으로 이동은 Windows Terminal 에서 가장 잘 동작합니다. 다른 콘솔(명령 프롬프트 창 · PowerShell 창)에서도
  보드와 알림은 정상 동작하고, 창으로 이동도 대부분 됩니다. 종료된 세션 이어 열기는 터미널 종류와 상관없이 보드 안의 터미널 탭에서 합니다.

### 2) 설치하면 바뀌는 것

| 위치 | 내용 |
|---|---|
| `%LOCALAPPDATA%\Programs\Claude Board\` | 앱 `ClaudeBoard.exe`, `claude-board-hook.exe`(원본), `LICENSE`, `README.md`, `THIRD_PARTY_NOTICES.txt`, 그리고 답변 마크다운 꾸미기 플러그인 파일 다섯 개(`plugins\md-render\`, 보드가 시작할 때 아래 notifier 폴더로 옮겨 씁니다). setup.exe 로 설치하면 `%LOCALAPPDATA%\Claude Board\` 에 들어가고 `uninstall.exe` 가 함께 생깁니다 |
| `%USERPROFILE%\.claude\notifier\` | macOS 판과 같은 폴더. hook 이 실행하는 `claude-board-hook.exe` 사본, `app-path`(앱 전체 경로), 세션 기록 `sessions\`, 알림 설정(`mute-all` · `notify-position`), 로그인할 때 열기를 끈 표시(`login-launch-off`), 저장한 계정(`accounts.json` · `accounts\`), 기록 파일(`update.log` · `auto-switch.log` · `board.log`), 보드가 옮겨 둔 답변 꾸미기 플러그인(`plugins\md-render\`, 다섯 파일과 Claude Code 가 그 안에 만드는 파일) |
| `%USERPROFILE%\.claude\settings.json` | Claude Code 전역 설정에 hook 11개와 환경변수 `CLAUDE_CODE_DISABLE_TERMINAL_TITLE=1` 추가 |
| `%USERPROFILE%\.local\bin\` | `claude-board.cmd`(보드 열기), `claude-board-tui.cmd`(터미널판 보드) |
| 레지스트리 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 의 `ClaudeBoard` 값 | 로그인할 때 보드를 자동 실행(`"<앱 경로>" --background`). 설정 > 일반에서 끄면 이 값을 지우고 `notifier\login-launch-off` 표시를 남깁니다 |
| `%APPDATA%\com.claude.board\` | 보드 설정(접힌 카드 · 고정한 경로 · 캐릭터 · 투명도 · 창 위치 · 터미널 펼침 여부 · 보드 폭과 위치 · 다시 켤 때 돌려놓을 탭 목록 · 답변 꾸미기를 끈 세션 · 바꾼 단축키 · 새 세션 기본 명령 · 설정 화면 전환 · 자동 업데이트 확인 등) |

- settings.json 을 바꾸기 전에 원본을 `settings.json.bak-claude-board-<날짜-시각>` 으로 백업합니다.
- 이미 쓰고 계신 다른 hook 과 설정은 그대로 유지됩니다. 여러 번 설치해도 hook 이 중복으로 등록되지 않습니다.
- hook 은 셸을 거치지 않는 형식(실행 파일 + 인자)으로 등록되어 PowerShell · cmd 설정의 영향을 받지 않습니다. 예:

  ```json
  {"type": "command", "command": "C:/Users/<사용자>/.claude/notifier/claude-board-hook.exe", "args": ["state", "working"], "timeout": 5}
  ```

  등록하는 이벤트는 SessionStart · UserPromptSubmit · PreToolUse · PostToolUse · PermissionRequest · Notification · Stop · StopFailure ·
  SessionEnd · SubagentStart · SubagentStop 11개이고, macOS 판과 같은 표시(`.claude/notifier/`)로 Claude Board hook 을 알아봅니다.
- hook 이 실행하는 사본을 `.claude\notifier\` 에 따로 두므로, 업데이트 중에도 실행 중인 Claude Code 세션의 hook 이 멈추지 않습니다.

### 3) 코드 서명과 SmartScreen

앱과 설치 프로그램에는 코드 서명이 없습니다. 그래서 setup.exe 를 처음 실행하면 SmartScreen 이 "Windows 의 PC 보호" 창을 띄우고
실행하지 않습니다. **추가 정보** 를 누른 뒤 **실행** 을 누르면 설치됩니다.

PowerShell 설치는 이 단계가 없습니다. 대신 설치 스크립트가 받은 zip 의 SHA256 을 릴리스에 함께 올린 `ClaudeBoard-windows-x64.zip.sha256` 과 맞춰 보고,
다르면 설치하지 않습니다.

### 4) 권한

- 관리자 권한은 필요 없습니다. 모든 파일과 설정이 지금 Windows 사용자 쪽에만 들어갑니다. 설치 프로그램도 관리자 권한을 묻지 않습니다.
- PowerShell 실행 정책은 `irm … | iex` 한 줄 명령에 영향을 주지 않습니다. 스크립트 파일을 내려받아 직접 실행하려면
  `powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1` 처럼 실행하세요.
  Windows PowerShell 5.1 로 내려받은 파일을 직접 실행하면 한글 안내가 깨져 보일 수 있습니다(동작은 같습니다). 한 줄 명령이나 PowerShell 7 을 쓰면 깨지지 않습니다.

### 5) 알림 패널과 키보드 입력

알림 패널은 키보드 입력을 가져가지 않고 작업 표시줄에도 나타나지 않습니다. 알림이 떠 있는 동안에도 터미널에 입력하던 프롬프트를
그대로 이어서 쓸 수 있습니다. 알림을 누르면 보드가 열리면서 닫히고, 누르지 않으면 10초 뒤 저절로 닫힙니다(마우스를 올려 두는 동안에는 멈춥니다).
알림 패널은 기본으로 화면 가운데에 뜹니다. 설정 > 알림에서 화면 그림의 자리를 눌러 왼쪽 위 · 오른쪽 위 · 왼쪽 아래 · 오른쪽 아래로
바꿀 수 있고, 모서리에서는 동시에 뜬 알림이 겹치지 않게 세로로 쌓입니다. 알림은 마우스가 있는 모니터에 뜹니다.

### 6) 터미널을 다루는 기능은 최선 노력입니다

다음 기능은 보드가 세션의 콘솔에 붙어(Windows 콘솔 API) 창을 찾거나 키 입력을 넣고, Windows Terminal 의 탭을 UI 자동화로 찾아 동작합니다.
Windows 와 Windows Terminal 의 내부 동작에 기대므로 버전 · 설정에 따라 동작하지 않을 수 있습니다.

- 다른 터미널의 세션을 더블 클릭해 그 세션의 터미널 창 · Windows Terminal 탭으로 이동
- … 메뉴의 일시중지 · 재개 · 중단(보드 탭의 세션에는 그 탭에, 다른 콘솔의 세션에는 그 콘솔에 키를 넣음), 한도 자동 전환 뒤 이어 가기 요청 넣기
- 세션 상태에 따라 터미널 제목을 "🔵 프로젝트 · 하는 일" 처럼 바꾸기

관리자 권한으로 연 터미널의 세션은 일반 권한으로 도는 보드가 다룰 수 없습니다. `claude -p` · `--bg` 처럼 터미널 없이 도는 세션(백그라운드)은 건드리지 않습니다.
보드 탭 안에서 시작한 `claude -p` 나 키를 넣을 수 없는 세션은 일시중지 · 재개가 꺼져 있고, 중단하면 그 `claude` 프로세스만 끝냅니다(탭의 셸과 대화 기록은 남습니다).
일시중지 · 재개 · 중단은 Windows 11 에서 가짜 claude 로 연결과 대상 판정까지만 확인했고, 실제 Claude Code 에서 Esc 와 `/exit` 가 먹는지는 아직 확인하지 못했습니다(미확인).

## 2. 설치 방법

### PowerShell 로 설치 (권장)

PowerShell(Windows PowerShell 5.1 또는 PowerShell 7)을 열고 아래 한 줄을 실행합니다.

```powershell
irm https://raw.githubusercontent.com/suhojang/claude-board/main/windows/packaging/install.ps1 | iex
```

1. 처음 설치라면 settings.json 에 hook 을 등록할지 묻습니다. Y(또는 Enter)를 누르면 설치합니다.
2. GitHub 릴리스 목록에서 `windows-v` 로 시작하는 최신 릴리스를 찾아 `ClaudeBoard-windows-x64.zip` 을 받고 SHA256 을 확인합니다.
3. 실행 중인 보드를 끄고 `%LOCALAPPDATA%\Programs\Claude Board\`(setup.exe 로 설치했다면 그 폴더)의 파일을 바꿔 끼웁니다. 도중에 실패하면 원래 파일로 되돌립니다.
4. `claude-board-hook.exe setup` 으로 hook 등록 · 명령 · 로그인 자동 실행을 설정합니다.
5. 보드 창이 열립니다. 이미 실행 중인 Claude Code 세션은 종료하고 다시 시작하세요. 새로 시작한 세션부터 보드에 나타나고 알림이 뜹니다.

특정 버전을 설치하려면 스크립트를 블록으로 만들어 `-Version` 을 넘깁니다.

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/suhojang/claude-board/main/windows/packaging/install.ps1))) -Version 2.12
```

### 설치 프로그램(setup.exe)으로 설치

1. 설치 프로그램 [ClaudeBoard-3.2.3-setup.exe](https://github.com/suhojang/claude-board/releases/download/windows-v3.2.3/ClaudeBoard-3.2.3-setup.exe) 를 받습니다([windows-v3.2.3 릴리스](https://github.com/suhojang/claude-board/releases/tag/windows-v3.2.3)).
   다른 버전은 [릴리스 목록](https://github.com/suhojang/claude-board/releases)에서 `windows-v` 로 시작하는 릴리스를 고르세요. **Latest** 표시가 붙은 릴리스는 macOS 판이니 헷갈리지 마세요.
2. 받은 파일을 실행합니다. SmartScreen 창이 뜨면 **추가 정보 → 실행** 을 누릅니다.
3. 설치 프로그램을 따라 설치합니다. WebView2 런타임이 없으면 이때 받아 설치합니다.
   설치가 끝나면 hook 등록 · 명령 · 로그인 자동 실행 설정까지 함께 합니다(PowerShell 설치와 달리 따로 묻지 않습니다).
4. 이미 실행 중인 Claude Code 세션은 종료하고 다시 시작하세요.

여러 PC 에 묻지 않고 설치하려면 `ClaudeBoard-3.2.3-setup.exe /S` 로 실행합니다. 설치가 끝나도 보드는 띄우지 않으니, 로그인하거나 `claude-board` 로 엽니다.

나중에 새 버전 setup.exe 로 덮어 설치해도 저장한 계정과 설정은 그대로 유지됩니다. 보드의 업데이트 단추를 써도 같은 폴더를 업데이트합니다.

## 3. 사용법

- 보드 창: 프로젝트 폴더(claude 를 띄운 폴더)별로 세션을 묶어 작업 중 · 승인 대기 · 대기 · 일시중지 · 종료 상태를 보여 줍니다.
  Claude 가 하위 폴더로 cd 하거나 워크트리에 들어가도 세션은 같은 카드에 남습니다. 끝난 세션을 다시 열 때도 그 프로젝트 폴더에서 엽니다.
- 트레이 아이콘(작업 표시줄 알림 영역): 왼쪽 클릭으로 보드 창을 열고 닫습니다. 마우스를 올리면 승인 대기 · 작업 중 세션 수가 보이고,
  승인 대기가 있으면 주황 점, 작업 중만 있으면 파란 점이 아이콘에 붙습니다.
  오른쪽 클릭 메뉴: 세션 보드 보기 · 터미널 펼치기 (지금 단축키) · 항상 위에 고정 · 설정… · 업데이트 확인… · 종료. 캐릭터 · 알림 위치 · 보드 위치는 설정 화면에서 고릅니다.
  아이콘이 보이지 않으면 작업 표시줄의 ^(숨겨진 아이콘 표시)를 누르거나, 설정 > 개인 설정 > 작업 표시줄 에서 항상 보이게 할 수 있습니다.
- 보드의 닫기 단추는 창만 숨기고 앱은 트레이에 남습니다. 완전히 끄려면 트레이 메뉴의 종료를 누릅니다.
- 로그인할 때 보드가 저절로 실행됩니다. 보드가 숨어 있을 때 Windows Terminal 을 새로 열면 보드가 다시 보입니다(포커스는 터미널에 그대로).
- 어느 앱에서든 Ctrl+Alt+B: 터미널을 접고 보드를 처음 크기로 화면 가장자리(보드 위치가 기본이면 오른쪽)에 붙여 앞으로 가져옵니다(키보드 포커스는 가져가지 않습니다). 키는 설정 > 단축키에서 바꿀 수 있습니다.
  다른 앱이 이 단축키를 이미 쓰고 있으면 등록되지 않고 `board.log` 에 기록만 남습니다.
- 어느 앱에서든 Ctrl+Alt+T: 내장 터미널을 펼치거나 접습니다. 접혀 있으면 펼치면서 터미널에 포커스를 줍니다.
  펼쳐져 있고 보드가 맨 앞이면 접고, 펼쳐져 있지만 다른 앱에 가려져 있으면 앞으로 가져와 터미널에 포커스를 줍니다.
  · 이 단축키는 JetBrains IDE 등 다른 앱의 같은 단축키와 겹칩니다. 보드가 켜져 있는 동안은 보드가 가져가고, 다른 앱이 먼저 쓰고 있으면 등록되지 않고 `board.log` 에 기록만 남습니다(제목 막대 단추와 트레이 메뉴로는 계속 쓸 수 있습니다).
  · AltGr 로 문자를 치는 키보드 배열에서는 Ctrl+Alt 조합이 그 글자와 겹쳐 입력이 막힐 수 있습니다.
  · 한국어 키보드에서는 왼쪽 Ctrl+Alt 로 누르세요.
- 설정 화면: **Ctrl+,**(보드가 앞에 있을 때) 또는 트레이 **설정…**(계정 칩 메뉴의 **계정 추가…** 도 계정 묶음으로 엽니다)을 누르면 보드는 그대로 두고 터미널 자리가 설정 화면으로 바뀝니다.

    이름에 특수문자가 있으면 큰따옴표로 묶어 칩니다(PowerShell 에서만 확인했고 cmd.exe 는 미확인). Claude Code 를 `/exit` 로 끝내면 같은 탭이 셸 프롬프트로 돌아오고, 셸을 끝내면 탭이 닫힙니다.
  · 이름 바꾸기: Ctrl+Shift+R. 이름 자리가 입력 칸이 되고 Enter 로 저장, Esc 로 취소하며 칸을 벗어나도 저장됩니다. 비우거나 폴더 이름과 같게 하면 폴더 이름으로 돌아갑니다.
    그 탭에서 도는 대화형 Claude Code 에는 `/rename <이름>` 도 보냅니다. 승인 창이나 질문 창이 떠 있으면 닫힐 때까지 기다리고, 대화 기록이 아직 없으면 보내지 않으며, 보낸 뒤 5초가 지나면 그 세션의 이름 바꾸기를 끝냅니다. 겹치는 이름에는 `-2`, `-3` 이 붙습니다.
  · 세션 연결 칩: 세션 줄의 칩이 그 세션이 어디서 도는지 알려 줍니다. `CB` 는 보드 탭(탭 안에서 시작한 `claude -p` 는 `CB -p`, 마우스를 올리면 "탭이 닫히면 함께 끝납니다"), 앱 이름(Windows Terminal · VS Code · Git Bash 등, 모르면 `터미널`)은 보드 밖의 터미널,
    `$ claude --bg` 는 터미널 없이 도는 세션(카드 안에서 따로 묶임), "보드에서 이어 열기" 는 끝난 세션입니다. 보드 탭의 판단은 세션 프로세스가 그 탭의 콘솔을 쓰는지로 하며 3초마다 새로 읽습니다. 그래서 탭에서 손으로 친 `claude` 는 최대 3초 뒤에 연결됩니다.
    탭 화면에 남은 세션 id 만으로는 보드 탭 세션으로 보지 않습니다. 그 탭에서 `claude` 가 도는 중이거나 3초 안에 `claude` 명령을 쳤을 때만 탭의 세션으로 보고, 그 밖(다른 터미널에서 이어 연 세션 등)은 세션이 도는 곳을 보여 줍니다.
    `/clear` 로 세션 id 가 바뀌어도 같은 콘솔이면 같은 탭에 따라옵니다. 한 콘솔에 세션이 여럿이면 마지막으로 움직인 세션이 그 탭의 세션입니다.
  · 크기 바꾸기: 창이나 경계를 끌어 크기를 바꾸면 보드는 터미널이 화면을 다시 그리기 시작하는 자리에서만 크기를 바꿔 줄이 덜 깨지게 합니다. 크기 변경은 끌기가 멈춘 뒤 200ms 에 한 번 적용됩니다(경계는 놓을 때).
    합성 출력으로 잰 결과 열을 줄이거나 행을 늘리는 크기 변경은 깨짐이 없었고(5개 중 0), 행을 줄이거나 경계를 끌어 열을 줄이면 줄 하나가 깨질 수 있습니다. 실제 Claude Code 화면과 다른 Windows 빌드는 측정하지 않았습니다.
  · 안내 줄: 터미널 없이 도는 세션을 누르는 것처럼 보드가 한 줄로 알릴 일이 있으면 창 아래 가운데에 6초 동안 뜹니다. 누르면 바로 닫힙니다.
  · 닫기: 탭의 ×. 그 탭에서 도는 세션이 아직 끝나지 않았으면 "탭을 닫을까요?" 로 묻고(닫기 · 취소 Esc), 셸만 있는 탭은 바로 닫힙니다. 닫으면 같은 경로의 이웃 탭, 없으면 이웃 경로, 없으면 빈 상태로 갑니다.
  · 터미널이 펼쳐진 동안 쓰는 키: **Ctrl+T** 새 세션 · **Ctrl+Shift+R** 이름 바꾸기 · **Ctrl+Alt+1~9** 지금 경로의 n 번째 탭 · **Ctrl+Alt+← →** 이전/다음 탭 · **Ctrl+Alt+↑ ↓** 이전/다음 경로 · **Ctrl+Alt+T** 접기/펼치기.
    Ctrl+Alt 를 누르고 있으면 탭에 번호 배지가 나타납니다. Ctrl+T 와 Ctrl+Shift+R 은 보드가 먼저 가져가므로 터미널 안의 셸에는 전달되지 않습니다. 이 키들은 기본 키이며 설정 > 단축키에서 바꿀 수 있습니다.
  · 제목 띠: 터미널 단추(캡슐, "터미널 펼침/접힘  Ctrl+Alt+T")가 앞쪽 가장자리에 있고 미니 화면에서는 보이지 않습니다.
  · 보드 위치: 설정 > 창 > **보드 위치** 에서 오른쪽(기본) 또는 왼쪽을 고릅니다. 접기 · 최대축소 · Ctrl+Alt+B 가 고른 쪽 기준으로 동작합니다.
  · 접어 두는 동안에도 터미널 출력은 쌓이고, 다시 펼치면 이어서 보입니다. 보드를 끄면 터미널의 셸도 끊깁니다(탭 목록은 아래 대로 다시 켤 때 돌아옵니다).
  · 탭 저장과 복원: 탭이 바뀔 때마다 탭 목록(경로 · 탭 이름 · 세션 · 고른 탭)을 기억합니다. 보드를 다시 켜면 탭이 돌아오고, 고른 탭의 `claude` 는 곧바로 `claude --resume <세션 id>` 로 이어 엽니다. 나머지 탭은 그 탭을 누를 때 이어 열고, 그 전에는 셸도 아직 뜨지 않은 상태입니다.
    이어 열 때 처음 실행에 쓴 옵션 가운데 허용된 글자로 된 것(`--model`·`--dangerously-skip-permissions` 등)이 따라옵니다. 이어 열 순간에 그 세션이 보드 밖에서 이미 도는 중이면 셸로만 둡니다. 보드를 다시 켠 직후 앞 보드의 `claude` 가 아직 끝나는 중이면 최대 5초 기다리고, 그래도 살아 있으면 그 탭은 되살리지 않습니다.
    저장해 둔 작업 폴더가 지금 없으면 그 탭은 되살리지 않고 `board.log` 에 `탭을 되살리지 않음: 작업 경로가 없습니다 <경로>` 를 남깁니다. 폴더가 없으면 셸이 홈 폴더로 떠서, 권한 확인을 건너뛰는 `claude` 가 홈 폴더 전체를 열게 되기 때문입니다. `claude` 가 끝나 셸만 남은 탭은 셸로 돌아옵니다.
    화면을 새로 고치면(개발용) 도는 터미널을 이어받되 저장해 둔 목록은 덮어쓰지 않습니다. 이때 한 번도 들어가 본 적 없는 복원된 탭은 다음에 보드를 켤 때까지 화면에서 사라집니다(미확인 한계).
  · 보드를 끌 때 확인: 트레이 **종료** 를 누르면, 보드 탭에서 도는 세션이 있을 때 "작업 중인 세션 n개가 꺼집니다" 창이 뜹니다. 목록에는 작업 중 · 승인 대기 · 서브에이전트가 도는 세션 · 셸에서 백그라운드 작업이 도는 세션 · 탭 안의 `claude -p` · `claude` 가 아닌 프로그램이 도는 셸이 줄로 나옵니다. 쉬는 세션과 백그라운드 세션 · 다른 터미널의 세션은 목록에 없습니다. 목록이 비면 묻지 않고 바로 끕니다.
    **종료** 를 고르면 끊기는 대화형 세션에 일시중지 표지가 남고(탭 안의 `claude -p` 는 입력 자리가 없어 남기지 않습니다), 다시 켠 뒤 그 세션 줄의 **세션 재개** 로 이어 갈 수 있습니다. **취소 (Esc)** 를 고르면 보드는 그대로 남습니다. 처음 포커스는 취소에 있습니다.
    창이 떠 있는 동안 트레이 **종료** 를 또 누르면 숨은 보드도 보이면서 창이 다시 뜹니다. 창이 떠 있는 동안 화면이 새로 고쳐지면 확인을 취소합니다. 15분 동안 고르지 않으면 취소하고 보드는 그대로 둡니다. 화면이 10초 안에 아무 반응이 없으면(화면이 멎은 경우) 그대로 끕니다. 보드 업데이트도 업데이트할 것이 있고 도는 세션이 있을 때만 같은 창으로 묻고, 업데이트가 끝내 실패하면 남긴 표지를 지웁니다.
  · 답변 마크다운 꾸미기(md-render): 보드가 시작할 때 설치 폴더의 플러그인 다섯 파일을 `%USERPROFILE%\.claude\notifier\plugins\md-render\` 로 옮겨 둡니다(내용이 바뀐 파일만, 링크이면 거절). Claude Code 가 플러그인 폴더에 파일을 쓰고 업데이트가 설치 폴더를 바꿔 끼워도 경로가 유지되기 때문입니다.
    보드 탭에서 띄우는 `claude` 에 `--plugin-dir "<그 폴더>"` 가 하나 붙습니다. 옮기지 못하면(파일이 잠겼을 때 등) `board.log` 에 이유를 남기고 붙이지 않습니다. 보드는 시작할 때 한 번 옮기므로 다시 시도는 다음에 보드를 켤 때 됩니다. 실제 Claude Code 가 답변을 다시 그리는 것은 확인하지 못했습니다(미확인).
  · 한글은 조합 중에 누른 Enter · Esc · 방향키가 조합이 끝난 다음에 전달됩니다. Shift+Enter 는 줄바꿈을 보냅니다. Ctrl+C 는 글자를 골라 둔 때만 복사이고, 아니면 터미널로 전달됩니다.
- 세션 줄 클릭은 세션이 도는 곳에 따라 다릅니다.
  · 보드 탭의 세션: 한 번이든 더블이든 그 탭을 골라 보드를 앞으로 가져옵니다.
  · 다른 터미널의 세션: 한 번 클릭은 그 터미널 앱 창을 앞으로 가져오고(모르면 Windows Terminal), 더블 클릭은 그 세션의 창으로 이동합니다. Windows Terminal 이면 그 세션의 탭을 고릅니다(최선 노력).
    한 번 클릭은 Windows 의 더블 클릭 시간(기본 500ms)만큼 기다린 뒤 동작하고, 그 안에 둘째 클릭이 오면 더블 클릭 동작만 합니다.
  · 터미널 없이 도는 세션(`claude -p` · `--bg`): 안내가 6초 동안 뜹니다("…로 실행된 세션이라 터미널이 없습니다. 보드에서는 상태만 보여 주고, 업데이트·종료에도 영향받지 않습니다."). 이 줄에는 … 메뉴가 없습니다.
  · 종료된 세션: 누르면 보드 탭에서 `claude --resume <세션 id>` 로 대화를 이어 엽니다. 같은 폴더의 탭 가운데 셸이 프롬프트에 있고 `claude` 가 없는 탭이 있으면 거기에 치고, 없으면 새 탭을 엽니다. 이미 이어 여는 중이거나 탭에 있으면 그 탭을 앞으로 가져올 뿐 다시 열지 않습니다.
    처음 실행할 때 쓴 옵션과 마지막 권한 모드 · 모델도 함께 적용됩니다. 단 허용된 글자(영문 · 숫자 · `._:=/@+-`)로 된 옵션만 따라오고, 하나라도 다른 글자가 있으면 옵션을 모두 버리고 `claude --resume <id>` 만 칩니다(셸이 값을 명령으로 읽지 않게 하려는 것).
    `claude -p` 였던 세션은 대화형으로 엽니다. 이어 열 수 없으면 "세션을 이어 열 수 없습니다" 가 뜹니다.
  · 터미널이 접혀 있으면 이어 열기를 위해 펼칩니다.
- 세션 줄의 … 메뉴
  · 일시중지: 그 세션에 Esc 를 넣어 지금 작업을 멈추고 보드에 일시중지(⏸)로 표시합니다. 작업 중이거나 승인 대기인 세션에서만, 그리고 키를 넣을 곳이 있을 때만 켜집니다(쉬는 세션이나 입력을 넣을 수 없는 세션에서는 꺼짐). 키가 들어간 뒤에만 일시중지로 표시됩니다.
  · 재개: 세션이 살아 있으면(끝나지 않았고 프로세스가 살아 있거나 pid 를 모르는 세션) 그 세션 터미널에 "보드에서 일시중지했던 세션을 재개합니다…" 요청을 넣습니다. pid 를 모르는 세션은 살아 있는 것으로 보고, 키 넣기가 실패해도 새 탭으로 이어 열지 않습니다(같은 claude 가 중복으로 뜨므로). 키를 넣지 못하면 "<폴더 이름>: 세션이 아직 돌고 있지만 그 터미널에 키를 넣지 못했습니다. 그 터미널에서 이어 가 주세요" 를 알립니다. 끝났거나 프로세스가 죽은 세션은 보드 탭에서 이어 열면서 같은 요청을 붙입니다.
  · 중단: 한 번 더 확인한 뒤 Esc 와 `/exit` 를 넣어 세션을 끝냅니다. 확인 창이 떠 있는 동안 세션이 끝났거나 다른 프로세스로 바뀌었으면 아무것도 하지 않습니다. 입력을 넣을 수 없는 세션은 그 `claude` 프로세스만 끝냅니다(탭의 셸과 대화 기록은 남습니다).
  · 보드로 옮기기(다른 터미널의 세션이고 키를 넣을 수 있을 때만): 그 콘솔에 Esc, 0.4초, `/exit`, 0.2초, Enter 를 넣어 세션을 끝내고, 8초 안에 끝나면 보드 새 탭에서 `claude --resume <세션 id>` 로 같은 대화를 이어 엽니다. 작업 중이거나 승인을 기다리는 세션은 먼저 "보드로 옮길까요?" 로 묻습니다(터미널이 접혀 있으면 펼쳐 보이고, 취소하면 다시 접습니다).
    키를 넣을 곳을 찾지 못하거나 8초 안에 끝나지 않으면 알림이 뜨고 옮기지 않습니다. 같은 세션을 옮기는 중에 또 누르면 키를 다시 보내지 않습니다. 입력 칸에 쓰다 만 글이 있으면 `/exit` 가 이어 붙어 질문으로 전송될 수 있습니다(macOS 판과 같습니다).
  · 종료된 세션: 세션 다시 열기 / 재개.
- 알림 패널을 누르면 그 세션으로 갑니다. 보드 탭의 세션은 그 탭을 고르고, 다른 터미널의 세션은 그 창(Windows Terminal 이면 그 탭)을 앞으로 가져오며, 보드가 숨어 있어도 보이게 합니다(포커스는 가져가지 않습니다). 세션을 찾지 못하면 보드만 보입니다. 세션 없는 알림도 보드만 보입니다.
- 터미널에서 `ClaudeBoard.exe --action <동작> <세션 id>` 로 실행 중인 보드에 같은 동작을 시킬 수 있습니다. 동작은 `pause` · `resume` · `stop`(확인 없이) · `reopen` · `focus` · `activate` 입니다. 보드가 막 켜지는 중에 보낸 `reopen` · `focus` 는 보드가 준비된 뒤에 처리됩니다.
- 종료된 세션 오른쪽의 ⓧ: 목록에서 지웁니다. 종료된 지 2일이 지나면 자동으로 지워집니다.
- 질문 없이 끝난 세션은 대화 기록이 없어 이어 열 수 없으므로 목록에 나타나지 않습니다.
- 세션 줄과 하위 작업(서브에이전트) 줄에 모델 · effort 라벨이 붙습니다. 색은 모델 계열(Opus 주황 · Sonnet 파랑 · Haiku 민트 · Fable 보라),
  뒤의 막대 5칸은 effort 단계(low 1칸 ~ max 5칸)입니다. 마우스를 올리면 정확한 모델 ID 와 effort 가 보입니다.
  값은 마지막 응답 기록에서 읽으므로, /effort 로 바꾼 뒤에는 다음 응답부터 바뀝니다.
- 세션 이름 라벨: 세션 줄에 태그 아이콘과 함께 Claude Code 세션 이름(`/rename` 이나 `--name` 으로 정한 이름)이 보입니다.
  24자를 넘으면 앞 11자와 뒤 11자만 보이고, 마우스를 올리면 "세션 이름 <이름>" 으로 전체가 나옵니다. 보드 칸이 좁아 줄어드는 세 번째 단계부터는 빠지고, 종료된 세션에는 붙지 않습니다.
- Esc 로 끊은 세션: 응답 중에 Esc 로 끊으면 Claude Code 가 완료 신호를 보내지 않지만, 보드 · 터미널판 보드 · 알림 패널의 상태별 개수는 그 세션을 바로 대기로 보여 줍니다(응답을 시작하기 전에 끊어도 같습니다).
  대기 시간은 끊은 때부터 셉니다. 승인을 처리한 뒤 도구가 도는 동안에는 승인 대기가 아니라 작업 중으로 보입니다. 이 판단은 Claude Code 가 남기는 대화 기록과 `%USERPROFILE%\.claude\sessions\` 의 세션 정보를 읽어서 하므로,
  Claude Code 가 그 형식을 바꾸면 예전처럼 작업 중으로 남을 수 있습니다.
- 컨텍스트 라벨: 그 세션이 컨텍스트 창을 얼마나 썼는지 보여 줍니다(30% 미만 초록, 70% 미만 노랑, 그 밖 빨강).
- 위쪽 상태 칩(승인 대기 · 작업 중 · 대기 개수): 누르면 그 상태 세션만 보입니다. 같은 칩을 다시 누르면 모두 보입니다.
- 알림 끄기: 세션 줄의 종 토글은 그 세션만, 윗줄의 종 단추는 전체 알림을 끕니다. 전체가 꺼져 있으면 붉은 "알림 꺼짐" 이 보입니다.
- 경로 카드: 별(☆)로 맨 위에 고정하고, X 로 목록에서 지웁니다(새 활동이 생기면 다시 나타납니다). 오른쪽 클릭 메뉴도 있습니다.
- 경로가 많아 아래로 가려진 카드가 있으면 목록 아래에 "아래에 경로 N개 더" 가 뜹니다. 누르면 그 카드로 내려갑니다.
- 승인 대기 · 작업 중 세션이 없고 30분 넘게 조용한 경로 카드는 자동으로 접힙니다. 다시 펼친 카드는 새 활동이 생기기 전까지 그대로 둡니다.
- 접힌 경로 카드에서도 진행 상황이 보입니다. 작업 중이면 폴더 아이콘 자리에 도는 링이, 승인 대기면 퍼지는 파문이 나오고,
  경로 대신 지금 하는 일(승인 대기면 승인 요청 내용)이 상태 색으로 나옵니다. 여러 세션이 돌고 있으면 뒤에 +1 처럼 나머지 개수가 붙습니다.
- 터미널 없이 도는 세션(백그라운드)은 카드 안에서 따로 묶입니다. 구역 머리글을 눌러 접고 펼 수 있습니다.
- 제목(Claude Board) 옆에 보드 버전이, 그 아래 활성 세션 수 옆에 설치된 Claude Code 버전이 있습니다.
- 캐릭터: 오른쪽 위 캐릭터가 세션 상태를 말풍선으로 알려 줍니다. 누르면 다음 말로 넘어갑니다.
  브레인롯 7종(트랄랄레로 트랄랄라 · 봄바르디로 크로코딜로 · 퉁 퉁 퉁 사후르 · 리릴리 라릴라 · 브르르 브르르 파타핌 · 보네카 암발라부 · 카푸치노 아사시노)과
  현장 감독 중에서 고릅니다(기본은 트랄랄레로 트랄랄라). 캐릭터를 오른쪽 클릭하거나 설정 > 일반에서 고르고, 고른 캐릭터는 다시 실행해도 유지됩니다.
  작업 중이면 바쁘게, 승인 대기면 재촉하며("!"), 쉬는 중이면 졸며("z") 움직이고, 승인 대기가 없을 때는 유행어를 한 번씩 섞습니다.
- 오른쪽 아래 독: 창 오른쪽 아래 끝의 탭에 마우스를 대면 Windows Terminal · PowerShell 7 · Windows PowerShell · 명령 프롬프트 · Git Bash 단추가
  세로로 나타납니다. 마우스를 올리면 무엇을 여는지 보이고, 설치되지 않은 것은 흐리게 표시되어 눌리지 않습니다. 실행 중인 앱에는 점이 붙습니다.
- 사용 한도 카드: 5시간 · 주간(전체) · 주간(모델별) 사용량을 보여 줍니다. 오른쪽 위 단추로 상세(한도마다 막대와 초기화 시각)와
  간략(한 줄) 모드를 바꿉니다. 간략 모드에서 각 한도에 마우스를 올리면 초기화 시각이 보입니다. 사용량은 30초마다 다시 읽습니다.
- 윗줄의 모두 접기 · 펼치기 단추: 모두 접기는 경로 카드를 모두 접고 사용 한도를 간략 모드로, 모두 펼치기는 카드를 모두 펴고 상세 모드로 바꿉니다.
  (중간 화면에서는 이 단추가 숨겨집니다.)
- 창 크기에 따라 화면이 세 단계로 바뀝니다.
  · 전체: 기본 화면입니다.
  · 중간: 창이 낮아지면 사용 한도가 한 줄로, 경로 카드가 접힌 한 줄 요약으로 바뀝니다. 카드를 누르면 그 카드만 펼쳐집니다.
  · 미니: 창이 더 작아지거나 폭이 좁아지면 경로마다 한 줄(상태 아이콘 · 이름 · 터미널/백그라운드 아이콘 · 지금 하는 일)로 보입니다.
    맨 위에 캐릭터와 한 줄 말풍선이, 제목 막대 오른쪽에 상태별 세션 수와 ⤢(원래 크기로) 단추가, 아래 줄에 사용 한도와 투명도 슬라이더가 있습니다.
    줄을 한 번 누르면 그 세션의 터미널 앱이, 두 번 누르면 그 세션의 터미널 창이 앞으로 옵니다.
- 제목 막대 오른쪽 위의 최대축소 단추(↘↖): 창을 보드 쪽(기본 오른쪽) 위 모서리 기준으로 가장 작게(가로 300, 세로는 경로 수에 맞춰 최대 6줄) 줄여 미니 화면으로 바꿉니다.
  미니 화면에서는 같은 자리의 ⤢ 를 누르면 줄이기 전 위치와 크기로 돌아갑니다. Ctrl+Alt+B 로도 원래 화면으로 돌아옵니다.
- 항상 위에 고정(기본 켜짐): 윗줄의 고정 단추, 트레이 메뉴, 설정 > 일반에서 바꿉니다. 터미널을 펼쳐 창이 작업 영역 전체를 덮는 동안만 고정이 쉽니다. 접힌 창이나 줄여 놓은 펼친 창은 고정을 따릅니다. 창 크기를 바꾼 뒤 0.7초 넘게 멎으면 다시 정합니다.
- 투명 모드: 창 오른쪽 아래 슬라이더로 창 전체의 투명도를 정합니다(왼쪽으로 갈수록 투명, 최소 30%).
  마우스가 보드 밖에 있으면 보드가 앞에 있어도 그 투명도로 보이고, 마우스를 보드 위로 올리면 불투명해집니다(포커스는 상관없습니다). 작업 영역 전체를 덮은 창은 마우스가 밖이어도 불투명합니다. 슬라이더를 움직이는 동안과 놓은 뒤 1.2초는 늘 슬라이더 값으로 보입니다.
  마우스 위치는 마우스가 움직일 때만 읽으므로, 창이 가만히 있는 마우스 밑에서 움직이면 한동안 이전 값으로 남을 수 있습니다(미확인 한계).
- 계정 전환: 사용 한도 카드 왼쪽 위의 계정(이메일 · 요금제)을 누르면 메뉴가 열립니다.
  · 계정 추가… : 설정 > 계정이 열리고 로그인이 시작됩니다. 보드가 띄운 로그인 창에서 추가할 계정으로 로그인하면 보드에 저장됩니다(자세한 절차는 위 설정 화면의 설정 안 계정 추가).
    지금 쓰는 로그인은 바뀌지 않으므로 작업 중에도 미리 추가해 둘 수 있습니다. 진행 중이면 이 메뉴에 **계정 추가 계속** 과 **계정 추가 취소** 가 뜹니다.
  · 저장한 계정을 고르면 모든 Claude Code 세션이 그 계정으로 바뀝니다. 실행 중인 세션은 다시 시작할 필요 없이 다음 요청부터(30초 안에) 새 계정으로 이어 갑니다.
    작업 중이거나 승인을 기다리는 세션이 있으면 전환할지 한 번 더 묻습니다. 지금 받고 있는 응답은 이전 계정으로 마무리됩니다.
    지금 Claude Code 로 로그인된 계정의 정보를 읽지 못하면 전환하지 않고 "전환하지 못했습니다: 지금 로그인된 계정의 정보가 없어 그 계정을 먼저 저장할 수 없습니다(그대로 바꾸면 그 로그인을 잃습니다). Claude Code 에서 /login 으로 다시 로그인한 뒤 해 주세요" 같은 안내를 보여 줍니다(모자라면 그 뜻으로 나옵니다). /login 으로 다시 로그인한 뒤 다시 고르세요.
  · 저장한 로그인 토큰은 `%USERPROFILE%\.claude\notifier\accounts\vault\` 에 DPAPI 로 암호화해 둡니다. 이 PC 의 이 Windows 사용자만 풀 수 있습니다.
    `accounts.json` 에는 이메일 · 조직 같은 표시용 정보만 남습니다. MCP 서버 로그인은 계정을 바꿔도 그대로 유지됩니다.
    `accounts.json` 이 깨져 읽지 못하면 `accounts.json.broken-<날짜-시각>` 으로 옆으로 옮겨 둔 뒤 새 목록을 씁니다(같은 이름이 이미 있으면 뒤에 `-2`, `-3` 을 더합니다). 옮기다 실패하면 목록을 그대로 두고 저장하지 않습니다.
  · 마지막으로 쓴 지 약 4주가 지난 계정은 로그인이 만료되어 메뉴에 "다시 로그인 필요" 로 표시됩니다. 고르면 다시 로그인합니다.
  · 저장한 계정 지우기: 메뉴 아래쪽 "저장한 계정 지우기" 하위 메뉴에서 계정을 고르면 그 계정을 지웁니다(지금 계정은 나오지 않습니다). 지우고 나면 "<이메일> 계정을 목록에서 지웠습니다" 로 알립니다. 로그인 정보를 지우지 못하면 "저장한 로그인 정보를 지우지 못해 목록에 그대로 두었습니다. 잠시 뒤 다시 지워 주세요" 와 함께 계정을 그대로 두고, 로그인 정보는 지웠지만 목록(accounts.json)을 갱신하지 못하면 그 뜻이 든 안내가 뜹니다(목록도 원래대로 둡니다).
  · Claude Code 에서 /logout 하면 그 계정의 로그인이 서버에서 취소되어, 보드에 저장한 그 계정도 다시 추가해야 합니다.
    계정을 바꿀 때는 /login · /logout 대신 보드의 계정 메뉴를 쓰세요.
  · CLAUDE_CONFIG_DIR 을 따로 정해 띄운 세션은 별도의 로그인을 쓰므로 전환되지 않습니다.
  · 한도 자동 전환(기본 꺼짐): 계정 메뉴 맨 아래 "한도가 차면 다른 계정으로 자동 전환" 을 켜면, 지금 계정의 5시간 · 주간(전체) 한도가 차거나
    세션이 한도에 걸려 멈출 때 저장한 다른 계정으로 바꿉니다. 켜져 있으면 계정 칩에 ⇅ 가 붙습니다.
    실행 중인 세션이 새 계정을 쓰기까지 최대 30초가 걸리므로, 전환하고 40초 뒤 한도로 멈췄던 세션에 이어서 진행하라는 요청을 넣습니다
    (콘솔에 입력을 넣을 수 있는 세션만. 그 밖의 세션은 직접 이어 주세요).
    다른 계정의 남은 한도는 미리 알 수 없어, 그 계정을 쓰다 5시간 · 주간(전체) 한도가 찼던 기록(풀리는 시각까지)으로 건너뜁니다(모델별 주간 한도는 이 기록에 넣지 않습니다).
    전환할 계정이 없으면 알리고 기다립니다. 지금 계정의 로그인 정보를 읽지 못해 전환할 수 없으면, Claude Code 에서 /login 으로 다시 로그인하라는 안내를 한 번 보여 주고 기다립니다.
    바꾸려다 실패하면 까닭에 따라 다릅니다. Claude Code 가 로그인 정보를 쓰는 중이면 알리지 않고 30초 뒤 다시 시도하고,
    바꿀 계정 쪽 문제면 그 계정만 1시간 동안 건너뛴 뒤 다른 계정을 찾고,
    그 밖(지금 계정의 로그인 정보를 읽지 못하는 등)은 "사용 한도에 도달해 <이메일> 계정으로 자동 전환하려 했지만 하지 못했습니다: <까닭>. 계정이 바뀌거나 1시간이 지날 때까지 자동 전환을 쉽니다" 로 알리고 1시간 동안 쉽니다.
    전환 · 이어 가기 기록은 `%USERPROFILE%\.claude\notifier\auto-switch.log` 에 남습니다.
- 터미널에서 `claude-board` 를 실행하면 보드 창을, `claude-board-tui` 를 실행하면 터미널판 보드를 엽니다.
  터미널판 보드는 q 로 끝내고 t 로 색 테마(4종)를 바꿉니다.
  (`%USERPROFILE%\.local\bin` 이 PATH 에 없으면 전체 경로로 실행하세요.)

## 4. 업데이트와 제거

### 업데이트

- 새 버전이 나오면 보드 윗줄 아래에 "새 버전 <버전> 이 나왔습니다" 가 뜹니다(미니 화면에서는 보이지 않습니다).
  **변경 내용** 을 누르면 브라우저에서 Windows 판 변경 내역(GitHub 의 `windows/CHANGELOG.md`)이 열립니다.
  **업데이트** 를 누르면 새 버전을 받아 바꿔 끼우고 보드가 다시 열립니다. hook 등록은 다시 묻지 않습니다.
  실패하면 보드는 그대로 두고 다시 시도 단추를 보이며, 기록은 `%USERPROFILE%\.claude\notifier\update.log` 에 남습니다.
- 새 버전은 보드를 켤 때와 그 뒤 1시간마다 확인합니다(설정 > 업데이트의 **자동으로 업데이트 확인** 을 끄면 하지 않습니다). 바로 확인하려면 윗줄의 업데이트 확인 단추(⟳)나 트레이 메뉴의 업데이트 확인… 을 누릅니다.
  새 버전이 없으면 "최신 버전입니다" 가 잠깐 보입니다.
- PowerShell 설치 명령을 다시 실행해도 같습니다.
- 업데이트는 GitHub 릴리스 목록에서 `windows-v` 로 시작하는 릴리스만 봅니다. macOS 판 릴리스와 섞이지 않습니다.

### 제거

PowerShell 에서 아래 한 줄을 실행합니다.

```powershell
irm https://raw.githubusercontent.com/suhojang/claude-board/main/windows/packaging/uninstall.ps1 | iex
```

- settings.json 의 Claude Board hook 과 환경변수(지우기 전에 백업), 로그인 자동 실행, `claude-board` · `claude-board-tui` 명령,
  `.claude\notifier\` 의 hook 실행 파일 · 세션 기록 · 알림 설정, 보드가 옮겨 둔 답변 꾸미기 플러그인(`plugins\` 폴더 전체, 그 안의 링크는 따라가지 않고 링크만 뗍니다), 계정 전환용으로 저장해 둔 로그인 정보(`accounts.json` · `accounts\`, 깨진 목록 백업 `accounts.json.broken-*` 도)를 지웁니다.
  지금 Claude Code 로그인(`%USERPROFILE%\.claude\.credentials.json`)은 그대로 둡니다.
- 실행 중인 보드를 끄고 앱 폴더를 지웁니다. setup.exe 로 설치했다면 그 제거 프로그램도 돌려 설정 > 앱 목록에서 뺍니다.
- setup.exe 로 설치했다면 **설정 > 앱 > 설치된 앱** 에서 Claude Board 를 제거해도 같습니다.
- 보드 설정(`%APPDATA%\com.claude.board\`)과 기록 파일(`update.log` 등)은 남습니다. 필요 없으면 직접 지우세요.
- 제거한 뒤에는 실행 중인 Claude Code 세션을 다시 시작하세요.

## 5. 문제가 생겼을 때

- 알림이 뜨지 않음: Claude Code 세션을 다시 시작했는지 확인하세요. `%USERPROFILE%\.claude\settings.json` 에 `.claude/notifier/` 가 들어간 hook 이 있는지,
  `%USERPROFILE%\.claude\notifier\claude-board-hook.exe` 와 `app-path` 가 있는지, `app-path` 에 적힌 경로에 `ClaudeBoard.exe` 가 있는지도 확인하세요.
  보드에서 전체 알림이나 그 세션의 알림을 꺼 두지 않았는지도 보세요.
- 보드에 세션이 나타나지 않음: 설치 뒤에 새로 시작한 세션인지 확인하세요. 요청을 보내면 `%USERPROFILE%\.claude\notifier\sessions\` 에 세션 파일이 생깁니다.
- Ctrl+Alt+T 가 동작하지 않음: 다른 앱(JetBrains IDE 등)이 같은 단축키를 먼저 쓰고 있으면 보드가 등록하지 못하고 `board.log` 에만 기록합니다. 그 앱의 단축키를 바꾸거나, 설정 > 단축키에서 보드 쪽 키를 바꾸거나(등록하지 못한 키는 그 줄에 표시됩니다), 제목 막대 단추 · 트레이 메뉴로 펼치세요.
  한국어 키보드에서는 오른쪽이 아니라 왼쪽 Ctrl+Alt 로 눌러야 합니다.
- 보드 창이 뜨지 않음: WebView2 런타임이 설치되어 있는지 확인하세요. 트레이에 아이콘만 있고 창이 숨어 있을 수도 있으니 Ctrl+Alt+B 나 `claude-board` 를 실행해 보세요.
  기록은 `%USERPROFILE%\.claude\notifier\board.log` 에 남습니다.
- "이 시스템에서 스크립트를 실행할 수 없으므로…" 오류: 스크립트 파일을 직접 실행했을 때 실행 정책 때문에 납니다. 위의 `irm … | iex` 한 줄 명령을 쓰거나
  `powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1` 로 실행하세요.
- 설치가 "앱 파일을 바꿔 넣지 못해 원래대로 되돌렸습니다" 로 끝남: 보드가 아직 떠 있거나 다른 프로그램(탐색기 · 백신 검사 등)이 앱 파일을 쥐고 있는 것입니다.
  트레이 메뉴의 종료로 보드를 끄고 다시 실행하세요. 원래 파일은 그대로 남아 있습니다.
- 설치가 "SHA256 이 … 달라 설치하지 않습니다" 로 끝남: 내려받는 도중 파일이 바뀌었거나 프록시가 내용을 바꾼 것입니다. 잠시 뒤 다시 실행하세요.
- 설치가 "터미널(PowerShell 창)에서 설치 명령을 실행해야…" 로 끝남: 처음 설치는 hook 등록을 물어봐야 하므로, 입력을 받을 수 있는 PowerShell 창에서 실행하세요.
- 더블 클릭해도 세션 창으로 이동하지 않음: 보드 밖 터미널의 세션이어야 창으로 이동합니다(보드 탭의 세션은 그 탭을 고릅니다). Windows Terminal 을 최신으로 업데이트해 보세요. 관리자 권한으로 연 터미널의 세션은 보드가 다룰 수 없습니다.
  Windows 가 다른 앱이 창을 앞으로 가져오는 것을 막아 작업 표시줄 단추만 깜빡일 수도 있습니다. Windows Terminal 이 없는 클래식 콘솔 창이 보드의 클릭 지점을 덮고 있으면 더블 클릭의 둘째 클릭이 콘솔에 닿아 선택 모드로 들어가 출력이 멈출 수 있습니다. Esc 로 풀립니다.
- 일시중지 · 재개 · 중단이 동작하지 않음: 터미널 없이 도는 세션이거나 관리자 권한 터미널의 세션이면 입력을 넣을 수 없습니다. 그 세션의 터미널에서 직접 Esc · `/exit` 를 입력하세요.
- 트레이 **종료** 를 눌렀는데 보드가 안 꺼짐: 도는 세션이 있으면 확인 창이 먼저 뜹니다. 보드가 숨어 있어도 창이 뜨니 보드 쪽을 보세요. 창이 안 보이면 **종료** 를 한 번 더 누르면 창이 다시 뜹니다. 15분 동안 답이 없으면 취소됩니다. 그래도 안 되면 `board.log` 의 `끌 때 확인` 줄을 보세요.
- 보드를 다시 켰는데 탭이 안 돌아옴: 저장해 둔 작업 폴더가 지워졌거나 옮겨졌는지, 그 세션이 다른 터미널에서 이미 도는 중은 아닌지 보세요. `board.log` 에 `탭을 되살리지 않음` 이나 `탭을 이어 열지 않음` 줄이 이유를 남깁니다. 고르지 않은 탭은 그 탭을 눌러야 이어 열립니다.
- 보드로 옮기기가 "끝나지 않아" 로 실패함: 그 터미널에서 Claude Code 가 `/exit` 를 받아들이지 못한 것입니다(백그라운드 작업이 도는 중이거나 입력 창이 다른 입력을 기다릴 때). 그 터미널을 확인해 직접 끝낸 뒤 종료된 세션을 눌러 이어 여세요.
- 답변이 꾸며지지 않음: 새 세션 창의 **답변 마크다운 꾸미기** 가 켜져 있는지, `%USERPROFILE%\.claude\notifier\plugins\md-render\` 에 다섯 파일이 있는지, `board.log` 에 `답변 꾸미기 플러그인을 옮기지 못했습니다` 가 있는지 보세요. 이미 도는 세션에는 적용되지 않고 새로 띄우거나 이어 연 세션부터 적용됩니다.
- 탭에서 크기를 바꿨더니 줄이 어긋남: 행을 줄이거나 경계를 끌어 열을 줄일 때 줄 하나가 깨질 수 있습니다(알려진 제한).
- 계정을 전환했는데 사용 한도가 "로그인 토큰 갱신 전" 으로 나옴: 오래 쓰지 않은 계정은 토큰이 만료된 상태로 전환됩니다.
  아무 세션에서나 요청을 한 번 보내면 Claude Code 가 토큰을 갱신하고, 그 뒤 사용량이 표시됩니다.
- 계정 전환이 "Claude Code 가 로그인 정보를 쓰는 중입니다" 로 실패함: Claude Code 가 토큰을 갱신하는 순간과 겹친 것입니다. 잠시 뒤 다시 고르면 됩니다.
- 계정 추가가 끝나지 않음: 보드는 로그인을 15분 동안 기다립니다. 설정 > 계정의 **취소** 나 계정 메뉴의 "계정 추가 취소" 로 멈추고 다시 시도하세요.
- 로그인 창에서 Google 로그인이 막힘: 앱 안 창에서는 막힐 수 있습니다. 이메일로 로그인하거나, 설정 > 계정의 **다른 브라우저에서 열기** 로 연 브라우저에서 로그인한 뒤 브라우저가 보여 주는 코드를 같은 화면의 칸에 붙여 넣으세요.
- 로그인할 때 열기가 바뀌지 않음: 스위치가 원래대로 돌아가고 한 줄 안내가 뜹니다. `%USERPROFILE%\.claude\notifier\board.log` 에 사유가 남습니다.
- 저장한 계정이 모두 "다시 로그인 필요" 가 됨: 다른 PC 로 옮겼거나 Windows 암호를 관리자가 강제로 재설정하면 DPAPI 로 암호화한 토큰을 풀 수 없습니다. 계정을 다시 추가하세요.
- 사용 한도가 "사용량을 불러오지 못했습니다" 로 나옴: Claude Code 에 로그인되어 있는지 확인하세요. 네트워크가 막혀 있어도 이렇게 나옵니다.
- 업데이트가 실패함: `%USERPROFILE%\.claude\notifier\update.log` 를 확인하고, PowerShell 설치 명령을 직접 실행해 보세요.
- settings.json 을 원래대로 되돌리기: `%USERPROFILE%\.claude\` 폴더의 `settings.json.bak-claude-board-<날짜-시각>` 파일 중 설치 직전 것을 `settings.json` 으로 복사하면 됩니다.
