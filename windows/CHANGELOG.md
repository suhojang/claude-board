# 변경 내역 (Windows)

Claude Board for Windows 의 버전별 변경입니다. macOS 판의 변경은 [최상위 CHANGELOG.md](../CHANGELOG.md) 를 보세요.

새 버전을 올릴 때 맨 위에 `## <버전> — <날짜>` 항목을 먼저 쓰고 `windows/VERSION` 을 그 버전으로 바꿔 main 에 push 합니다.
CI(`.github/workflows/windows.yml`)가 그 항목을 `windows-v<버전>` GitHub 릴리스 설명으로 그대로 씁니다. 항목이 없으면 릴리스가 실패합니다.

## 3.2.3 — 2026-10-29

macOS 판과 같은 번호입니다. 2.13 은 나간 적이 없어 아래 2.13 항목의 변경도 이 판에 들어 있습니다.

Windows 11(10.0.26300) 한 대에서 확인한 것: 빈 화면 · 탭 줄 · 경로 줄이 그려지는 것, + 단추로 탭 열기, 새 세션 창, pwsh 탭에서 `claude` 가 시작되어 바르게 그려지는 것, 접고 펼쳐도 출력이 남는 것, 셸이 창 크기를 아는 것,
가짜 claude 로 본 세션 연결 칩, 합성 출력으로 잰 크기 바꾸기, pwsh 가 없는 PC · GPU 가 없는 화면 · 클래식 콘솔을 Windows 11 에서 흉내 낸 확인, Windows PowerShell 5.1 설치 · 업데이트 · 제거 흐름(75항목 통과).
실제 Claude Code 에서의 일시중지 · 재개 · 중단 · 이어 열기 · `/rename` 은 아직 확인하지 않았습니다(미확인). 자세한 근거와 확인하지 못한 목록은 [SPEC 11장](docs/SPEC.md) 에 있습니다.
G7 결과(실제 키 입력 확인): 일시중지·재개·중단·이어 열기·이름 바꾸기가 키를 받아 적는 가짜 claude 에서 설계대로 동작했고 보드는 2분 넘게 응답했습니다. 실제 Claude Code 에서의 키 처리는 확인하지 못했습니다.
G9 · G10 결과(같은 PC, 가짜 claude): 트레이 종료의 확인 창과 일시중지 표지, 보드를 다시 켰을 때의 탭 복원, 답변 꾸미기 플러그인 옮겨 쓰기와 `--plugin-dir` 하나, 다른 콘솔 세션을 보드 탭으로 옮기기, 알림 패널을 눌러 그 세션으로 가기, 경로 줄 밀기, 맨 위 고정과 투명도 규칙이 설계대로 동작했습니다.
다만 경로 줄 밀기는 손으로 민 스크롤이 1초 안에 되돌아오는 결함이 확인 중에 나와 고쳤고, 고친 뒤 G11 에서 9초 동안 유지되는 것을 확인했습니다. 이 PC 에는 쓸 수 있는 트레이 아이콘이 없어 탐색기가 보드에 아이콘 이벤트를 넘기는 부분은 확인하지 못했습니다. 단계별 결과와 확인하지 못한 목록은 [SPEC 11.2.1](docs/SPEC.md) 에 있습니다.
G11 결과(같은 PC, 가짜 claude 와 가짜 로그인): 설정 화면 열기 · 닫기 · Esc 차례, 접힌 보드에서 펼쳤다가 다시 접기, 검색, 전환 효과 셋, 묶음별 설정, 새 세션 기본 명령, 단축키 바꾸기(충돌 · 거절 · 되돌리기 · 숨은 보드에서의 전역 단축키), 설정 안 계정 추가(가짜 로그인으로 끝까지, 지우기 확인 창의 취소)가 설계대로 동작했습니다.
진짜 claude 는 한 번도 띄우지 않았고 진짜 시작 프로그램 값도 건드리지 않았습니다. 진짜 `claude auth login` 의 출력과 `BROWSER` 환경변수 처리, 보드가 여는 로그인 창(Google 로그인 포함), 진짜 시작 프로그램 값 쓰기, 실제 Windows 10, 모니터가 둘인 PC, AltGr 배열은 확인하지 못했습니다(미확인). 단계별 결과와 확인하지 못한 목록은 [SPEC 11.2.2](docs/SPEC.md) 에 있습니다.

### 추가
- 내장 터미널: 보드 창 안에 터미널 영역이 생기고, 탭마다 PowerShell 7 · Windows PowerShell · 명령 프롬프트 중 이 PC 에 있는 것(이 순서)이 열립니다.
- 탭 줄 · 경로 줄 · 빈 상태: 탭은 작업 폴더별로 경로 줄에 묶이고 탭 줄에는 지금 경로의 탭이 보입니다. 넘치면 가로로 밀립니다. macOS 판과 같은 모양입니다.
- 새 세션: 탭 줄의 **+ Ctrl+T**, 빈 화면의 **새 세션**, 경로 카드 머리의 **+**. 폴더와 명령을 골라 새 탭에서 시작합니다.
  `claude` 명령에는 `--session-id` 와 `--name <폴더 이름>` 이 붙고, 탭의 셸에 쳐 넣어 실행하므로 Claude Code 를 끝내면 셸 프롬프트로 돌아옵니다.
- 세션 연결 칩: 세션 줄에 그 세션이 어디서 도는지 칩이 붙습니다. 보드 탭이면 `CB`(탭 안에서 시작한 `claude -p` 는 `CB -p`), 다른 터미널이면 앱 이름(Windows Terminal 등), 터미널 없이 도는 세션이면 `$ claude --bg`, 끝난 세션이면 "보드에서 이어 열기" 입니다.
  보드가 연 터미널의 `claude` 는 손으로 쳐서 띄운 것도 3초 안에 그 탭에 연결됩니다.
- 세션 줄 클릭: 보드 탭의 세션은 그 탭을 앞으로, 다른 터미널의 세션은 한 번 클릭하면 그 터미널 앱을, 더블 클릭하면 그 창(Windows Terminal 이면 그 탭)을 앞으로 가져옵니다. 한 번 클릭은 더블 클릭 시간만큼 기다린 뒤 동작합니다.
  터미널 없이 도는 세션을 누르면 안내가 6초 동안 뜹니다.
- 일시중지 · 재개 · 중단: 보드 탭의 세션에는 보드가 그 탭에 키를 넣고, 다른 터미널의 세션에는 그 콘솔에 키를 넣습니다. 키를 넣을 수 없는 세션은 중단할 때 그 `claude` 프로세스만 끝냅니다(탭의 셸은 그대로). 터미널 없이 도는 세션은 건드리지 않습니다.
  재개할 때 키를 넣지 못하면 "키를 넣을 수 없어 재개하지 못했습니다" 를 알리고 같은 세션을 한 번 더 열지 않습니다.
- 탭 이름 바꾸기(**Ctrl+Shift+R**): 그 탭에서 도는 Claude Code 에 `/rename` 도 함께 보냅니다.
- 탭 닫기 확인(도는 세션이 있을 때만), **Ctrl+Alt+1~9** 로 탭 고르기(누르는 동안 번호 배지), **Ctrl+Alt+← → ↑ ↓** 로 탭 · 경로 옮기기.
- 제목 띠의 터미널 단추가 "터미널 펼침/접힘  Ctrl+Alt+T" 캡슐이 되었습니다. 탭 이름에 셸 실행 파일 경로가 보이지 않습니다.
- 터미널 펼치기 · 접기: 제목 막대의 단추, 트레이 메뉴의 **터미널 펼치기 (Ctrl+Alt+T)**, 어느 앱에서든 **Ctrl+Alt+T**.
  펼치면 창이 작업 영역 전체로 넓어지고, 그렇게 화면을 덮은 동안은 항상 위 고정이 풀리며 투명도가 적용되지 않습니다. 접으면 끌어 둔 폭으로 보드 쪽 화면 가장자리에 붙고 항상 위 고정이 돌아옵니다.
  접어 두는 동안에도 터미널 출력은 쌓이고, 다시 펼치면 이어서 보입니다.
- 터미널과 보드 사이의 경계를 끌어 보드 폭을 정합니다. 놓으면 그 폭을 기억합니다.
- 보드 위치: **설정 > 창 > 보드 위치** 에서 오른쪽(기본) 또는 왼쪽을 고릅니다. 접기 · 미니 화면 · Ctrl+Alt+B 로 붙이기가 고른 쪽 기준으로 동작합니다.
- 한글 입력: 조합 중에 누른 Enter · Esc · 방향키가 조합이 끝난 다음에 전달됩니다.
- Ctrl+Alt+B 는 터미널을 접고 보드를 고른 쪽에 붙여 앞으로 가져옵니다.
- 배포: 답변 마크다운 꾸미기 플러그인(md-render)의 파일 다섯 개가 릴리스 zip 과 설치 프로그램의 `plugins\md-render\` 에 실리고, 업데이트가 그 폴더를 앱 파일과 함께 바꿔 끼우며, 제거가 지웁니다.
- 탭 저장과 복원: 보드를 끄면 탭 목록(폴더 · 탭 이름 · 세션 · 고른 탭)을 기억하고, 다시 켜면 탭이 돌아옵니다. 고른 탭은 곧바로 `claude --resume` 으로 이어 열고, 나머지 탭은 그 탭을 누를 때 이어 엽니다.
  이어 열 때는 처음 실행에 쓴 옵션(`--model` · `--dangerously-skip-permissions` 등 허용된 글자로 된 것)이 따라옵니다. 보드 밖에서 같은 세션이 이미 도는 중이면(업데이트 직후 옛 보드의 `claude` 가 아직 끝나는 중인 경우 포함, 최대 5초 기다림) 그 탭은 셸로만 남습니다.
  저장해 둔 작업 폴더가 지금 없으면 그 탭은 되살리지 않습니다. 없는 폴더에서는 셸이 홈 폴더로 떠서, 권한 확인을 건너뛰는 `claude` 가 홈 폴더 전체를 열게 되기 때문입니다.
- 보드를 끌 때 확인: 트레이 **종료**를 누르면 보드 탭에서 도는 세션(작업 중 · 승인 대기 · 서브에이전트나 셸이 도는 세션 · 탭 안의 `claude -p` · 다른 프로그램이 도는 셸)이 있을 때만 목록과 함께 묻습니다. **종료**를 고르면 끊기는 대화형 세션에 일시중지 표지가 남아 다시 켠 뒤 "세션 재개"로 이어 갈 수 있습니다.
  백그라운드 세션과 다른 터미널의 세션은 영향이 없어 목록에 없습니다. 창이 떠 있는 동안 종료를 또 누르면 창을 다시 보여 줍니다. 화면이 새로 고쳐지면 확인을 취소하고, 15분 동안 답이 없으면 취소하며, 화면이 10초 안에 반응하지 않으면 그대로 끕니다. 업데이트도 도는 세션이 있을 때만 같은 확인을 합니다.
- 답변 마크다운 꾸미기(md-render): 보드가 시작할 때 플러그인을 `%USERPROFILE%\.claude\notifier\plugins\md-render\` 에 옮겨 두고(바뀐 파일만), 보드 탭에서 띄우는 `claude` 에 `--plugin-dir` 로 하나 붙입니다. 새 세션 창의 **답변 마크다운 꾸미기** 체크를 풀면 그 세션은 붙이지 않고, 같은 세션을 이어 열 때도 끈 채로 엽니다.
  제거하면 옮겨 둔 `plugins` 폴더도 지웁니다. 실제 Claude Code 가 답변을 다시 그리는 것은 확인하지 못했습니다(미확인).
- 보드로 옮기기: 다른 터미널에서 도는 세션의 **…** 메뉴에서 **보드로 옮기기** 를 고르면 그쪽을 끝내고(Esc, `/exit`) 보드 새 탭에서 같은 대화를 이어 엽니다. 작업 중이거나 승인을 기다리는 세션은 먼저 묻습니다. 8초 안에 끝나지 않거나 그 터미널을 찾지 못하면 알림이 뜹니다.
- 알림에서 세션으로: 알림 패널을 누르면 그 세션으로 갑니다. 보드 탭의 세션은 그 탭을 고르고, 다른 터미널의 세션은 그 창을 앞으로 가져옵니다. 보드가 숨어 있어도 보이게 하고, 세션을 찾지 못하면 보드만 보입니다.
- 경로 줄 가로 밀기: 경로가 많아 넘치면 이름을 줄이지 않고 가로로 밉니다(휠 · Shift+휠 · 트랙패드). 지금 경로는 고르거나 다시 켜거나 창 폭이 바뀔 때 보이게 따라갑니다.
- 서브에이전트: 시작 기록을 보지 못한 서브에이전트(끝 기록이나 도구 기록만 온 경우)는 목록에 보이지 않고 세션을 작업 중으로 만들지 않습니다.
- 설정 화면: **Ctrl+,**(또는 트레이 **설정…**)를 누르면 보드는 그대로 두고 터미널 자리가 설정 화면으로 바뀝니다. 왼쪽의 묶음(일반 · 창 · 알림 · 터미널 · 보드 · 계정 · 단축키 · 업데이트)을 고르거나 검색 칸에 이름을 쳐 모든 묶음에서 찾고, 바꾸면 바로 적용됩니다. 검색 결과를 누르면 그 설정으로 가서 잠깐 밝게 보여 줍니다.
  닫는 길은 Ctrl+, 한 번 더, **터미널로 돌아가기**, Esc 입니다. Esc 는 키를 받는 중이면 받기 취소, 검색어가 있으면 검색어 지우기, 아니면 닫기 순서로 동작합니다. 열려 있는 동안 탭의 터미널은 뒤에서 계속 돕니다.
  터미널을 접어 둔 보드에서 열면 터미널 칸이 펼쳐지고 닫을 때 다시 접힙니다. 탭을 고르거나 새 세션을 열거나 세션 줄을 누르면 설정 화면이 닫히고 그 동작을 합니다.
- 설정 화면 전환: **설정 > 창 > 설정 화면 전환** 에서 옆으로 밀기(기본) · 서서히 바뀌기 · 효과 없음을 고릅니다. Windows 의 움직임 줄이기가 켜져 있으면 설정과 상관없이 효과 없이 바뀝니다.
- 단축키 바꾸기(**설정 > 단축키**): 줄의 키 칸을 누르고 새 키를 누르면 바로 바뀝니다(Esc 취소, Backspace 비우기). 탭 줄 **+** · 터미널 단추 · 제목 막대 · 트레이 메뉴의 안내 글자가 바꾼 키를 따라갑니다.
  다른 동작과 같은 키를 고르면 두 줄에 알리고 **그쪽 비우기** 로 겹친 쪽을 비울 수 있습니다. 줄의 되돌리기 단추나 **모두 기본값으로** 로 기본 키로 돌립니다. 새 세션 · 탭 이름 바꾸기 · 탭과 경로 옮기기 · 항상 위에 고정 · 어느 앱에서든 듣는 두 키(Ctrl+Alt+B · Ctrl+Alt+T)를 바꿀 수 있습니다.
  Windows 가 먼저 쓰는 키(Alt+F4 · Alt+Tab · Ctrl+C 같은 복사·붙여넣기 키와 Win 이 든 키)와 Ctrl · Alt 가 없는 키(F1~F12 는 됩니다)는 고를 수 없습니다. 어느 앱에서든 듣는 두 키는 바꾼 키로 다시 등록되고, 다른 앱이 쓰는 키라 등록하지 못하면 그 줄에 알립니다.
  탭 옮기기에 **Ctrl+Tab** · **Ctrl+Shift+Tab** 보조 키를 더했습니다.
- 새 세션 기본값(**설정 > 터미널**): **기본 명령** 과 **답변 마크다운 꾸미기** 기본값을 정합니다. 새 세션 창의 처음 값과 경로 카드 머리의 **+** 가 따릅니다. 기본 명령은 `claude` 로 시작해야 하고 줄바꿈 · 제어 문자는 쓸 수 없으며 500자까지입니다. 비우면 `claude --dangerously-skip-permissions` 입니다.
- 로그인할 때 열기(**설정 > 일반**): 끄면 시작 프로그램 등록을 지우고 업데이트해도 다시 등록하지 않습니다. 켜면 다음 로그인부터 보드가 다시 뜹니다. 제거하면 끈 표시도 지웁니다. 바꾸지 못하면 스위치를 되돌리고 알립니다.
- 자동으로 업데이트 확인(**설정 > 업데이트**): 끄면 보드를 켤 때와 1시간마다의 확인을 하지 않습니다. 업데이트 확인 단추와 트레이 **업데이트 확인…** 은 그대로 되고, 켜면 바로 한 번 확인합니다.
- 알림 위치를 화면 그림에서 눌러 고릅니다(**설정 > 알림**).
- 설정 안 계정 추가(**설정 > 계정**): **계정 추가…**(계정 칩 메뉴에서도 됩니다)를 누르면 보드가 로그인을 시작하고, 보드가 띄운 로그인 창에서 추가할 계정으로 로그인하면 저절로 추가됩니다. 그 창을 닫으면 계정 추가를 취소합니다.
  브라우저가 코드를 보여 주면 같은 자리의 칸에 붙여넣고, Google 로그인이 막히면 **다른 브라우저에서 열기**(또는 **링크 복사**)로 열고 코드를 받아 넣습니다. 15분 안에 끝나지 않으면 접습니다. 저장한 계정 줄의 **지우기** 는 확인 창에서 **지우기** 를 눌러야 지웁니다.

### 바뀜
- 항상 위 고정은 터미널을 펼친 창이 그 모니터 작업 영역 전체를 덮을 때만 쉽니다. 접힌 창과 줄여 놓은 펼친 창은 고정을 따릅니다.
- 투명도는 포커스가 아니라 마우스 위치로 정해집니다. 보드가 앞에 있어도 마우스가 창 밖이면 슬라이더 값으로 보이고, 작업 영역 전체를 덮은 창은 마우스가 밖이어도 불투명합니다. 슬라이더를 움직이는 동안은 늘 슬라이더 값입니다.
- 종료된 세션 이어 열기는 새 콘솔 창이 아니라 보드 탭에서 엽니다. 같은 폴더에 빈 셸 탭이 있으면 거기에 치고 없으면 새 탭을 엽니다. 처음 실행할 때 쓴 모델 · 권한 옵션은 허용된 글자로 된 것만 그대로 따라오고, 하나라도 그렇지 않으면 `claude --resume <id>` 만 칩니다.
- 보드 탭의 세션이 있는 줄은 위 표대로 동작하고, 터미널 앱을 따로 찾아 새 창을 띄우지 않습니다.
- 트레이 메뉴는 세션 보드 보기 · 터미널 펼치기 (지금 키) · 항상 위에 고정 · 설정… · 업데이트 확인… · 종료입니다. 캐릭터 · 알림 위치 · 보드 위치는 설정 화면(일반 · 알림 · 창)에서 고릅니다. 캐릭터 오른쪽 클릭, 윗줄 종 단추, 투명도 슬라이더는 그대로입니다.
- 계정 추가는 새 콘솔 창을 띄우지 않고 **설정 > 계정** 안에서 합니다. 보드가 쥔 가짜 콘솔에서 `claude auth login` 을 돌려 로그인 주소와 코드 칸을 보여 주고, 지금 쓰는 로그인은 바뀌지 않습니다.
- 계정을 지울 때(설정 화면 · 계정 칩 메뉴 모두) 확인 창이 먼저 뜹니다. 지금 쓰는 계정은 지울 수 없습니다.
- 키를 바꾼 동작의 안내 글자와 어느 앱에서든 듣는 키가 바꾼 키를 따릅니다. 기본 키는 그대로입니다.

### 고침
- 창이나 경계를 끌어 터미널 크기를 바꿀 때 출력 줄이 깨지던 문제를 줄였습니다. 크기는 ConPTY 가 다시 그리기 시작하는 자리에서만 바꾸고, 모양(열 · 행 · 늘림 · 줄임)마다 측정으로 고른 순서를 씁니다.
  합성 출력으로 잰 결과(5개씩): 열을 줄이는 경우와 행을 늘리는 경우는 깨진 캡처 0/5, 이전 방식은 ascii 4/5 와 5/5 였습니다. 행을 줄이거나 열을 줄이면서 행을 줄이는 경우는 깨진 줄이 남습니다(알려진 제한).
- 글자 렌더러가 WebGL 대신 기본 렌더러로 내려간 화면에서 글자가 칸에서 어긋나던 문제를 고쳤습니다(앱의 글자 간격이 터미널에 상속되던 것).
- 업데이트 중 앱 폴더 교체가 중간에 막혔을 때 플러그인 폴더가 반쪽으로 남던 문제를 고쳤습니다. 이제 폴더를 한 번에 옮기고 막히면 처음 상태로 되돌립니다.
- 폴더 이름에 `claude` 가 든 node 도구(예: `claude-board` 폴더 아래의 스크립트)를 Claude Code 로 잘못 세던 것을 고쳤습니다. 이제 Claude Code 패키지 경로가 있어야 합니다.
- 승인할 것이 없는데 세션 카드가 "승인 대기" 로 보이고 같은 문구로 승인 대기 알림이 뜨던 문제를 고쳤습니다. Claude Code 는 다른 백그라운드 작업이 끝나거나 실패했을 때, 로그인에 성공했을 때 같은 알림도 승인 요청과 같은 길로 보내는데, 지금까지는 이것을 모두 승인 대기로 기록했습니다. 이제 도구 승인과 MCP 의 입력 요청만 승인 대기로 보고, 나머지 알림은 세션 상태를 바꾸지 않으며 알림 패널도 띄우지 않습니다.
- 계정 저장에서 깨진 저장 계정 목록은 지우지 않고 `accounts.json.broken-<시각>` 파일로 옆에 옮겨 두고, 제거할 때 이 파일들도 지웁니다.
- 지금 로그인된 계정의 정보가 없거나 모자라면 계정 전환을 막고, Claude Code 에서 /login 으로 다시 로그인하라고 알립니다.
- 깨진 저장 계정 목록을 옆 파일로 옮기지 못하면 계정을 저장하지 않고 그 사실을 알립니다.
- 계정 지우기의 결과를 성공·경고·실패 각각에 맞춰 알립니다. 지우기에 실패해도 목록에서 지웠다고 알리지 않습니다.
- 요금제 종류가 없는 계정의 요금제 글자가 "5x" 처럼 앞 빈칸 없이 보입니다.
- 자동 전환 실패를 원인 쪽에 따라 나눕니다: 전환하려던 계정 쪽이면 그 계정만 1시간 건너뛰고, 지금 계정·시스템 쪽이면 1시간 쉬고 한 번 알리며, 로그인 정보 쓰기 잠금 실패는 알리지 않고 30초 뒤에 다시 시도합니다. 지금 계정을 알 수 없을 때는 /login 안내를 한 번 알립니다. 한도 판단과 표시는 5시간·주간(전체) 한도만 봅니다.
- 일시중지한 세션을 재개할 때 세션이 아직 돌고 있는 것을 새 탭으로 다시 이어 열지 않고, 그 터미널에 키를 넣지 못하면 그 터미널에서 이어 가 주라고 알립니다. 일시중지 표지는 그대로 둡니다.
- pid 를 남기지 않은 세션의 생사를 Claude Code 세션 파일에서 판단해, 죽은 프로세스면 종료로 보입니다.
- 같은 이름 모델별 주간 한도가 여럿이면 뒤의 것에 `-2`, `-3` 을 붙여 둘 다 보입니다. 한도를 알 수 없는 응답으로는 보이던 한도를 비우지 않습니다.
- 경로 줄의 상태 점은 일시중지를 대기보다 급한 것으로 보입니다. 다른 터미널에서 이어 연 세션이 보드 탭 세션으로 잘못 보이지 않고, 같은 콘솔에서 도는 세션이 여럿이면 마지막으로 움직인 세션이 탭의 세션으로 고릅니다.

### 알려진 제한
- 아직 없는 것: 화면 나누기 · 터미널 글꼴 크기 / 테마 / 애니메이션 설정 · 보드 글자 크기 배율.
- 크기 바꾸기는 Windows 11 빌드 26300 한 대에서 합성 출력으로 측정했습니다. 실제 Claude Code 화면과 다른 Windows 빌드는 측정하지 않았습니다. 행을 줄이는 크기 변경과, 경계를 끌어 열을 줄이는 경우에는 줄 하나가 깨질 수 있습니다.
- Ctrl+Alt+T 는 어느 앱에서든 듣는 단축키라, 보드가 켜져 있는 동안 JetBrains IDE 같은 다른 앱의 같은 단축키는 보드가 가져갑니다. AltGr 배열 키보드에서는 AltGr 로 치는 글자가 막힐 수 있습니다.
  다른 앱이 먼저 쓰고 있으면 등록에 실패하고 `board.log` 에만 남습니다. 그때도 트레이 메뉴와 제목 막대 단추로 펼치고 접을 수 있습니다.
  한국어 키보드에서는 왼쪽 Ctrl+Alt 로 누르세요.
- 터미널 셸은 보드가 켜 둔 동안만 삽니다. 보드를 끄면 셸도 끊기고, 다시 켜면 탭과 claude 대화는 복원되지만 셸 안에서 하던 일은 이어지지 않습니다.
- 화면을 새로 고치면 한 번도 들어가 본 적 없는 복원된 탭이 다음에 보드를 켤 때까지 화면에서 사라집니다(저장된 목록에는 남아 있습니다). 작업 폴더가 지워진 탭은 화면에서도 저장 목록에서도 빠집니다.
- Ctrl+T 와 Ctrl+Shift+R 은 터미널이 펼쳐진 동안 보드가 가져가 셸에는 전달되지 않습니다. **설정 > 단축키** 에서 다른 키로 바꿀 수 있습니다.
- 실제 한글 입력기, 배율이 다른 모니터, 모니터가 여럿인 PC, 폴더 선택 창, cmd.exe 탭의 `--name` 따옴표 처리는 확인하지 않았습니다(미확인).
- 실제 Claude Code 에서 `--plugin-dir` 로 답변이 다시 그려지는 것, 보드로 옮길 때 `/exit` 가 받아들여지는 것, Windows Terminal 안의 세션을 옮기는 것, 보드를 끄고 켠 뒤 실제 대화를 이어 여는 것은 확인하지 않았습니다(미확인).
- 마우스 위치는 마우스가 움직일 때만 읽습니다. 창이 가만히 있는 마우스 밑에서 움직이면 투명도가 한동안 이전 값으로 남을 수 있습니다.
- Windows 10 에서는 확인하지 않았습니다(미확인). Windows 11 에서 흉내 낸 확인(pwsh 가 없는 PC, GPU 가 없는 화면, 글꼴 대체, Windows Terminal 이 없는 클래식 콘솔, Windows PowerShell 5.1 설치)만 했고, 실제 Windows 10 에서 확인하는 순서는 [SPEC 11.3](docs/SPEC.md) 에 있습니다.
- 클래식 콘솔 창이 보드의 클릭 지점을 덮고 있으면 더블 클릭의 둘째 클릭이 콘솔에 닿아 선택 모드로 들어가 출력이 멈출 수 있습니다(Esc 로 풀림).
- 설정 안 계정 추가는 가짜 로그인으로만 끝까지 확인했습니다. 진짜 `claude auth login` 의 출력 모양, Windows 의 Claude Code 가 `BROWSER` 환경변수를 따르는지, 보드가 여는 로그인 창은 확인하지 못했습니다(미확인). Google 로그인은 앱 안 창에서 막힐 수 있고, 그때는 **다른 브라우저에서 열기** 와 코드 칸을 씁니다. 로그인 중에 보드를 끄면 로그인 프로그램이 끝나는지도 확인하지 못했습니다.
- 계정을 실제로 지우는 것은 시험하지 않았습니다(확인 창의 취소만 시험했습니다). 로그인할 때 열기가 진짜 시작 프로그램 값을 쓰고 지우는 것도 격리한 시험 환경에서만 확인했습니다(미확인).
- 단축키를 바꾼 뒤의 안내 글자는 탭 줄 **+** 와 터미널 단추만 화면에서 확인했습니다. 보드가 보이는데 다른 창에 포커스가 있을 때의 전역 단축키, 보드 위치가 왼쪽일 때의 설정 화면 전환, 실제 Claude Code 에서 바꾼 키가 닿는 모습, 모니터가 둘인 PC, AltGr 배열은 확인하지 못했습니다(미확인).
- 단축키를 받는 도중 화면이 새로 고쳐지면 어느 앱에서든 듣는 키가 풀린 채 남고, 설정 > 단축키를 다시 열면 다시 등록됩니다.
- 접힌 보드에서 설정 화면을 열어 두는 동안은 터미널 칸이 펼쳐진 상태로 저장됩니다. 닫거나 보드를 끄면 접힌 상태로 돌아갑니다.

## 2.13 — 2026-10-21

macOS 판 3.0 ~ 3.1.8 에서 바뀐 세션 상태 규칙을 Windows 판에 옮겼습니다.

### 바뀜
- Esc 로 응답을 끊은 세션이 보드 · 터미널판 보드 · 알림 패널의 상태별 개수에서 계속 작업 중으로 남지 않고 바로 대기로 보입니다. 응답을 시작하기 전에 끊어도 같습니다. 대기 시간은 끊은 때부터 셉니다.
- 승인을 처리한 뒤 도구가 도는 동안 세션이 승인 대기로 남지 않고 바로 작업 중으로 보입니다.
- Esc 로 끊은 뒤 다음 요청을 보내면 작업 중 시간이 그 요청을 보낸 때부터 다시 셉니다.
- 보드가 프로젝트 폴더(claude 를 띄운 폴더)로 카드를 묶습니다. Claude 가 하위 폴더로 `cd` 하거나 워크트리에 들어가도 세션이 같은 카드에 남습니다. 끝난 세션은 그 프로젝트 폴더에서 이어 엽니다.

### 추가
- 세션 줄에 Claude Code 세션 이름 라벨이 붙습니다(`/rename` 이나 `--name` 으로 정한 이름, 다른 터미널의 세션 포함). 24자를 넘으면 앞 11자와 뒤 11자만 보이고 마우스를 올리면 전체 이름이 보입니다.
  보드 칸이 좁아지면 이름 라벨이 먼저 빠집니다. 종료된 세션에는 붙지 않습니다.

### 고침
- 서브에이전트가 물은 승인을 처리했는데도 세션이 계속 승인 대기로 남던 문제를 고쳤습니다. 승인 창이 몇 초 넘게 떠 있어 Claude Code 가 알림을 보낸 경우에 생겼습니다. 이제 승인하면 승인을 묻기 전 상태(작업 중 또는 대기)로 돌아갑니다.
- bypass 권한 모드로 이어 열 때마다 `--allow-dangerously-skip-permissions` 가 하나씩 늘던 문제를 고쳤습니다. 같은 옵션은 한 번만 넘깁니다.

### 알려진 제한
- Esc 감지와 세션 이름은 Claude Code 가 `%USERPROFILE%\.claude\sessions\` 와 대화 기록에 남기는 값을 읽습니다. 실제 Claude Code 세션에서 Esc 로 끊었을 때의 동작은 Windows 에서 아직 확인하지 못했습니다.

## 2.12 — 2026-10-16

첫 Windows 판입니다. macOS 판 2.12 의 기능을 Windows 10(1809 이상) · Windows 11 로 옮겼습니다.
기능 전체는 [설치 가이드](https://github.com/suhojang/claude-board/blob/main/windows/docs/설치%20가이드.md)를 보세요.

### 추가
- 보드: 작업 경로마다 카드 하나에 세션을 묶어 승인 대기 · 작업 중 · 대기 · 일시중지 · 종료 상태를 급한 순서로 보여 줍니다.
  세션 줄에 마지막 요청, 경과 시간, 모델 · effort, 컨텍스트 사용량, 서브에이전트와 지금 쓰는 도구, 백그라운드 셸 수가 붙습니다.
  경로 고정 · 지우기, 조용한 카드 자동 접기, 상태 칩으로 한 상태만 보기, 세션 · 전체 알림 끄기도 macOS 판과 같습니다.
- 창 크기에 따라 전체 · 중간 · 미니 세 단계로 바뀌고, 최대축소 단추(↘↖)와 ⤢ 로 미니 화면을 오갑니다. 투명도 슬라이더, 항상 위에 고정(기본 켜짐).
- 알림 패널: 승인이 필요하거나 응답이 끝나면 화면 가운데(또는 고른 모서리)에 뜹니다. 키보드 입력을 가져가지 않고 작업 표시줄에 나타나지 않습니다.
  누르면 보드가 열리고, 누르지 않으면 10초 뒤 닫힙니다. 모서리에서는 동시에 뜬 알림이 겹치지 않게 쌓입니다.
- hook: 실행 파일 하나(`claude-board-hook.exe`)로 상태를 기록하고 알림을 띄웁니다. python 이 필요 없습니다.
  `%USERPROFILE%\.claude\settings.json` 에 셸을 거치지 않는 형식(command + args)으로 hook 11개를 등록하고, 기록 형식은 macOS 판과 같습니다.
- 사용 한도: 5시간 · 주간(전체 · 모델별) 사용량과 초기화 시각을 보여 줍니다.
- 계정 전환: 계정을 미리 추가해 두고 보드에서 바꿉니다. 저장한 로그인 토큰은 DPAPI 로 암호화해 이 Windows 사용자만 풀 수 있습니다.
- 한도 자동 전환(기본 꺼짐): 한도가 차면 저장한 다른 계정으로 바꾸고, 40초 뒤 한도로 멈췄던 세션에 이어서 진행하라는 요청을 넣습니다.
- 세션 터미널 제어: 더블 클릭으로 그 세션의 터미널 창(Windows Terminal 이면 그 탭)으로 이동, 종료된 세션을 새 콘솔 창(기본 터미널)에서 이어 열기,
  … 메뉴의 일시중지 · 재개 · 중단.
- 트레이 아이콘(승인 대기 주황 점 · 작업 중 파란 점, 오른쪽 클릭 메뉴: 세션 보드 보기 · 항상 위에 고정 · 캐릭터 · 알림 위치 · 업데이트 확인… · 종료),
  전역 단축키 Ctrl+Alt+B, 로그인 자동 실행, Windows Terminal 이 새로 뜨면 숨은 보드를 다시 보이기.
- 캐릭터 8종(브레인롯 7종과 현장 감독)과 말풍선. 캐릭터를 오른쪽 클릭하거나 트레이 메뉴에서 고릅니다.
- 오른쪽 아래 터미널 독: Windows Terminal · PowerShell 7 · Windows PowerShell · 명령 프롬프트 · Git Bash.
- 터미널판 보드 `claude-board-tui`, 보드를 여는 `claude-board` 명령.
- 설치 · 업데이트 · 제거: PowerShell 한 줄 설치(`install.ps1`, 받은 zip 의 SHA256 확인), 설치 프로그램 `ClaudeBoard-<버전>-setup.exe`,
  제거 스크립트 `uninstall.ps1`. 새 버전 알림 줄의 업데이트 단추로 바로 업데이트합니다.

### 알려진 제한
- 터미널 창을 직접 다루는 기능(창 · 탭으로 이동, 일시중지 · 재개 · 중단, 자동 전환 뒤 이어 가기, 터미널 제목 바꾸기)은
  Windows 콘솔 · Windows Terminal 의 내부 동작에 기대므로 환경에 따라 동작하지 않을 수 있습니다. 관리자 권한으로 연 터미널의 세션은 다룰 수 없습니다.
- 코드 서명이 없어 setup.exe 를 처음 실행할 때 SmartScreen 경고가 뜹니다.
- ARM64 Windows 에서는 확인하지 않았습니다.
