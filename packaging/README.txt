Claude Board 설치 가이드 (macOS)
==================================

Claude Board 는 Claude Code 세션 상태를 한눈에 보여 주는 보드 창과, 응답이 끝나거나
승인이 필요할 때 화면 가운데(또는 고른 모서리)에 뜨는 알림 패널을 함께 제공합니다.
보드 창 왼쪽에는 터미널이 있어, 보드에서 세션을 바로 띄우고 다룰 수 있습니다("4. 보드 안 터미널").


1. 설치하기 전에 알아 두실 점
------------------------------

1) 필요한 환경
   - macOS 14(Sonoma) 이상이 필요합니다. Apple Silicon 과 Intel Mac 모두 지원합니다.
   - Claude Code 가 설치되어 있어야 합니다.
   - python3 가 필요합니다. 알림과 상태 기록 스크립트가 python3 로 실행되기 때문입니다.
     터미널에서 python3 --version 을 실행해 버전이 나오면 준비된 것입니다.
     설치되어 있지 않다면 xcode-select --install 을 실행하거나 Homebrew 로 설치하세요.
   - 보드 안 터미널의 탭(보드 탭)에서 도는 세션은 터미널 앱 없이 보드에서 바로 다룹니다.
     종료된 세션도 보드 탭에서 이어 엽니다.
   - 다른 터미널에서 도는 세션을 더블 클릭해 그 탭으로 이동하는 기능과, 그 세션의 일시중지·재개·중단·보드로 옮기기는
     Ghostty 터미널 1.3 이상에서만 동작합니다. 다른 터미널에서도 보드와 알림은 정상 동작합니다.

2) 설치하면 바뀌는 것
   - /Applications/Claude Board.app 이 설치되고, 로그인할 때 자동으로 실행되도록
     ~/Library/LaunchAgents/com.claude.board.plist 가 등록됩니다. 보드의 설정 > 일반 > 로그인할 때 열기 를 끄면
     이 파일을 지우고, 업데이트해도 다시 등록하지 않습니다.
   - ~/.claude/notifier/ 폴더에 알림 패널과 상태 기록 스크립트가 설치됩니다.
   - Claude Code 전역 설정 파일 ~/.claude/settings.json 에 hook 11개가 등록되고,
     환경변수 CLAUDE_CODE_DISABLE_TERMINAL_TITLE=1 이 추가됩니다.
     · 바꾸기 전에 원본을 settings.json.bak-claude-board-<날짜-시각> 으로 백업합니다.
     · 이미 쓰고 계신 다른 hook 과 설정은 그대로 유지됩니다.
     · 여러 번 설치해도 hook 이 중복으로 등록되지 않습니다.
   - ~/.local/bin 에 claude-board(보드 열기)와 claude-board-tui(터미널판 보드) 명령이 설치됩니다.
   - Ghostty 가 설치되어 있으면, Ghostty 를 열 때 보드가 꺼져 있으면 함께 띄우는 줄을
     ~/.zshrc 에 추가합니다(# >>> claude-board >>> 표시로 감싸며, 제거할 때 함께 지웁니다).
   - 예전 판(~/Applications 에 설치하던 1.x)이 있으면 지우고 /Applications 판으로 바꿉니다.
   - 보드는 뜰 때마다 앱 안의 답변 마크다운 꾸미기 플러그인(md-render)을 ~/.claude/notifier/plugins/md-render/ 로
     옮겨 둡니다(내용이 같으면 건드리지 않습니다). 보드 탭에서 띄우는 claude 만 이 폴더를 쓰고, Claude Code 전역
     플러그인으로는 설치하지 않습니다. Claude Code 가 이 폴더에 tsconfig.json 과 .claude-plugin/types/ 를 만들기도
     하는데 정상입니다. 제거할 때 함께 지웁니다.
   - 앱에 함께 들어간 구성 요소(터미널 엔진 등)의 라이선스 고지는 앱 안
     /Applications/Claude Board.app/Contents/Resources/THIRD_PARTY_NOTICES.txt 에,
     md-render 의 고지는 같은 폴더의 plugins/md-render/LICENSE 에 있습니다.

3) dmg 로 설치할 때는 처음 한 번 "그래도 열기" 가 필요합니다 (터미널로 설치하면 필요 없습니다)
   앱과 dmg 는 배포자의 개인 인증서로 서명되어 있지만, Apple 공증을 받은 것은 아닙니다.
   그래서 처음 설치 패키지를 열 때 macOS 가 "Apple 은 악성 코드가 없음을 확인할 수 없습니다" 라는 창을 띄우고
   열지 않습니다. 아래 "2. 설치 방법" 의 dmg 2) 를 따라 한 번만 허용하면 됩니다.
   서명자를 확인하고 싶으면 설치 후 터미널에서 아래 명령을 실행해
   Authority=Claude Board Signing 이 나오는지 보세요. dmg 안의 "서명 인증서.cer" 가 그 공개 인증서입니다.

       codesign -dvv "/Applications/Claude Board.app" 2>&1 | grep Authority

4) macOS 권한 요청
   - 보드에서 다른 터미널의 세션을 처음 더블 클릭하거나, Ghostty 세션을 일시중지·재개·중단·보드로 옮기기 할 때
     "Claude Board 가 Ghostty 를 제어하려고 합니다" 라는 창이 뜹니다. 창의 설명은 "세션의 터미널(Ghostty·iTerm2·Terminal)로
     포커스를 옮기고, 일시중지·재개·중단·보드로 옮기기 때 Ghostty 세션에 키를 입력합니다." 입니다.
     허용해야 탭 이동과 Ghostty 세션 조작이 동작합니다. 보드 탭 세션은 이 권한 없이 동작합니다.
     거부했다면 시스템 설정 > 개인정보 보호 및 보안 > 자동화 에서 다시 켤 수 있습니다.

5) 알림 패널과 키보드 입력
   알림 패널은 키보드 입력을 가져가지 않습니다. 알림이 떠 있는 동안에도 터미널에 입력하던 프롬프트를
   그대로 이어서 쓸 수 있습니다. 알림을 누르면 보드가 열리면서(보드 탭 세션이면 터미널을 펼쳐 그 탭으로)
   닫히고, 누르지 않으면 10초 뒤 저절로 닫힙니다(마우스를 올려 두는 동안에는 멈춥니다).
   알림 패널은 기본으로 화면 가운데에 뜹니다. 보드의 설정 > 알림 > 알림 위치 에서 화면 그림의 왼쪽 위 · 오른쪽 위 ·
   왼쪽 아래 · 오른쪽 아래를 눌러 바꿀 수 있고, 모서리에서는 동시에 뜬 알림이 겹치지 않게 세로로 쌓입니다.


2. 설치 방법
------------

[터미널로 설치 (권장)]
터미널에서 아래 한 줄을 실행합니다. 처음 설치라면 settings.json 에 hook 을 등록할지 묻고, Y(또는 Enter)를 누르면
설치합니다. "그래도 열기" 단계는 없고, 예전에 dmg 로 설치한 앱을 바꿀 때만 관리자 비밀번호 창이 한 번 뜹니다.

    curl -fsSL https://github.com/suhojang/claude-board/releases/latest/download/install.sh | bash

설치가 끝나면 보드 창이 자동으로 열립니다. 이미 실행 중인 Claude Code 세션은 종료하고 다시 시작하세요.

[dmg 로 설치]
1) 받은 ClaudeBoard-<버전>.dmg 파일을 더블 클릭해 엽니다.
   Finder 에 "Claude Board" 볼륨이 나타납니다.

2) "Claude Board 설치.pkg" 를 더블 클릭합니다.
   처음에는 "열 수 없음" 경고가 뜹니다. 완료(또는 확인)를 누르고
   시스템 설정 > 개인정보 보호 및 보안 으로 가서 아래쪽의
   "'Claude Board 설치.pkg' 이(가) 차단되었습니다" 옆 "그래도 열기" 를 누릅니다.
   다시 묻는 창에서 "그래도 열기" 를 누르고 로그인 비밀번호(또는 Touch ID)로 확인합니다.
   (이 단계는 처음 한 번만 필요합니다.)

3) 설치 프로그램이 열리면 계속 → 설치를 누르고, 관리자 비밀번호를 입력합니다.

4) "설치가 완료되었습니다" 가 나오면 닫기를 누릅니다. 보드 창이 자동으로 열립니다.

5) 이미 실행 중인 Claude Code 세션이 있다면 종료하고 다시 시작하세요.
   새로 시작한 세션부터 보드에 나타나고 알림이 뜹니다.

6) dmg 볼륨은 Finder 에서 꺼내기(⏏) 해도 됩니다. 설치된 파일은 dmg 와 무관하게 동작합니다.


3. 사용법
---------

- 보드 창: 프로젝트 폴더(claude 를 띄운 폴더)별로 세션을 묶어 작업 중·승인 대기·대기·종료 상태를 보여 줍니다.
  Claude 가 하위 폴더로 cd 하거나 워크트리(.claude/worktrees/…)에 들어가도 세션은 같은 카드에 남아, 보드 안 터미널의 경로 줄과 같게 묶입니다.
  끝난 세션을 다시 열 때도 그 프로젝트 폴더에서 엽니다.
- 메뉴 막대의 Claude Board 아이콘: 보드 창을 열고 닫습니다. 승인 대기·작업 중 세션 수도 함께 보여 줍니다.
- 세션 한 번 클릭
  · 보드 탭 세션: 터미널을 펼치고(접혀 있거나 미니 화면이어도) 그 탭(나눈 화면이면 그 세션의 화면)으로 바꿔 입력 칸에 포커스를 둡니다.
  · 다른 터미널의 세션: 그 터미널 앱(Ghostty 등)을 앞으로 가져옵니다.
  · 종료된 세션: 보드 탭에서 claude --resume 으로 대화를 이어 엽니다.
    처음 실행할 때 쓴 옵션과 마지막 권한 모드도 함께 적용됩니다(-p 는 넘기지 않아 대화형으로 열립니다).
  · 백그라운드 세션(터미널 없이 claude -p·claude --bg 로 도는 세션): 아무 데도 가지 않고 "터미널이 없습니다" 안내만
    보드 아래에 잠깐(6초) 뜹니다. 끝난 백그라운드 세션은 눌러도 아무것도 하지 않고, 메뉴로만 엽니다(아래 ⋯ 메뉴).
- 세션 더블 클릭(다른 터미널의 세션): 그 세션이 열린 Ghostty 탭으로 이동합니다.
- 세션 칩: 세션 줄의 경과 시간 옆에 세션이 어디서 도는지 붙습니다.
  · CB: 보드 탭에서 도는 세션. 보드 탭 안에서 시작된 claude -p 는 CB -p 로 따로 줄이 생기고, 탭이 닫히면 함께 끝납니다.
  · 앱 이름(Ghostty·iTerm2 등): 다른 터미널에서 도는 세션.
  · $ claude -p, $ claude --bg: 백그라운드 세션(실제 실행 방식을 보여 줍니다). Claude Code 의 /bg·claude --bg 로 보낸 세션도 여기입니다.
  · 보드에서 이어 열기: 종료된 세션. 누르면 보드 탭에서 이어 엽니다. 끝난 백그라운드 세션은 $ claude -p 로 보입니다.
  경로 카드 안에서는 보드 탭 세션과 다른 터미널의 세션이 "터미널" 구역에, 백그라운드 세션만 "백그라운드" 구역에 묶입니다.
- 세션 이름: 세션 칩 옆에 Claude Code 의 세션 이름이 붙습니다(세션끼리 메시지를 주고받을 때 부르는 이름입니다).
  보드 탭 세션은 탭 줄 이름과 같고("4. 보드 안 터미널" 의 세션 이름), 다른 터미널·백그라운드 세션은 Claude Code 가 붙인
  이름(예: claude-board-81) 그대로입니다. 보드 칸이 좁으면 이 라벨부터 빠지고, 종료된 세션에는 붙지 않습니다.
- 세션 줄 오른쪽 위의 ⋯ 메뉴: 누르면 보드와 같은 모양의 메뉴 패널이 단추 아래에 뜹니다. 맨 위에 세션 이름과 상태·칩·작업 폴더가
  보이고, 항목마다 아이콘·제목·한 줄 설명이 붙습니다. 지금 쓸 수 없는 항목은 흐리게 두고 설명에 까닭을 적습니다
  (예: "대기 중이라 멈출 응답이 없습니다"). 세션 중단은 빨간색으로 구분선 아래에 따로 있습니다.
  마우스나 ↑↓ 로 고르고 클릭·Return 으로 실행합니다. Esc, 바깥 클릭, 스크롤, 다른 앱으로 넘어가기, 보드 창 옮기기에는 닫힙니다.
  · 일시중지: 지금 응답을 멈추고(Esc) 일시중지로 표시합니다. 작업 중·승인 대기인 보드 탭 세션과 Ghostty 세션만 됩니다.
  · 세션 재개: 일시중지한 세션에 이어서 진행하라는 요청을 넣어 하던 일을 이어 갑니다. 세션이 꺼져 있으면 보드 탭에서
    이어 열면서 그 요청을 넣습니다.
  · 세션 중단: 확인한 뒤 진행 중인 응답을 멈추고 세션을 끝냅니다. 대화 기록은 남아 나중에 다시 열 수 있습니다.
  · 보드로 옮기기(Ghostty 세션): "4. 보드 안 터미널" 을 보세요.
  · 종료된 세션은 "세션 다시 열기"(일시중지였던 세션은 "세션 재개 (이어서 진행)")로 보드 탭에서 엽니다.
    끝난 백그라운드 세션도 "세션 다시 열기" 로 대화형으로 열고, 이때부터 보드 탭 세션입니다.
  · 도는 백그라운드 세션에는 ⋯ 메뉴가 없습니다(알림 스위치만). 보드는 백그라운드 세션에 신호를 보내지 않습니다.
  보드 탭 세션은 그 탭에 직접 키를 넣고, Ghostty 세션은 Ghostty 에 AppleScript 로 키를 넣습니다.
- 종료된 세션 오른쪽의 ⓧ: 목록에서 지웁니다. 종료된 지 2일이 지나면 자동으로 지워집니다.
- 질문 없이 끝난 세션은 대화 기록이 없어 이어 열 수 없으므로 목록에 나타나지 않습니다.
- 세션 줄과 하위 작업(서브에이전트) 줄에 모델·effort 라벨이 붙습니다. 색은 모델 계열(Opus 주황·Sonnet 파랑·Haiku 민트·Fable 보라),
  뒤의 막대 5칸은 effort 단계(low 1칸 ~ max 5칸)입니다. 마우스를 올리면 정확한 모델 ID 와 effort 가 보입니다.
  값은 마지막 응답 기록에서 읽으므로, /effort 로 바꾼 뒤에는 다음 응답부터 바뀝니다.
- 위쪽 상태 칩(승인 대기·작업 중·대기 개수): 누르면 그 상태 세션만 보입니다. 같은 칩을 다시 누르면 모두 보입니다.
- 경로가 많아 아래로 가려진 카드가 있으면 목록 아래에 "아래에 경로 N개 더" 가 뜹니다. 누르면 그 카드로 내려갑니다.
- 승인 대기·작업 중 세션이 없고 30분 넘게 조용한 경로 카드는 자동으로 접힙니다. 다시 펼친 카드는 새 활동이 생기기 전까지 그대로 둡니다.
- 접힌 경로 카드에서도 진행 상황이 보입니다. 작업 중이면 폴더 아이콘 자리에 도는 링이, 승인 대기면 퍼지는 파문이 나오고,
  경로 대신 지금 하는 일(승인 대기면 승인 요청 내용)이 상태 색으로 나옵니다. 여러 세션이 돌고 있으면 뒤에 +1 처럼 나머지 개수가
  붙고, 작업 중인 카드 머리 위로는 빛이 지나갑니다.
- 제목(Claude Board) 옆에 보드 버전이, 그 아래 활성 세션 수 옆에 설치된 Claude Code 버전이 있습니다.
  오른쪽에는 세션 상태를 말풍선으로 알려 주는 캐릭터가 있습니다.
  캐릭터를 누르면 다음 말로 넘어갑니다. 캐릭터는 브레인롯 7종(트랄랄레로 트랄랄라 · 봄바르디로 크로코딜로 · 퉁 퉁 퉁 사후르 ·
  리릴리 라릴라 · 브르르 브르르 파타핌 · 보네카 암발라부 · 카푸치노 아사시노)과 현장 감독 중에서 고릅니다(기본은 트랄랄레로 트랄랄라).
  캐릭터를 오른쪽 클릭하거나 설정 > 일반 의 캐릭터 그림에서 고르고, 고른 캐릭터는 다시 실행해도 유지됩니다.
  캐릭터는 세션 상태에 따라 작업 중이면 바쁘게, 승인 대기면 재촉하며("!"), 쉬는 중이면 졸며("z") 움직이고,
  승인 대기가 없을 때는 돌아가는 말 사이에 캐릭터 유행어를 한 번씩 섞습니다.
- 오른쪽 아래 독: 창 오른쪽 아래 끝의 터미널 탭(◀ 와 터미널 아이콘)에 마우스를 대면(창이 화면 오른쪽에 붙어 있으면
  마우스를 화면 끝까지 밀면) Ghostty·iTerm2·터미널·Orca 아이콘이 세로로 보드 위에 나타납니다.
  평소에는 탭만 보이고, 보드에 마우스를 올리면 탭이 밝아집니다.
  아이콘에 마우스를 올리면 왼쪽에 무엇을 여는지 보이고, 설치되지 않은 것은 흐리게 표시되어 눌리지 않습니다.
  실행 중인 앱은 아이콘 오른쪽에 점이 붙습니다.
- 사용 한도 카드: 5시간·주간(전체)·주간(Fable) 사용량을 보여 줍니다. 오른쪽 위 단추로 상세(한도마다 막대와 초기화 시각)와
  간략(한 줄) 모드를 바꿉니다. 간략 모드에서 각 한도에 마우스를 올리면 초기화 시각이 보입니다.
- 윗줄의 모두 접기·펼치기 단추: 모두 접기는 경로 카드를 모두 접고 사용 한도를 간략 모드로, 모두 펼치기는 카드를 모두 펴고
  상세 모드로 바꿉니다. (중간 화면에서는 이미 카드와 사용 한도가 한 줄이라 이 단추가 숨겨집니다.)
- 창 크기에 따라 화면이 세 단계로 바뀝니다.
  · 전체: 기본 화면입니다. 목록을 넉넉히 보여 줄 만큼 창이 높을 때입니다.
  · 중간: 창이 낮아지면 사용 한도가 한 줄로, 경로 카드가 접힌 한 줄 요약으로 바뀝니다.
    카드를 누르면 그 카드만 펼쳐집니다(이렇게 펼친 상태는 단계가 바뀌거나 다시 실행하면 접힙니다).
    전체 화면에서 정해 둔 접기 상태와 사용 한도 간략·상세 설정은 바뀌지 않습니다.
  · 미니: 창이 더 작아지거나 폭이 좁아지면 경로마다 한 줄(상태 아이콘 · 이름 · 터미널/백그라운드 아이콘 · 지금 하는 일)로 보입니다.
    맨 위에 캐릭터와 한 줄 말풍선이, 제목 막대 오른쪽에 상태별 세션 수와 ⤢(원래 크기로) 단추가,
    아래 줄에 사용 한도와 투명도 슬라이더가 있습니다.
    줄을 한 번 누르면 그 세션의 터미널 앱이, 두 번 누르면 그 세션의 터미널 창이 앞으로 옵니다
    (보드 탭 세션은 한 번에 터미널을 펼쳐 그 탭으로 갑니다).
  창을 손으로 줄이거나 늘리면 단계가 저절로 바뀝니다. 창은 미니 크기(가로 300 · 세로 110)까지 줄일 수 있습니다.
- 제목 막대 오른쪽 위의 최대축소 단추(↘↖ 모양): 창을 오른쪽 위 모서리(보드 위치가 왼쪽이면 왼쪽 위) 기준으로 가장 작게(가로 300, 세로는 경로 수에 맞춰 최대 6줄) 줄여
  미니 화면으로 바꿉니다. 미니 화면에서는 같은 자리의 ⤢ 를 누르면 줄이기 전 위치와 크기로 돌아갑니다.
  미니로 둔 채 종료하면 다음에 실행할 때도 미니 크기로 열립니다. ⌃⌥B(처음 크기로 오른쪽에 붙이기)로도 원래 화면으로 돌아옵니다.
  터미널을 펼친 채 최대축소하면 먼저 터미널을 접고, ⤢ 로 되돌리면 터미널을 다시 펼칩니다(그사이 다시 실행해도 같습니다).
  창을 손으로 끌어 미니 화면을 벗어나면 터미널은 접힌 채로 둡니다.
- 계정 전환: 사용 한도 카드 왼쪽 위의 계정(이메일·요금제)을 누르면 메뉴가 열립니다.
  · 계정 추가… : 설정 > 계정 이 열리고 그 안에서 로그인이 시작됩니다(터미널 창은 뜨지 않습니다). 보드가 띄운 "Claude 계정 추가"
    창에서 추가할 계정으로 로그인해 승인하면 보드에 저장되고 창이 닫힙니다. 그 창을 닫으면 계정 추가를 취소합니다.
    창은 매번 새로 시작해 브라우저에 로그인된 계정이 이어지지 않습니다. Google 로그인이 막히면 이메일로 로그인하거나
    "다른 브라우저에서 열기"·"링크 복사" 를 쓰고,
    브라우저가 보여 준 코드를 "인증 코드" 칸에 붙여넣고 확인을 누릅니다(이때는 브라우저 탭을 닫아도 알 수 없으니 취소 단추로 멈춥니다).
    실패하면 까닭이 그 아래에 뜹니다.
    지금 쓰는 로그인은 바뀌지 않으므로 작업 중에도 미리 추가해 둘 수 있습니다.
  · 저장한 계정을 고르면 모든 Claude Code 세션이 그 계정으로 바뀝니다. 실행 중인 세션은 다시 시작할 필요 없이
    다음 요청부터(30초 안에) 새 계정으로 이어 갑니다. 작업 중이거나 승인을 기다리는 세션이 있으면 이전 계정으로 작업 중인
    세션 목록을 보여 주고 전환할지 한 번 더 묻습니다. 지금 받고 있는 응답은 이전 계정으로 마무리됩니다.
  · 로그인 토큰은 키체인(서비스 이름 "Claude Board-account")에만 저장되고, ~/.claude/notifier/accounts.json 에는
    이메일·조직 같은 표시용 정보만 남습니다. MCP 서버 로그인은 계정을 바꿔도 그대로 유지됩니다.
  · 마지막으로 쓴 지 약 4주가 지난 계정은 로그인이 만료되어 메뉴에 "다시 로그인 필요" 로 표시됩니다. 고르면 설정 > 계정 에서
    다시 로그인합니다.
  · 저장한 계정 지우기(메뉴, 설정 > 계정 의 휴지통)는 지우기 전에 한 번 묻습니다.
  · Claude Code 에서 /logout 하면 그 계정의 로그인이 서버에서 취소되어, 보드에 저장한 그 계정도 다시 추가해야 합니다.
    계정을 바꿀 때는 /login·/logout 대신 보드의 계정 메뉴를 쓰세요.
  · CLAUDE_CONFIG_DIR 을 따로 정해 띄운 세션은 별도의 로그인을 쓰므로 전환되지 않습니다.
  · 한도 자동 전환(기본 꺼짐): 계정 메뉴 맨 아래 "한도가 차면 다른 계정으로 자동 전환" 을 켜면, 지금 계정의
    5시간·주간 한도가 차거나 세션이 한도에 걸려 멈출 때 저장한 다른 계정으로 바꿉니다. 켜져 있으면 계정 칩에 ⇅ 가 붙습니다.
    실행 중인 세션이 새 계정을 쓰기까지 최대 30초가 걸리므로, 전환하고 40초 뒤 한도로 멈췄던 세션에
    이어서 진행하라는 요청을 넣습니다. 보드 탭 세션과 Ghostty 세션만 되고, 다른 터미널은 직접 이어 주세요.
    다른 계정의 남은 한도는 미리 알 수 없어, 그 계정을 쓰다 한도가 찼던 기록(풀리는 시각까지)으로 건너뜁니다.
    전환할 계정이 없으면 알리고 기다립니다. 전환·이어 가기 기록은 ~/.claude/notifier/auto-switch.log 에 남습니다.
- 투명 모드: 창 오른쪽 아래 슬라이더로 창 전체의 투명도를 정합니다(왼쪽으로 갈수록 투명, 최소 30%).
  마우스가 보드 창 밖에 있으면 그 투명도로 보이고(보드를 쓰는 중이어도 같습니다), 마우스를 올리면 불투명해집니다.
  터미널을 펼쳐 화면 전체를 덮은 동안에는 늘 불투명합니다. 창 크기 전환으로 60% 로 줄이거나 손으로 줄이면 다시 적용됩니다.
- 보드 글자 크기: 맨 위 메뉴 막대의 윈도우 > 글자 크기 에서 "보드 글자 크게"(⌥⌘+, ⌥⌘= 도 됨)·"보드 글자 작게"(⌥⌘-)·
  "보드 글자 원래 크기"(⌥⌘0)로 보드 창의 글자를 10%씩 80%~150% 사이로 바꿉니다. 바꾸면 보드 아래쪽에 지금 비율이 잠깐 뜹니다.
  보드 쪽(윗줄·사용 한도·경로 카드·⋯ 메뉴), 터미널 탭 줄, 새 세션 창의 글자가 함께 바뀌고 아이콘·제목 막대 단추·알림 패널은 그대로입니다.
  다시 실행해도 유지됩니다. 보드 폭이 좁은 채 크게 하면 긴 이름·제목이 "…" 로 줄어듭니다(경계를 끌어 보드를 넓히면 다 보입니다).
- 보드가 다른 창 뒤에 있어도 첫 클릭이 바로 단추에 전달됩니다.
- 터미널에서 claude-board 를 실행하면 보드 창을, claude-board-tui 를 실행하면 터미널판 보드를 엽니다.
  (~/.local/bin 이 PATH 에 없으면 전체 경로로 실행하세요.)


4. 보드 안 터미널
-----------------

보드 창 왼쪽에 터미널이 있습니다. 보드에서 새로 띄우거나 이어 연 Claude Code 세션은 이 터미널의 탭(보드 탭)에서 돌고,
지금 Ghostty·iTerm2 등에서 도는 세션은 그대로 그 터미널에 있습니다. 터미널 엔진은 Ghostty 의 libghostty 입니다.

- 펼치기·접기: 제목 막대 왼쪽의 "터미널 펼침/접힘" 단추, 어느 앱에서든 ⌃⌥T, 맨 위 메뉴 막대의 윈도우 > 터미널 펼치기·접기.
  펼치면 창이 화면(메뉴 막대·Dock 을 뺀 영역) 전체로 넓어져 왼쪽 터미널·오른쪽 보드가 되고, 접으면 예전처럼 보드만
  화면 오른쪽에 남습니다. 기본은 펼침이고, 펼침·접힘은 다시 실행해도 유지됩니다.
  · 펼쳐 있어도 다른 앱을 쓰는 중이면 ⌃⌥T 는 접지 않고 보드를 앞으로 꺼내 터미널에 포커스를 줍니다.
  · ⌃⌥B(처음 크기로 오른쪽에 붙이기)는 터미널을 접습니다. 미니 화면 제목 막대에는 단추 자리가 없어 숨지만 ⌃⌥T 는 됩니다.
  · 펼쳐 화면 전체를 덮은 동안에는 "항상 위에 고정" 과 투명도를 쓰지 않습니다(화면 전체를 덮은 창이 늘 위에 있으면 다른 앱을 쓸 수 없습니다).
    아래의 창 크기 전환으로 60% 로 줄이거나 손으로 줄이면 둘 다 다시 적용되고, 접어도 원래 설정으로 돌아옵니다.
- 창 크기 전환: 터미널을 펼친 동안 제목 막대(창 맨 위 띠, 터미널 쪽·보드 쪽 모두)나 경로 줄·탭 줄의 빈 곳(경로 항목 오른쪽,
  탭·"+ ⌘T" 단추 오른쪽)을 두 번 누르면, 창이 화면(메뉴 막대·Dock 을 뺀 영역) 전체일 때는 가로·세로 각각 60% 크기로 화면 가운데에, 그 밖의 크기
  (60%·손으로 바꾼 크기 등)일 때는 화면 전체로 바뀝니다. 제목 막대의 초록 단추도 같습니다.
  · 신호등 단추와 제목 막대의 단추(처음 크기로 붙이기·터미널 펼침·최대축소) 위에서는 그 단추 동작만 합니다.
  · 시스템 설정의 제목 막대 이중 클릭 동작(확대·최소화 등)과 상관없이 이렇게 동작합니다. 크기는 기억하지 않아 펼치기와 다시 실행은
    늘 화면 전체이고, 터미널을 접었을 때와 미니 화면에서는 예전 동작 그대로입니다.
- 보드 위치: 설정 > 창 > 보드 위치 에서 오른쪽(기본)·왼쪽을 고릅니다. 왼쪽이면 펼친 창이 왼쪽 보드·오른쪽
  터미널이 되고, 접기·최대축소·⌃⌥B 도 화면 왼쪽 기준입니다(메뉴 이름도 "처음 크기로 왼쪽에 붙이기" 로 바뀝니다).
  고르면 바로 적용됩니다. 펼쳐 있으면 배치만 바뀌고, 접혀 있거나 미니 화면이면 같은 크기로 화면 반대쪽 끝으로 옮겨 갑니다.
- 펼치기·접기 애니메이션: 설정 > 창 의 "펼치기·접기 애니메이션" 을 켜면 펼치고 접을 때 창이 약 0.55초 동안 부드럽게
  넓어지고 좁아집니다. 기본은 꺼짐이라 바로 바뀝니다. 제목 막대 단추·⌃⌥T·메뉴·세션 클릭 어느 쪽으로 펼쳐도 같습니다.

- 경계 끌기: 터미널과 보드 사이 경계를 끌어 두 영역의 폭을 바꿉니다. 바꾼 보드 폭은 기억하고, 접었을 때도 그 폭입니다.
- 경로 줄: 탭은 작업 경로마다 따로 봅니다. 터미널 맨 위(탭 줄 위)의 경로 줄에 탭이 있는 경로가 처음 연 순서대로 늘어서고,
  탭 줄에는 지금 경로의 탭만 보입니다. 경로 항목에는 상태 점(그 경로 세션 가운데 가장 급한 상태: 승인 대기, 작업 중, 그 밖 순)·
  폴더 이름·탭 수가 보이고, 마우스를 올리면 전체 경로가 뜹니다. 같은 폴더 이름이 둘이면 부모 폴더를 붙여 가릅니다.
  경로가 많아 경로 줄에 다 들어가지 않으면 경로 줄을 가로로 밀어(트랙패드 가로 밀기, Shift+휠) 봅니다. 지금 경로는
  늘 보이도록 경로 줄이 따라 움직입니다.
  · 탭의 경로는 탭을 연 경로(이어 연 세션은 그 세션의 경로)입니다. 탭 안 셸에서 cd 해도 바뀌지 않습니다.
  · 경로 항목을 누르면 그 경로에서 마지막에 고른 탭으로 가서 입력 칸에 포커스를 둡니다.
  · ⌃⌥↑ · ⌃⌥↓ 를 누르면 경로 줄의 앞·뒤 경로로 갑니다. 맨 끝에서 누르면 반대쪽 끝 경로로 넘어가고, 터미널이 접혀 있으면
    펼칩니다. 맨 위 메뉴 막대의 윈도우 > 탭으로 가기 > 이전 경로·다음 경로 에도 있습니다.
  · 세션 줄을 누르거나 종료된 세션을 이어 열거나 새 세션을 시작하면 그 세션의 경로로 바뀝니다.
  · 경로의 마지막 탭을 닫으면 그 경로가 경로 줄에서 빠지고 옆 경로로 바뀝니다. 탭이 하나도 없으면 경로 줄도 숨습니다.
  · 터미널을 펼친 동안 지금 경로의 보드 카드는 폴더 아이콘 모서리에 터미널 표지가 붙습니다. 카드 머리를 누르면 카드를
    접고 펼치면서, 그 경로에 탭이 있으면 터미널도 그 경로로 바뀝니다(터미널이 접혀 있으면 펼치지 않고, 다음에 펼칠 때 그 경로가 보입니다).
- 탭: 세션은 탭으로 하나씩 보고, 탭 안의 화면을 나눌 수도 있습니다(아래 "화면 나누기"). 탭에는 상태 점(화면들의 세션 가운데
  가장 급한 상태)·탭 이름(처음에는 경로의 폴더 이름. 나눈 탭은 탭을 연 경로의 폴더 이름 그대로입니다)·지금 하는 일(고른 화면)이
  보입니다.
  탭이 많아 탭 줄에 다 들어가지 않으면 탭 줄을 가로로 밀어(트랙패드 가로 밀기, Shift+휠) 봅니다. "+ ⌘T" 단추는 늘 오른쪽 끝에
  보이고, 탭을 고르면 그 탭이 보이도록 탭 줄이 따라 움직입니다.

  닫아도 되면 바로 닫고, 프로그램이 돌고 있으면 "탭을 닫을까요?"(나눈 탭에서 ⌘W 는 "화면을 닫을까요?")로 묻습니다(그 프로그램이
  함께 끝납니다). 나눈 탭의 × 는 프로그램이 도는 화면이 하나라도 있으면 한 번 묻고 화면을 모두 닫습니다. 탭이 하나도 없으면
  "보드에서 띄운 세션이 없습니다" 와 새 세션 단추가 보입니다.
  · ⌘1~⌘9 를 누르면 탭 줄(지금 경로의 탭) 순서대로 그 탭으로 가서 입력 칸에 포커스를 둡니다(⌘1 이 첫 번째 탭, ⌘9 가 아홉 번째 탭).
    그 자리에 탭이 없으면 아무 일도 없고, 터미널이 접혀 있으면 펼칩니다. 맨 위 메뉴 막대의 윈도우 > 탭으로 가기 에도 있습니다.
  · ⌃⌥← · ⌃⌥→ 를 누르면 탭 줄(지금 경로의 탭)에서 왼쪽·오른쪽 탭으로 갑니다. 맨 끝에서 누르면 반대쪽 끝 탭으로 넘어가고, 터미널이 접혀
    있으면 펼칩니다. Ghostty 의 탭 키 ⇧⌘[ · ⇧⌘] 와 ⌃⇥ · ⌃⇧⇥ 도 같습니다. 맨 위 메뉴 막대의 윈도우 > 탭으로 가기 > 이전 탭·다음 탭 에도 있습니다.
    다른 앱(창 정리 앱 등)이 ⌃⌥ 방향키를 쓰고 있으면 그 앱이 먼저 받습니다. 그럴 때는 아래 "단축키 바꾸기" 로 다른 키로 옮깁니다.
  · 탭 이름 바꾸기: ⇧⌘R(맨 위 메뉴 막대의 윈도우 > 탭 이름 바꾸기)을 누르면 고른 탭의 이름 자리가 입력 칸이 됩니다(지금 이름이
    골라진 채). Return 이나 입력 칸 밖을 눌러 저장하고, Esc 로 취소합니다. 비우고 저장하면 폴더 이름으로 돌아갑니다.
    끝나면 터미널에 포커스가 돌아오고, 터미널이 접혀 있으면 펼친 뒤 고칩니다. 바꾼 이름은 보드를 다시 켜도 남고 탭 닫기
    확인 창에도 쓰입니다. 옆의 지금 하는 일 글자는 그대로입니다.
  · 세션 이름: 보드 탭에서 띄우거나 이어 여는 claude 는(새 세션, 끝난 세션 이어 열기, 보드를 다시 켤 때 되살리기 모두)
    탭 이름(바꾼 이름, 없으면 폴더 이름)을 세션 이름으로 씁니다. 같은 이름을 쓰는 세션이 이미 있으면 뒤에 -2, -3 을
    붙입니다(나눈 탭의 화면들도 이렇게 나뉩니다). 화면이 하나인 탭의 탭 줄에는 그 세션의 실제 이름이 보입니다.
    claude 가 도는 탭의 이름을 바꾸면 보드가 그 claude 에 /rename <새 이름> 을 바로 쳐 넣어 세션 이름도 바꿉니다(이름을
    지워 폴더 이름으로 돌아갈 때도 같습니다). 승인을 기다리는 중이면 승인 창에 키가 들어가지 않게 승인을 처리한 뒤에
    칩니다. 아직 요청이 없는 세션은 첫 요청을 보낼 때 칩니다(그동안 탭 줄은 새 이름, 카드 라벨은 옛 이름입니다).
    claude 의 입력 칸에 쓰던 글이 있으면 그 글과 섞일 수 있습니다. 명령에 -n·--name 을 직접 적었으면 그 이름을
    그대로 쓰고, 셸 프롬프트에서 직접 친 claude 는 Claude Code 가 붙인 이름으로 시작합니다.
  · ⌘ 를 누르면 바로 지금 경로의 탭마다 × 자리에 ⌘1~⌘9 가 보이고(열 번째 탭부터는 없습니다), 고른 탭에는
    지금 하는 일 대신 "⇧⌘R 이름 바꾸기" 가 보입니다. ⌘ 를 놓을 때까지(⌘1~⌘9 로 탭을 옮기는 동안에도) 남고,
    ⌘C·⌘V 처럼 다른 키와 함께 칠 때도 잠깐 보입니다. 놓으면 원래대로 돌아옵니다.
  · 터미널 안을 마우스로 끌면 글자를 고르고(⌘C 로 복사), 두 번 누르면 단어를 고릅니다.
- 화면 나누기: 탭 안의 화면을 Ghostty 처럼 나눕니다. 키도 Ghostty 와 같습니다(맨 위 메뉴 막대의 윈도우 > 화면 나누기).
  · ⌘D 는 오른쪽으로, ⇧⌘D 는 아래로 반씩 나눕니다. 새 화면에는 지금 화면의 셸이 있는 폴더(셸에서 cd 한 곳)의 셸이 열리고
    포커스가 새 화면으로 갑니다. claude 는 띄우지 않습니다. 터미널이 접혀 있으면 펼칩니다.
  · ⌘[ · ⌘] 는 앞·뒤 화면(왼쪽·위가 앞, 맨 끝에서는 반대쪽 끝), ⌥⌘방향키는 그 방향에 있는 화면으로 갑니다(그 방향에 화면이
    없으면 그대로). 화면을 눌러도 그 화면으로 갑니다. 고르지 않은 화면은 흐리게 보입니다(Ghostty 설정의
    unfocused-split-opacity, 없으면 0.7). 화면 사이 경계 색은 Ghostty 설정의 split-divider-color 를 따릅니다.
  · 경계를 끌어 크기를 바꿉니다(화면이 너무 작아지지 않게 막습니다). ⌃⌘방향키는 고른 화면에서 가장 가까운, 그 방향으로 나눈
    경계를 그 방향으로 10pt 옮기고, ⌃⌘= 는 나눈 크기를 고르게 맞춥니다.
  · ⇧⌘↩ 는 고른 화면 하나만 터미널 칸 전체로 크게 보고, 다시 누르면 돌아옵니다. 크게 보는 동안 탭 이름 옆에 표시가 붙고,
    다른 화면으로 옮기거나 나누면 풀립니다.
  · ⌘W 나 셸의 exit 로 그 화면이 닫히고 옆 화면으로 포커스가 갑니다. 탭의 마지막 화면이면 탭이 닫힙니다.
  · 보드에서 세션 줄을 누르면 그 세션이 도는 탭의 그 화면으로 갑니다(크게 보는 중이면 풉니다). 일시중지·재개·중단,
    업데이트·종료 확인도 화면마다의 세션을 봅니다.
  · 나눈 모양·크기·화면마다의 경로·고른 화면은 보드를 다시 켜도 그대로입니다(크게 보기는 풀린 채).
- 터미널 모양과 키: Ghostty 설정 파일이 있으면 글꼴·색·테마 등을 따릅니다(Ghostty 의 전역 단축키 줄은 쓰지 않습니다).

  Shift+Enter 는 Ghostty 와 같은 키(Claude Code 에서 줄바꿈), ⌘Q 는 보드 종료, ⌘T 는 새 세션, ⇧⌘R 은 탭 이름
  바꾸기입니다. 한글 조합 중 Return·Esc·Shift+Enter 가 한 번에 듣도록 고쳐 두었고, 한글 입력 상태에서도 ⌘W·⌘C·⌘V 같은
  ⌘ 단축키가 영문 상태와 같이 듣습니다. 붙여넣기 모드를 켜지 않은 프로그램에 여러 줄을 붙여 넣을 때와 프로그램이
  클립보드를 읽으려 할 때는 확인 창으로 묻습니다.
- 터미널 글자 크기: ⌘+(⌘= 도 됨)·⌘- 로 1pt씩(8~40pt), 맨 위 메뉴 막대의 윈도우 > 글자 크기 의 "터미널 글자 원래 크기" 로
  Ghostty 설정 크기로 돌아갑니다. 설정 > 터미널 의 − · + 와 되돌리기 단추도 같습니다. 바꾸면 열린 탭 모두와 새로 여는 탭이 같은 크기가 되고, 보드 아래쪽에 지금 크기가 잠깐 뜹니다.

  글자 원래 크기가 아니라 "세션 보드 보기" 입니다. 보드 글자 크기는 따로 정합니다(3장).
- 터미널 테마: 설정 > 터미널 의 테마 목록에서 고릅니다.
  · 목록 위 검색 칸에 이름 일부를 치면(대소문자 무관) 엔진에 든 테마 485개 가운데 맞는 것만 남습니다. 줄마다 테마 이름과
    색 띠(바탕색 칩과 기본 8색)가 보이고, 목록 옆(좁으면 아래)에는 고른 테마의 색으로 그린 터미널 견본이 보입니다.

    (theme 줄이 없거나 엔진에 없는 이름이면 기본 테마(Afterglow)). 검색어를 치는 동안에는 숨습니다.
  · 줄을 누르면 열린 탭 모두 바로 그 테마로 바뀌고 보드 아래쪽에 테마 이름이 잠깐 뜹니다. 지금 쓰는 테마에는 체크 표시가 붙습니다.

    따르기" 를 고릅니다.

- 설정 화면: 맨 위 메뉴 막대의 Claude Board > 설정…(⌘,)을 누르면 오른쪽 보드는 그대로 두고 터미널 자리가 설정 화면으로 바뀝니다.
  · 왼쪽에 "터미널로 돌아가기", 검색 칸, 묶음(일반·창·알림·터미널·보드·계정·단축키·업데이트)이 있고, 오른쪽에 고른 묶음의 설정이
    카드로 보입니다. 검색 칸에 이름 일부를 치면 모든 묶음에서 맞는 설정만 묶음별로 모아 보여 줍니다.

  · 터미널이 접혀 있을 때 열면 펼쳐서 보여 주고, 닫으면 다시 접습니다. 이때 펼친 것은 기억하지 않아 다시 실행해도 접힌 채로 뜹니다.
  · 설정 화면이 떠 있는 동안에도 탭은 뒤에서 그대로 돕니다. ⌘T·⌘1~⌘9·⌘D 같은 탭 단축키, 세션 줄 누르기, 새 세션은
    설정 화면을 닫고 그 동작을 합니다(이때는 펼친 채로 둡니다). ⌃⌥T 로 접으면 설정 화면도 함께 내려갑니다.
  · 들어오는 모양: 설정 > 창 > 설정 화면 전환 에서 옆으로 밀기(기본, 보드 반대쪽에서 밀려 들어옵니다)·서서히 바뀌기·효과 없음을 고릅니다.
  · 묶음별 설정
    - 일반: 항상 위에 고정, 로그인할 때 열기, 제목 옆 캐릭터
    - 창: 보드 위치, 투명도(오른쪽 아래 슬라이더와 같습니다), 펼치기·접기 애니메이션, 설정 화면 전환
    - 알림: 모든 알림 끄기(윗줄 종 단추와 같습니다), 알림 위치
    - 터미널: 터미널 글자 크기, 터미널 테마, 새 세션의 기본 명령과 답변 마크다운 꾸미기 기본값
    - 보드: 보드 글자 크기, 사용 한도 간략히 보기
    - 계정: 저장한 계정(전환·다시 로그인·지우기는 마우스를 올리면 나오는 휴지통), 계정 추가(로그인 링크·인증 코드 칸), 한도가 차면 다른 계정으로 자동 전환
    - 단축키: 아래 "단축키 바꾸기"
    - 업데이트: 지금 버전, 업데이트 확인(새 버전이 있으면 업데이트 단추), 바뀐 점, 자동으로 업데이트 확인
  · 로그인할 때 열기를 끄면 ~/Library/LaunchAgents/com.claude.board.plist 를 지우고 ~/.claude/notifier/login-launch-off 를 남겨
    업데이트가 다시 등록하지 않게 합니다. 지금 떠 있는 보드는 그대로이고 다음 로그인부터 적용됩니다. 켜면 다시 등록합니다.
  · 자동으로 업데이트 확인을 끄면 1시간마다 하던 확인을 하지 않습니다. 손으로 누르는 업데이트 확인은 그대로 됩니다.
- 단축키 바꾸기: 설정 > 단축키 에서 바꿉니다. 이 안내서에 적은 보드 단축키는 모두 기본값이고, 여기서 바꿀 수 있습니다.
  · 바꿀 수 있는 것: 세션 보드 보기, 항상 위에 고정, 처음 크기로 붙이기(⌃⌥B)와 터미널 펼치기·접기(⌃⌥T, 둘 다 어느 앱에서든
    듣습니다), 새 세션, 탭 이름 바꾸기, 탭 1~9, 이전·다음 탭(보조 키 ⇧⌘[·⇧⌘]·⌃⇧⇥·⌃⇥ 도 한 줄씩), 이전·다음 경로,
    화면 나누기의 모든 키, 터미널·보드 글자 크기(보조 키 ⌘=·⌥⌘= 도 한 줄씩, 단축키가 없던 "터미널 글자 원래 크기" 에도 줄 수 있습니다).
  · 묶음(보드·터미널·탭으로 가기·화면 나누기·글자 크기)별 카드로 늘어서고, 설정 화면의 검색 칸으로도 찾습니다.
  · 줄 오른쪽의 키를 누르면 "새 키를 누르세요…" 로 바뀝니다. 그때 누른 키가 바로 새 단축키가 되고, 메뉴와 탭 줄·제목 막대의
    안내 글자(+ ⌘T, ⇧⌘R 이름 바꾸기, ⌘ 를 누르면 보이는 탭 번호 키 등)도 함께 바뀝니다. Esc 는 취소, ⌫ 는 그 단축키를 비웁니다.
    키를 받는 동안에는 ⌃⌥B·⌃⌥T 도 동작하지 않고 그 칸에 들어갑니다. 다른 앱으로 옮기면 받기를 그만둡니다.
  · ⌘·⌃·⌥ 가운데 하나는 함께 눌러야 합니다(F1~F12 는 혼자도 됩니다). ⌘Q·⌘H·⌥⌘H·⌘M·⌘W·⌘C·⌘V·⌘X·⌘A·⌘Z·⇧⌘Z 같은
    macOS 기본 키와 설정 화면을 여는 ⌘, 는 고를 수 없고, 누르면 단축키 카드 아래쪽에 까닭이 뜹니다.
  · 보드의 다른 동작과 같은 키를 고르면 받아 두고 두 줄에 "같은 키입니다" 가 뜹니다. "그쪽 비우기" 로 겹친 쪽을 비웁니다.
    macOS 시스템 단축키(시스템 설정 > 키보드 > 키보드 단축키에서 켜 둔 것)와 겹치면 그 줄에 알립니다. 다른 앱이 잡아 둔
    전역 단축키는 macOS 가 알려 주지 않아 표시하지 못합니다. ⌃⌥B·⌃⌥T 자리의 키를 등록하지 못하면 그 줄에 알립니다.
  · 키는 자판 위치로 맞춥니다(한글 입력 상태에서도 같은 키). 그래서 ⌘+ 는 설정 화면과 메뉴에 ⇧⌘= 로, ⌥⌘+ 는 ⌥⇧⌘= 로 보입니다.
  · 바꾼 키는 노란 글자로 보이고 옆의 되돌리기 단추로 기본값으로 돌아갑니다. "모두 기본값으로" 는 전부 되돌립니다.
    바꾼 키는 다시 실행해도 유지됩니다.
  · 터미널에 포커스가 있어도 보드 단축키가 먼저입니다. 고른 키가 Ghostty 설정이나 터미널 프로그램이 쓰던 키면 그 키는
    터미널로 가지 않습니다.
  · ⌘ 를 누르고 있으면 탭 번호 키가 보이는 것은 그대로입니다(탭 번호 키를 ⌘ 없는 키로 바꿔도 ⌘ 를 누를 때 보입니다).
- 새 세션: 탭 줄 끝의 "+ ⌘T" 단추(마우스를 올리면 "새 세션")를 누르거나 ⌘T(맨 위 메뉴 막대의 윈도우 > 새 세션…)를 누르면
  창이 뜹니다. 터미널이 접혀 있으면 펼칩니다. ⌘T 는 보드가 앞에 있을 때 듣습니다(⌃⌥T 처럼 어느 앱에서든 듣는 단축키는
  아닙니다). 창이 떠 있을 때 다시 눌러도 하나만 뜹니다.
  · 작업 폴더: 보드에 있는 경로 중에서 고르거나(지금 경로가 먼저 골라져 있습니다. 보드에 없는 경로면 첫 경로) "다른 폴더 고르기…" 로 고릅니다.
  · 실행할 명령: 기본값은 claude --dangerously-skip-permissions 입니다. 권한 확인을 건너뛰므로 승인 대기가 거의 없습니다.
    확인을 받으려면 명령에서 --dangerously-skip-permissions 를 지우세요. 창을 열 때마다 기본값으로 돌아갑니다.
    기본값은 설정 > 터미널 > 새 세션 의 기본 명령에서 바꿉니다(비우면 위 명령). 경로 카드 머리의 + 도 이 기본 명령을 씁니다.
    명령은 그 작업 경로의 로그인 셸에 쳐 넣어 실행하고(셸 기록에 남습니다), claude 면 보드가 --session-id 를 붙여 그 세션을 미리 압니다.
    명령 칸과 탭 이름 입력 칸에서는 ⌘A·⌘C·⌘X·⌘V·⌘Z·⇧⌘Z 가 듣습니다(맨 위 메뉴 막대의 편집 메뉴).
  · 답변 마크다운 꾸미기: 기본 켬(아래 참고). 기본값은 설정 > 터미널 > 새 세션 에서 바꿉니다.
  · "새 탭에서 시작"(Return) 또는 "취소"(Esc).
  경로 카드 머리의 + 단추를 누르면 창 없이 그 경로에서 기본 명령(꾸미기는 기본값대로)으로 바로 시작합니다.
  처음 여는 폴더에서는 Claude Code 의 폴더 신뢰 질문이 탭에 뜹니다. 탭에서 답하면 됩니다.
- 실행 환경: 보드 탭은 모두 로그인 셸(사용자 기본 셸)이고, claude 는 그 셸에서 뜹니다. 그래서 셸 설정(~/.zshrc 등)의
  PATH 그대로 사용자 hook 이 쓰는 node 등도 터미널에서처럼 찾고, 셸 설정을 바꾸면 새 탭에 바로 반영됩니다.
- 세션이 끝난 탭: claude 가 끝나면(/exit, 세션 중단) 일반 터미널처럼 그 탭에 작업 경로의 셸 프롬프트가 남습니다.
  방금 실행한 명령은 ↑ 로 다시 부를 수 있습니다.
  · 종료된 세션을 누르면(⋯ 메뉴의 "세션 다시 열기" 도 같음) 그 세션이 돌던 화면이 같은 경로의 셸 프롬프트로 남아 있으면
    그 화면에서 이어 엽니다. 그런 화면이 없거나 다른 프로그램이 돌고 있으면 새 탭에서 엽니다.
  · 셸까지 끝내면(exit) 그 화면이 닫히고, 탭의 마지막 화면이면 탭이 닫힙니다.
- 보드로 옮기기: Ghostty 에서 도는 세션의 ⋯ 메뉴에서 고릅니다. 작업 중·승인 대기면 "보드로 옮길까요?" 로 먼저 묻습니다
  (진행 중인 응답은 끊깁니다). 그 세션을 /exit 로 끝내고, 끝나면(최대 8초 기다림) 보드 새 탭에서 같은 대화를 이어 엽니다.
  세션의 터미널을 찾지 못하거나 세션이 끝나지 않으면 보드 아래에 알리고 그대로 둡니다.
- 업데이트·종료: 보드가 터미널을 쥐고 있으므로 보드 탭 세션은 보드와 함께 꺼집니다.
  보드 탭 세션 가운데 작업 중·승인 대기이거나 서브에이전트·셸이 도는 세션, 탭 안에서 도는 claude -p 가 있으면
  업데이트하거나 종료(⌘Q·메뉴·Dock)하기 전에 "작업 중인 세션 n개가 꺼집니다" 창에 그 목록을 보여 주고
  업데이트(또는 종료)·취소(Esc) 를 묻습니다. 그런 세션이 없으면 묻지 않습니다.
  백그라운드 세션과 다른 터미널의 세션은 영향 없이 그대로 돌고, 목록에도 나오지 않습니다.
  계속하면 끊기는 세션(그 탭에서 사람이 입력하던 claude)에 일시중지 표시를 남깁니다.
- 다시 뜰 때 이어 열기: 보드는 쥐고 있는 탭 목록(작업 경로·명령·세션)을 바뀔 때마다 남겨 두었다가, 다시 뜨면 같은 순서로
  탭을 되살립니다. 보드가 갑자기 꺼져도 마지막으로 남긴 목록으로 되살립니다. 접힌 채 꺼졌으면 접힌 채로 뜹니다.
  지금 경로와 경로마다 마지막에 고른 탭, 나눈 화면의 모양·크기·고른 화면도 그대로입니다.
  · claude 탭(화면)은 대화를 이어 엽니다. 진행 중이던 응답만 끊기고 대화는 남습니다. 질문하기 전에 꺼진 탭은 처음 명령으로 새로 띄웁니다.
    마지막에 보던 탭만 보드가 뜨자마자 이어 열고, 다른 claude 탭은 셸 프롬프트로 기다리다가 그 탭에 들어가는 순간(탭 누르기·⌘ 번호·
    탭 이동 키·세션 줄 누르기) 이어 엽니다. 들어가기 전에 다시 꺼도 그 탭은 claude 탭으로 남습니다.
    셸 탭에서 직접 친 claude 도 돌고 있었으면 claude 탭으로 남깁니다(claude -p 는 빼고).
  · 셸 탭(claude 가 끝나 셸만 남은 탭도)은 그 경로에서 셸을 엽니다.
  · 확인 창을 거쳐 끊긴 세션은 카드가 일시중지로 보이고, ⋯ 메뉴의 "세션 재개" 로 하던 일을 이어 갑니다.
  · /exit 등으로 끝낸 탭은 되살리지 않습니다(종료된 세션을 눌러 이어 열 수 있습니다). 작업 폴더가 없어진 탭도 뺍니다.
  · 그 사이 보드 밖에서 같은 세션을 이어 열어 다른 프로세스가 쥐고 있으면(5초 기다린 뒤에도) 이어 열지 않고 뺍니다.
- 답변 마크다운 꾸미기(md-render): 보드 탭에서 띄우거나 이어 여는 claude 는 답변이 끝나면 제목(보라 굵게)·굵게(주황)·
  기울임(노랑)·취소선·인라인 코드(초록)·목록 기호(주황)·인용(│ 막대)·링크(글자 + 흐린 주소)를 색으로 다시 그립니다.

  · Ghostty·claude -p 에서 시작해 보드로 옮기거나 보드에서 이어 연 세션에도 붙습니다. Ghostty 등 다른 터미널과
    백그라운드 세션에는 붙지 않습니다(Claude Code 전역 플러그인으로 설치하지 않습니다).
  · 끄려면 새 세션 창에서 "답변 마크다운 꾸미기" 체크를 끄고 띄웁니다. 보드가 그 세션을 기억해 다시 열기·다시 뜰 때도
    끈 채로 엽니다.

- 알아 둘 점
  · 보드 탭 세션을 Claude Code 의 /bg 등으로 백그라운드에 보내면 탭을 떠나 백그라운드 세션이 됩니다(탭은 끝납니다).
    그 세션은 새 세션으로 이어 가므로 카드 제목이 "요청 전" 으로 보입니다.
    대화를 넘긴 원래 세션의 카드는 이어 받은 세션의 카드가 생기면 목록과 세션 수에서 빠집니다(다른 터미널에서 보낸 세션도
    같습니다). 원래 세션에서 다시 대화를 이어 가면 다시 보입니다.
    보내는 방법에 따라 탭이 끝나지 않고 넘긴 작업을 붙여 보여 주기도 합니다. 그동안은 탭 줄의 상태 점과 터미널 구역의
    그 탭 카드(CB)가 이어 받은 작업의 상태(작업 중·서브에이전트)를 따라가고, 카드를 누르면 그 탭으로 갑니다. 그 카드에는
    ⋯ 메뉴가 없고(보드는 백그라운드 작업을 멈추거나 끝내지 않습니다), 탭 이름 바꾸기(⇧⌘R)는 탭에서 작업을 풀 때까지 미룹니다.
  · 보드 탭 세션도 hook 이 똑같이 기록하므로 알림·상태 표시는 다른 세션과 같습니다.


5. 업데이트와 제거
------------------

- 업데이트: 새 버전이 나오면 보드 윗줄 아래에 "새 버전 <버전> 이 나왔습니다" 가 뜹니다(미니 화면에서는 보이지 않습니다).
  변경 내용 을 누르면 브라우저에서 버전별 변경 내역(GitHub 의 CHANGELOG.md)이 열립니다.
  업데이트 를 누르면 새 버전을 받아 바꿔 끼우고 보드가 다시 열립니다. hook 등록은 다시 묻지 않습니다.
  보드 탭에서 일하는 중인 세션이 있으면 먼저 묻고, 다시 열린 보드가 탭을 되살립니다("4. 보드 안 터미널" 의 업데이트·종료).
  터미널 설치 명령을 다시 실행해도 같습니다. 실패하면 ~/.claude/notifier/update.log 에 기록이 남습니다.
  새 버전은 보드를 켤 때와 그 뒤 1시간마다 확인합니다(설정 > 업데이트 > 자동으로 업데이트 확인 으로 끕니다).
  바로 확인하려면 윗줄의 업데이트 확인 단추(⟳), 메뉴 막대의 Claude Board > 업데이트 확인…, 설정 > 업데이트 의 업데이트 확인 을 누릅니다.
  새 버전이 없으면 "최신 버전입니다" 가 잠깐 보입니다.
- 제거: dmg 의 Uninstall.command 를 실행합니다. (터미널에서는
  bash "/Volumes/Claude Board/Uninstall.command")
  앱, 설치된 파일(보드가 옮겨 둔 ~/.claude/notifier/plugins/ 포함), settings.json 의 hook 과 환경변수, 자동 실행 등록,
  ~/.zshrc 에 추가한 줄, 계정 전환용으로 저장해 둔 로그인 정보를 지웁니다(지금 Claude Code 로그인은 그대로 둡니다).
  /Applications 의 앱을 지울 때 터미널에서 관리자 비밀번호를 묻습니다.
  settings.json 과 ~/.zshrc 는 지우기 전에 백업합니다.
  제거한 뒤에는 실행 중인 Claude Code 세션을 다시 시작하세요.


6. 문제가 생겼을 때
-------------------

- 알림이 뜨지 않음: Claude Code 세션을 다시 시작했는지, python3 가 동작하는지 확인하세요.
  ~/.claude/settings.json 에 .claude/notifier/ 가 들어간 hook 이 있는지도 확인하세요.
- 보드에 세션이 나타나지 않음: 설치 뒤에 새로 시작한 세션인지 확인하세요.
- 설치가 "실패" 로 끝남: python3 가 없으면 사용자 설정 단계가 실패합니다. 터미널에서
  xcode-select --install 로 설치한 뒤 다시 설치하세요. 자세한 기록은 /var/log/install.log 에 있습니다.
- 더블 클릭해도 탭으로 이동하지 않음: Ghostty 1.3 이상인지, 자동화 권한을 허용했는지 확인하세요.
  "보드로 옮기기" 가 "세션 터미널을 찾지 못해" 로 실패할 때도 같습니다.
- 보드 탭의 claude 가 node·claude 같은 명령을 못 찾거나 hook 오류가 화면에 뜸: 터미널 새 창(로그인 셸)에서 그 명령이
  PATH 에 있는지 확인하세요.
- 새 세션 창의 "답변 마크다운 꾸미기" 체크가 흐리게 꺼져 있음: 플러그인을 ~/.claude/notifier/plugins/md-render/ 로
  옮기지 못한 것입니다. 그 폴더에 쓸 수 있는지 확인하세요.
- 위 문제와 단축키 등록 실패, 터미널 설정 오류, 다시 뜰 때 되살리지 않은 탭 같은 보드 쪽 기록은
  ~/.claude/notifier/board.log 에 남습니다.
- 계정을 전환했는데 사용 한도가 "로그인 토큰 갱신 전" 으로 나옴: 오래 쓰지 않은 계정은 토큰이 만료된 상태로 전환됩니다.
  아무 세션에서나 요청을 한 번 보내면 Claude Code 가 토큰을 갱신하고, 그 뒤 사용량이 표시됩니다.
- 계정 전환이 "Claude Code 가 로그인 정보를 쓰는 중입니다" 로 실패함: Claude Code 가 토큰을 갱신하는 순간과 겹친 것입니다.
  잠시 뒤 다시 고르면 됩니다.
- 계정 추가가 끝나지 않음: 보드는 로그인을 15분 동안 기다립니다. 설정 > 계정 의 "취소"(계정 메뉴의 "계정 추가 취소")로 멈추고 다시 시도하세요.
- settings.json 을 원래대로 되돌리기: ~/.claude/ 폴더의 settings.json.bak-claude-board-<날짜-시각>
  파일 중 설치 직전 것을 settings.json 으로 복사하면 됩니다.
