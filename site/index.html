왜 Claude Board 인가

터미널 창을 뒤지는 시간을 없앱니다

Claude Code 를 여러 개 돌리면 어느 창이 끝났는지, 어느 세션이 권한 승인을 기다리며 멈춰 있는지 알기 어렵습니다. Claude Board 는 모든 세션의 상태를 실시간으로 모아 보여 주고, 끝나거나 멈추는 순간 알려 줍니다.

알림 패널

끝나면 알려 주고, 누르면 그 세션으로

응답이 끝났을 때와 권한 승인이 필요할 때 알림이 뜹니다. 누르면 보드가 열리고, 보드 탭의 세션이면 그 탭으로 바로 갑니다. 위치는 화면 가운데나 네 모서리 중에서 고릅니다.

동작 방식

설치하면 바로 동작합니다

Claude Board 는 Claude Code 의 hook 으로 세션 상태를 기록하고 그 기록을 읽어 보여 줍니다. 별도 서버도, 화면 읽기도 없습니다.

hook 이 상태를 남깁니다

세션이 시작되고, 일하고, 승인을 기다리고, 끝날 때마다 Claude Code 가 hook 을 실행해 상태를 파일로 남깁니다.

보드가 1초마다 읽습니다

보드는 그 파일을 읽어 경로별로 묶고, 상태가 바뀌면 화면과 메뉴 막대 아이콘에 바로 반영합니다.

필요한 순간에 알립니다

응답이 끝나거나 승인이 필요하면 알림 패널이 뜨고, 누르면 그 세션으로 데려갑니다.

지금 설치하기기능 전체 보기

기능

세션 관리에 필요한 모든 것

Claude Board 의 주요 기능을 모았습니다. 각 기능의 자세한 사용법은 사용 설명서에 있습니다.

프로젝트별 세션 보드

프로젝트 폴더(claude 를 띄운 폴더)마다 카드 하나로 세션을 묶습니다. Claude 가 하위 폴더로 cd 하거나 워크트리에 들어가도 세션은 같은 카드에 남습니다. 위쪽 상태 칩을 누르면 그 상태의 세션만 보이고, 30분 넘게 조용한 카드는 저절로 접힙니다. 접힌 카드에서도 도는 링과 지금 하는 일로 진행 상황이 보입니다.

서브에이전트와 백그라운드 작업

세션이 띄운 서브에이전트는 부모 세션 아래에 이름과 지금 쓰는 도구까지 보입니다. 터미널 없이 도는 claude -p 세션은 "백그라운드" 구역에 따로 모입니다.

모델·effort·컨텍스트 표시

세션 줄마다 모델 계열 색(Opus 주황, Sonnet 파랑, Haiku 민트, Fable 보라)과 effort 다섯 칸 막대, 컨텍스트 사용량이 붙습니다.

세션 칩

세션이 어디서 도는지 칩으로 구분합니다. CB 는 보드 탭, Ghostty 같은 앱 이름은 다른 터미널, $ claude -p 는 백그라운드입니다.

세션 메뉴

⋯ 를 누르면 보드 모양의 패널에서 일시중지, 세션 재개, 세션 중단, 보드로 옮기기, 세션 다시 열기를 고릅니다. 지금 쓸 수 없는 항목은 그 까닭을 함께 보여 줍니다.

알림 패널

응답 완료와 승인 요청을 알리는 패널입니다. 세션별로 알림을 끄거나 모두 끌 수 있고, 위치는 가운데와 네 모서리 중에서 고릅니다.

보드 안 터미널

Ghostty 엔진의 터미널이 보드 창에 들어 있습니다. 새 세션, 이어 열기, 보드로 옮기기, 다시 뜰 때 되살리기까지 보드에서 합니다.

답변 마크다운 꾸미기

보드 탭의 Claude 답변을 제목, 굵게, 인라인 코드, 목록, 인용까지 색으로 다시 그려 읽기 쉽게 합니다.

사용 한도

5시간, 주간 전체, 주간 Fable 사용량과 초기화 시각을 보여 줍니다. 상세 모드와 한 줄 간략 모드를 고릅니다.

계정 전환과 자동 전환

여러 Claude 계정을 저장해 두고 한 번에 바꿉니다. 실행 중인 세션도 다시 시작하지 않고 다음 요청부터 새 계정을 씁니다.

세 가지 화면 크기와 투명 모드

전체, 중간, 미니 화면이 창 크기에 맞춰 바뀌고, 다른 앱을 쓰는 동안 보드를 반투명하게 띄워 둘 수 있습니다.

캐릭터와 앱 독

세션 상태를 말풍선으로 알려 주는 캐릭터 여덟 가지 중에서 고르고, 보드 가장자리의 독에서 Ghostty, iTerm2 같은 터미널 앱을 바로 엽니다.

설정 화면

⌘, 를 누르면 보드는 그대로 두고 터미널 자리가 설정 화면으로 바뀝니다. 일반, 창, 알림, 터미널, 보드, 계정, 단축키, 업데이트 묶음에서 고르거나 검색으로 찾고, 바꾸면 바로 적용됩니다.

단축키 바꾸기

새 세션, 탭·경로 이동, 화면 나누기, 글자 크기, 어느 앱에서든 듣는 ⌃⌥B·⌃⌥T 까지 보드 단축키를 원하는 키로 바꿉니다. 다른 동작이나 macOS 단축키와 겹치면 알려 줍니다.

새 기능

보드 안 터미널

보드 창 옆에 터미널이 들어왔습니다. 보드에서 세션을 띄우고, 지켜보고, 꺼져도 이어 엽니다. 지금 Ghostty·iTerm2 에서 쓰는 세션은 그대로 두고 함께 볼 수 있습니다.

펼치고, 접고, 원하는 쪽에

제목 막대의 "터미널 펼침" 단추나 어느 앱에서든 ⌃⌥T 로 터미널을 펼치고 접습니다. 펼치면 창이 화면 전체로 넓어지고, 접으면 보드만 화면 한쪽에 남습니다. 접혀 있어도 탭의 세션은 계속 돕니다.

  • 보드 위치: 설정 › 창 › 보드 위치에서 오른쪽(기본)과 왼쪽을 고릅니다. 왼쪽이면 접기, 미니, 처음 크기로 붙이기도 모두 화면 왼쪽 기준입니다.
  • 펼치기·접기 애니메이션: 설정 › 창에서 켜면 약 0.55초 동안 부드럽게 열리고 닫힙니다. 기본은 꺼짐입니다.
  • 경계 끌기: 터미널과 보드 사이 경계를 끌어 폭을 바꾸면 그 폭을 기억합니다.
  • 창 크기 전환: 펼친 동안 제목 막대나 경로 줄·탭 줄의 빈 곳을 두 번 누르면 화면 전체와 가로·세로 60%(화면 가운데) 사이를 오갑니다. 초록 단추도 같습니다.
탭과 화면 나누기
탭마다 상태 점, 탭 이름(처음에는 경로의 폴더 이름), 지금 하는 일이 보입니다. 탭은 작업 경로마다 따로 봅니다. 탭 줄 위 경로 줄에 탭이 있는 경로가 상태 점·폴더 이름·탭 수로 늘어서고, 탭 줄에는 지금 경로의 탭만 보입니다. 경로를 누르거나 ⌃⌥↑↓ 로 옮기면 그 경로에서 마지막에 고른 탭으로 가고, 보드에서 세션을 누르거나 카드 머리를 눌러도 그 경로로 바뀝니다. ⌘1~⌘9 로 탭 줄 순서대로 바로 고르고 ⌃⌥←→ 로 왼쪽·오른쪽 탭으로 가며(Ghostty 의 ⇧⌘[] 도 같습니다), ⌘ 를 잠깐 누르고 있으면 탭마다 그 번호가 보입니다. ⇧⌘R 로 고른 탭의 이름을 탭 안에서 바로 바꾸고(비우면 폴더 이름), 바꾼 이름은 다시 켜도 남습니다. 탭에서 띄운 claude 는 탭 이름을 세션 이름으로 쓰고(같은 이름이 있으면 -2, -3), 탭 이름을 바꾸면 세션 이름도 함께 바뀝니다. 탭 안의 화면은 Ghostty 와 같은 키로 나눕니다. ⌘D 는 오른쪽, ⇧⌘D 는 아래로 나눠 같은 폴더의 셸을 열고, ⌘[] 와 ⌥⌘ 방향키로 화면을 고르며, 경계를 끌거나 ⌃⌘ 방향키로 크기를 바꿉니다. ⇧⌘↩ 는 고른 화면 하나만 크게 봅니다. 나눈 모양은 다시 켜도 남습니다. 탭에 마우스를 올리면 나오는 × 로 탭을, ⌘W 로 고른 화면을 닫고, 프로그램이 돌고 있으면 먼저 묻습니다. 글꼴과 색은 Ghostty 설정을 따르고, 한글 조합 중 Return·Esc 도 한 번에 듣습니다. 한글 입력 상태에서도 ⌘W·⌘C·⌘V 같은 단축키가 영문 상태와 같이 듣습니다.

기본값은 claude --dangerously-skip-permissions 입니다. 권한 확인을 건너뛰므로 승인 대기가 거의 없습니다. 확인을 받고 싶으면 이 옵션을 지우세요. 늘 쓰는 명령은 설정 › 터미널 › 새 세션의 기본 명령에 넣어 두면 이 창과 경로 카드의 + 가 그 명령을 씁니다.

기본으로 켜져 있고, 기본값은 설정 › 터미널 › 새 세션에서 바꿉니다. 끄고 띄운 세션은 보드가 기억해, 다시 열 때도 끈 채로 엽니다.

세션 줄을 한 번 누르면 세션이 도는 곳으로 갑니다. 줄의 칩이 어디로 갈지 알려 줍니다.

보드로 옮기기

Ghostty 에서 돌던 세션의 ⋯ 메뉴에서 고르면, 그쪽 세션을 끝내고 보드 새 탭에서 같은 대화를 이어 엽니다. 작업 중이면 먼저 묻습니다(진행 중인 응답은 끊깁니다).

끝난 탭

claude 는 그 작업 폴더의 셸에서 뜹니다. /exit 로 끝내면 일반 터미널처럼 셸 프롬프트로 돌아오고, 종료된 세션을 누르면 그 탭에서 이어 엽니다. 셸까지 끝내면 탭이 닫힙니다.

업데이트·종료 전 확인

보드 탭에서 일하는 세션이 있으면 업데이트나 종료 전에 그 목록을 보여 주고 묻습니다. 일하는 세션이 없으면 묻지 않습니다. 백그라운드와 다른 터미널의 세션은 영향을 받지 않습니다.

다시 뜰 때 되살리기

보드는 쥐고 있는 탭 목록을 늘 남겨 두었다가, 다시 뜨면 같은 순서로 탭을 되살립니다. 마지막에 보던 탭은 바로 대화를 이어 열고, 다른 탭은 그 탭에 들어갈 때 이어 엽니다. 일하다 끊긴 세션은 일시중지로 남아 "세션 재개" 한 번으로 이어 갑니다.

지금 Claude Board 설치하기변경 기록 보기

설치

1분이면 시작합니다

터미널 한 줄로 설치하는 방법을 권합니다. dmg 설치 파일도 있습니다.

필요한 환경

  • macOS 14 Sonoma 이상(Apple Silicon, Intel 모두 지원)
  • Claude Code
  • python3: 터미널에서 python3 --version 이 버전을 보여 주면 준비된 것입니다. 없으면 xcode-select --install 로 설치합니다.
  • 다른 터미널의 세션으로 탭 이동, 그 세션의 일시중지·재개·중단·보드로 옮기기는 Ghostty 1.3 이상에서 동작합니다. 보드와 알림, 보드 탭 세션은 어떤 터미널에서도 동작합니다.

터미널로 설치 (권장)

아래 명령을 터미널에 붙여 넣습니다. 처음 설치라면 Claude Code 설정에 hook 을 등록할지 묻고, Enter 를 누르면 설치합니다.

curl -fsSL https://github.com/suhojang/claude-board/releases/latest/download/install.sh | bash

설치가 끝나면 보드 창이 열립니다. 이미 실행 중인 Claude Code 세션은 끝내고 다시 시작하세요. 새로 시작한 세션부터 보드에 나타납니다.

dmg 로 설치

최신 릴리스에서 ClaudeBoard-<버전>.dmg 를 받습니다.

  1. dmg 를 열고 "Claude Board 설치.pkg" 를 더블 클릭합니다.
  2. 처음에는 "열 수 없음" 경고가 뜹니다. 확인을 누른 뒤 시스템 설정 › 개인정보 보호 및 보안 아래쪽에서 "그래도 열기" 를 누르고 암호나 Touch ID 로 확인합니다. 처음 한 번만 필요합니다.
  3. 설치 프로그램에서 계속 › 설치를 누르고 관리자 암호를 입력합니다.
  4. "설치가 완료되었습니다" 가 나오면 닫기를 누릅니다. 보드 창이 자동으로 열립니다.
  5. 실행 중인 Claude Code 세션을 끝내고 다시 시작합니다.
앱은 배포자의 인증서(Claude Board Signing)로 서명되어 있지만 Apple 공증을 받지 않아 dmg 에서는 "그래도 열기" 가 한 번 필요합니다. 터미널로 설치하면 이 단계가 없습니다. 서명은 codesign -dvv "/Applications/Claude Board.app" 2>&1 | grep Authority 로 확인할 수 있습니다.

설치하면 바뀌는 것

  • /Applications/Claude Board.app 이 설치되고 로그인할 때 자동으로 실행됩니다. 보드의 설정 › 일반 › 로그인할 때 열기로 끌 수 있고, 끄면 업데이트해도 다시 등록하지 않습니다.
  • ~/.claude/notifier/ 에 알림 패널과 상태 기록 스크립트가 들어갑니다.
  • ~/.claude/settings.json 에 hook 11개와 환경 변수 하나가 더해집니다. 바꾸기 전에 원본을 백업하고, 쓰고 계신 다른 hook 과 설정은 그대로 둡니다. 여러 번 설치해도 중복으로 등록되지 않습니다.
  • ~/.local/bin 에 claude-board(보드 열기)와 claude-board-tui(터미널판 보드) 명령이 생깁니다.
  • 보드 탭의 답변 꾸미기 플러그인은 ~/.claude/notifier/plugins/md-render/ 에 둡니다.

권한

다른 터미널의 세션으로 이동하거나 Ghostty 세션을 조작할 때 "Claude Board 가 Ghostty 를 제어하려고 합니다" 창이 한 번 뜹니다. 허용해야 그 기능이 동작합니다. 거부했다면 시스템 설정 › 개인정보 보호 및 보안 › 자동화에서 다시 켭니다. 보드 탭 세션은 이 권한 없이 동작합니다.

업데이트

새 버전이 나오면 보드 윗줄 아래에 알림이 뜹니다. 보드를 켤 때와 그 뒤 1시간마다 확인하고, 설정 › 업데이트 › 자동으로 업데이트 확인으로 끌 수 있습니다. "업데이트" 를 누르면 새 버전으로 바꾸고 보드가 다시 열립니다. 보드 탭에서 일하는 세션이 있으면 먼저 묻고, 다시 열린 보드가 탭을 되살립니다. 윗줄의 ⟳ 단추나 설정 › 업데이트의 "업데이트 확인" 으로 바로 확인할 수도 있습니다.

제거

dmg 안의 Uninstall.command 를 실행합니다. 앱, 설치된 파일, settings.json 의 hook 과 환경 변수, 자동 실행 등록, 계정 전환용으로 저장한 로그인 정보를 지웁니다. 지금 쓰는 Claude Code 로그인은 그대로 두고, 바꾸는 설정 파일은 먼저 백업합니다.

Claude Board 사용법

보드 화면을 읽는 법부터 계정 전환까지 차례로 설명합니다. 보드 안 터미널은 따로 정리한 페이지를 보세요.

보드 읽기세션 누르기세션 메뉴알림 패널 화면 크기사용 한도계정 전환설정 화면그 밖의 기능

보드 읽기

보드는 프로젝트 폴더(claude 를 띄운 폴더)별 카드로 세션을 묶어 보여 줍니다. Claude 가 하위 폴더로 cd 하거나 워크트리에 들어가도 같은 카드에 남습니다. 카드 안에서는 보드 탭과 다른 터미널의 세션이 "터미널" 구역에, 터미널 없이 도는 세션이 "백그라운드" 구역에 모입니다.

  • 위쪽 상태 칩: 승인 대기, 작업 중, 대기 세션 수입니다. 누르면 그 상태의 세션만 보이고, 다시 누르면 모두 보입니다.
  • 세션 줄: 상태 아이콘, 첫 요청(제목), 경과 시간, 세션 칩, 모델과 effort, 컨텍스트 사용량, 세션 이름이 보입니다. 승인 대기면 무엇을 승인해야 하는지도 나옵니다.
  • 세션 이름: Claude Code 의 세션 이름(세션끼리 메시지를 보낼 때 부르는 이름)입니다. 보드 탭 세션은 탭 이름과 같고, 다른 터미널 세션은 Claude Code 가 붙인 이름(예: claude-board-81) 그대로입니다. 보드 칸이 좁으면 먼저 빠집니다.
  • 모델 라벨: 색은 모델 계열(Opus 주황, Sonnet 파랑, Haiku 민트, Fable 보라), 뒤의 다섯 칸 막대는 effort 단계입니다. 마우스를 올리면 정확한 모델 ID 가 보입니다.
  • 서브에이전트: 세션이 띄운 하위 작업은 부모 세션 아래에 이름, 모델, 지금 쓰는 도구와 함께 보입니다.
  • 카드 접기: 승인 대기나 작업 중 세션이 없고 30분 넘게 조용한 카드는 저절로 접힙니다. 접힌 카드에서도 작업 중이면 도는 링, 승인 대기면 퍼지는 파문과 지금 하는 일이 보입니다.
  • 종료된 세션: 카드 아래 "종료된 세션" 에 모이고, 2일이 지나면 저절로 지워집니다. 오른쪽 ⓧ 로 바로 지울 수도 있습니다.

세션 누르기

  • 보드 탭 세션(CB): 터미널을 펼치고 그 탭의 입력 칸으로 갑니다. 접혀 있거나 미니 화면이어도 됩니다.
  • 다른 터미널의 세션: 한 번 누르면 그 터미널 앱이, 두 번 누르면 그 세션의 탭이 앞으로 옵니다(탭 이동은 Ghostty 1.3 이상).
  • 종료된 세션: 보드 새 탭에서 claude --resume 으로 대화를 이어 엽니다. 처음 실행할 때 쓴 옵션과 마지막 권한 모드도 그대로 적용됩니다.
  • 백그라운드 세션($ claude -p): 이동할 터미널이 없어 보드 아래에 안내만 잠깐 뜹니다.

세션 메뉴(⋯)

세션 줄 오른쪽의 ⋯ 를 누르면 메뉴 패널이 뜹니다. 맨 위에 세션 이름과 상태, 칩, 작업 폴더가 있고 항목마다 한 줄 설명이 붙습니다. 마우스나 ↑↓ 로 고르고 클릭이나 Return 으로 실행하며, Esc 나 바깥 클릭으로 닫습니다.

세션 재개일시중지한 세션에 이어서 진행하라는 요청을 넣어 하던 일을 이어 갑니다. 꺼진 세션이면 보드 새 탭에서 이어 열며 요청을 넣습니다.
보드로 옮기기Ghostty 세션을 끝내고 보드 새 탭에서 같은 대화를 이어 엽니다.
세션 다시 열기종료된 세션을 보드 새 탭에서 대화형으로 엽니다.
세션 중단확인한 뒤 진행 중인 응답을 멈추고 세션을 끝냅니다. 대화 기록은 남아 다시 열 수 있습니다.

도는 백그라운드 세션에는 메뉴가 없습니다. 보드는 백그라운드 세션에 어떤 신호도 보내지 않습니다.

알림 패널

  • 응답이 끝나거나 승인이 필요할 때 뜹니다. 키보드 입력을 가져가지 않아 쓰던 프롬프트를 그대로 이어 쓸 수 있습니다.
  • 누르면 보드가 열리고(보드 탭 세션이면 그 탭으로) 패널이 닫힙니다. 누르지 않으면 10초 뒤 닫히고, 마우스를 올려 두면 기다립니다.
  • 위치는 설정 › 알림 › 알림 위치의 화면 그림에서 가운데, 왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래 중 한 자리를 눌러 고릅니다. 모서리에서는 여러 알림이 겹치지 않게 쌓입니다.
  • 세션 줄의 종 모양 스위치로 그 세션의 알림을, 윗줄의 종 단추로 모든 알림을 끕니다.

화면 크기

창 크기에 따라 화면이 세 단계로 바뀝니다. 창을 손으로 줄이거나 늘리면 저절로 바뀝니다.

  • 전체: 기본 화면입니다.
  • 중간: 창이 낮아지면 사용 한도가 한 줄로, 카드가 한 줄 요약으로 바뀝니다. 카드를 누르면 그 카드만 펼쳐집니다.
  • 미니: 경로마다 한 줄씩 상태와 지금 하는 일을 보여 줍니다. 제목 막대의 최대축소 단추로 바로 가장 작게 줄이고, ⤢ 로 원래 크기로 돌아옵니다. 터미널을 펼친 채 줄였으면 되돌릴 때 다시 펼칩니다.

⌃⌥B 를 누르면 언제든 처음 크기로 화면 한쪽에 붙습니다.

사용 한도

사용 한도 카드는 5시간, 주간 전체, 주간 Fable 사용량과 초기화 시각을 보여 줍니다. 오른쪽 위 단추로 한도마다 막대를 보는 상세 모드와 한 줄 간략 모드를 바꿉니다. 간략 모드에서는 마우스를 올리면 초기화 시각이 보입니다.

계정 전환

사용 한도 카드 왼쪽 위의 계정(이메일·요금제)을 누르면 계정 메뉴가 열립니다.

  • 계정 추가: "계정 추가…" 를 누르면 설정 › 계정이 열리고 그 안에서 로그인이 시작됩니다(터미널 창은 뜨지 않습니다). 보드가 띄운 로그인 창에서 추가할 계정으로 로그인하면 저절로 저장되고, 그 창을 닫으면 계정 추가를 취소합니다. Google 로그인이 막히면 이메일로 로그인하거나 링크를 다른 브라우저에서 열고, 브라우저가 보여 준 코드는 같은 자리의 칸에 붙여넣습니다. 지금 쓰는 로그인은 바뀌지 않아 작업 중에도 미리 추가해 둘 수 있습니다.
  • 계정 바꾸기: 저장한 계정을 고르면 모든 Claude Code 세션이 그 계정으로 바뀝니다. 실행 중인 세션도 다음 요청부터(30초 안에) 새 계정을 씁니다. 작업 중인 세션이 있으면 한 번 더 묻습니다. 설정 › 계정에서도 고르고 지울 수 있고, 지우기 전에 한 번 묻습니다.
  • 한도 자동 전환: 메뉴 맨 아래나 설정 › 계정의 "한도가 차면 다른 계정으로 자동 전환" 을 켜면, 한도가 차거나 세션이 한도에 걸려 멈출 때 다른 계정으로 바꾸고 멈췄던 세션을 이어 가게 합니다(기본 꺼짐).
로그인 토큰은 macOS 키체인에만 저장됩니다. 계정을 바꿀 때는 Claude Code 의 /login·/logout 대신 보드의 계정 메뉴를 쓰세요. /logout 은 그 계정의 로그인을 서버에서 취소합니다.

설정 화면

메뉴 막대의 Claude Board › 설정…(⌘,)을 누르면 오른쪽 보드는 그대로 두고 터미널 자리가 설정 화면으로 바뀝니다. 왼쪽에서 묶음을 고르거나 검색 칸에 이름을 쳐 모든 묶음에서 찾습니다. 저장 단추는 없고, 바꾸면 바로 적용되어 다시 켜도 남습니다.

  • 일반: 항상 위에 고정, 로그인할 때 열기, 제목 옆 캐릭터
  • 창: 보드 위치, 투명도, 펼치기·접기 애니메이션, 설정 화면 전환(옆으로 밀기 기본, 서서히 바뀌기, 효과 없음)
  • 알림: 모든 알림 끄기, 알림 위치
  • 터미널: 터미널 글자 크기, 터미널 테마, 새 세션의 기본 명령과 답변 마크다운 꾸미기 기본값
  • 보드: 보드 글자 크기, 사용 한도 간략히 보기
  • 계정: 저장한 계정 고르기·지우기, 계정 추가, 한도가 차면 다른 계정으로 자동 전환
  • 단축키: 보드 단축키 바꾸기
  • 업데이트: 지금 버전, 업데이트 확인, 바뀐 점, 자동으로 업데이트 확인

Esc(검색어가 있으면 먼저 지웁니다), "터미널로 돌아가기", ⌘, 한 번 더, ⌘W 로 닫습니다. 터미널이 접혀 있었으면 펼쳐서 보여 주고 닫을 때 다시 접습니다. 설정 화면이 떠 있는 동안에도 탭은 뒤에서 그대로 돌고, ⌘T·⌘1 같은 탭 단축키나 세션 줄을 누르면 설정 화면을 닫고 그 동작을 합니다.

단축키 바꾸기

설정 › 단축키에서 줄의 키를 누르고 새 키를 누르면 바로 바뀌고, 메뉴와 탭 줄·제목 막대의 안내 글자도 함께 바뀝니다. Esc 는 취소, ⌫ 는 그 단축키 비우기입니다. 보드의 다른 동작과 같은 키면 그 줄에 알리고 겹친 쪽을 비울 수 있고, macOS 시스템 단축키(시스템 설정 › 키보드 › 키보드 단축키에서 켜 둔 것)와 겹치면 알립니다. ⌘Q·⌘W·⌘C·⌘V 같은 macOS 기본 키와 설정 화면을 여는 ⌘, 는 고를 수 없습니다. 바꾼 키는 "모두 기본값으로" 나 줄의 되돌리기 단추로 되돌립니다.

Rectangle 이나 Raycast 같은 창 정리 앱이 ⌃⌥ 방향키를 먼저 가져가 탭·경로 이동이 듣지 않으면, 설정 › 단축키에서 다른 키로 옮기면 됩니다.

그 밖의 기능

  • 메뉴 막대 아이콘: 보드 창을 열고 닫고, 승인 대기와 작업 중 세션 수를 보여 줍니다.
  • 캐릭터: 제목 오른쪽 캐릭터가 세션 상태를 말풍선으로 알려 줍니다. 오른쪽 클릭이나 설정 › 일반에서 여덟 가지 중에 고릅니다.
  • 앱 독: 보드 바깥쪽 가장자리 아래의 작은 탭에 마우스를 대면 Ghostty, iTerm2, 터미널, Orca 를 바로 여는 독이 나옵니다.
  • 투명 모드: 오른쪽 아래 슬라이더(설정 › 창의 투명도와 같습니다)로 투명도를 정하면 마우스가 보드 창 밖에 있는 동안 보드가 반투명해집니다. 마우스를 올리면 다시 또렷해지고, 터미널을 펼쳐 화면 전체를 덮은 동안에는 늘 불투명합니다.
  • 위에 고정: 윗줄의 "위에 고정", ⌘P, 설정 › 일반에서 보드를 다른 창 위에 띄워 둡니다.
  • 터미널판 보드: 터미널에서 claude-board-tui 를 실행하면 보드를 터미널 안에서 봅니다.

문제 해결

자주 묻는 질문

대부분의 문제는 세션을 다시 시작하거나 권한을 확인하면 풀립니다. 보드 쪽 기록은 ~/.claude/notifier/board.log 에 남습니다.

알림이 뜨지 않아요

설치한 뒤 Claude Code 세션을 다시 시작했는지 확인하세요. python3 가 동작하는지, ~/.claude/settings.json 에 .claude/notifier/ 가 들어간 hook 이 있는지도 봅니다.

보드에 세션이 나타나지 않아요

설치한 뒤 새로 시작한 세션만 보입니다. 질문 없이 끝난 세션은 이어 열 대화가 없어 목록에 나오지 않습니다.

세션을 두 번 눌러도 터미널 탭으로 가지 않아요

탭 이동은 Ghostty 1.3 이상에서 됩니다. 시스템 설정 › 개인정보 보호 및 보안 › 자동화에서 Claude Board 가 Ghostty 를 제어하도록 허용했는지 확인하세요. "보드로 옮기기" 가 세션 터미널을 찾지 못할 때도 같습니다.

탭·경로 이동 단축키(⌃⌥ 방향키)가 듣지 않아요

Rectangle 이나 Raycast 같은 창 정리 앱이 같은 키를 먼저 가져간 것입니다. 그 앱에서 키를 비우거나, 보드의 설정 › 단축키에서 이전 탭·다음 탭·이전 경로·다음 경로를 다른 키로 옮기세요.

보드 탭의 claude 가 node 같은 명령을 못 찾아요

터미널 새 창에서 그 명령이 PATH 에 있는지 확인하세요. 셸 설정을 바꿨다면 보드를 다시 띄워야 새 탭에 반영됩니다.

"답변 마크다운 꾸미기" 체크가 흐리게 꺼져 있어요

플러그인을 ~/.claude/notifier/plugins/md-render/ 로 옮기지 못한 것입니다. 그 폴더에 쓸 수 있는지 확인하세요.

계정을 바꿨더니 사용 한도가 "로그인 토큰 갱신 전" 으로 나와요

오래 쓰지 않은 계정은 토큰이 만료된 채 전환됩니다. 아무 세션에서나 요청을 한 번 보내면 갱신되고 사용량이 보입니다.

설치가 "실패" 로 끝났어요

python3 가 없으면 사용자 설정 단계가 실패합니다. xcode-select --install 로 설치한 뒤 다시 설치하세요. 자세한 기록은 /var/log/install.log 에 있습니다.

settings.json 을 설치 전으로 되돌리고 싶어요

~/.claude/ 의 settings.json.bak-claude-board-<날짜-시각> 가운데 설치 직전 파일을 settings.json 으로 복사하면 됩니다.

Claude Board

Claude Code 세션을 한 화면에서 보고, 띄우고, 이어 여는 macOS 앱입니다. 이 설명서는 3.2.0 을 기준으로 합니다.

Claude Board 는 Anthropic 의 공식 제품이 아닌 개인 오픈 소스 프로젝트입니다.
